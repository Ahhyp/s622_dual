# record-issue

记录问题：现象 + 原因 + 解决方法。每个问题一条记录。

## 参数

- `<标题>` — 问题简短标题（必需）
- `--stage <N>` — 指定阶段（如 "第一阶段"），不传则根据上下文推断

## 格式

追加到 `docs/issues.md`（集中管理）：

```markdown
---

## [第X阶段] <标题>

**日期：** YYYY-MM-DD

**现象：**
```
<错误日志>
```

**原因：**
<根因分析>

**解决：**
<修复命令或代码改动>
```

## 执行步骤

1. 确定目标阶段（用户传参或从上下文推断）
2. 收集现象（错误日志）、原因、解决方法（从对话中提取）
3. 追加到 `docs/issues.md`
4. 如果 `docs/issues.md` 不存在则创建
