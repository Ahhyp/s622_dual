就是你 Gazebo 相机的那四个数字：


fx = 465.6    fy = 625.2
cx = 320      cy = 240
fx, fy — 焦距（像素单位）。把物理世界的"米"翻译成图像上的"像素"。f 越大，同样的物体在图像上占的像素越多。

cx, cy — 光心。相机光轴穿过图像传感器的那个像素位置，通常是图像正中心（640/2=320, 480/2=240）。

怎么用的：

```
像素 u = fx × (X_cam / Z_cam) + cx     # 3D米 → 像素
      = 465.6 × (X / Z) + 320

反推： X_cam = (u - cx) × Z / fx       # 像素 → 3D米
```
这就是你代码里 error_estimator.py 那两行公式的数学含义。内参是相机"眼睛"的处方——告诉你每个像素对应现实世界哪个方向。
