# 慧灵六轴双机械臂协同搬运与递物系统

英文项目名：

> **Dual HITBOT 6-DoF Arm Cooperative Transport and Handover System**

你现在的基础是：

```text
已有：
1. 环境已经准备好
2. 有单臂抓取经验
3. 使用慧灵/类法奥六轴机械臂
4. 目前只做过抓取，还没有完整放置流程

下一步重点：
1. 先补齐单臂 pick-and-place 闭环
2. 再做双臂同步运动
3. 最后做双臂交接和协同搬运
```

慧灵官方资料里，Z-Arm 六轴系列支持更换末端工具；例如 S622 标称工作半径 622 mm、负载 3 kg、重复定位精度 ±0.02 mm，S922 标称工作半径 922 mm、负载 5 kg、重复定位精度 ±0.02 mm，并且官方参数页写有 TCP/IP、Modbus、ROS 等开发方式。具体项目里你要以自己手上的型号为准，但这说明这类机械臂很适合做 ROS/MoveIt 项目。([慧灵科技][1])

# 一、项目总体目标

最终做成两个核心 demo：

## Demo 1：双臂协同搬运

两个慧灵六轴机械臂分别抓住长条物体两端，同步搬运到目标位置。

效果：

```text
左臂抓住物体左端
右臂抓住物体右端
双臂同步抬起
保持相对位姿
移动到目标区域
同步放下
双臂撤离
```

## Demo 2：双臂递物交接

左臂抓取物体，递给右臂，右臂接过后放置到指定位置。

效果：

```text
左臂 pick
左臂移动到 handover pose
右臂移动到 receive pose
左臂松开
右臂夹紧
右臂 place
```

这个项目最后可以体现：

```text
1. 单臂抓取与放置
2. 双臂坐标系统一
3. 双臂运动规划
4. 轨迹同步执行
5. 双臂交接策略
6. 真实机械臂部署能力
7. 安全约束与异常处理
```

# 五、第一阶段：补齐单臂 Pick-and-Place

你现在只做过抓取，没有放置。下一步最应该做的是：

## 目标

让单臂完整完成：

```text
home
  -> pre_grasp
  -> grasp
  -> close_gripper
  -> lift
  -> move_to_place
  -> descend
  -> open_gripper
  -> retreat
  -> home
```

这一步完成后，你的单臂就不只是“抓一下”，而是完整任务闭环。

## 需要新增的能力

### 1. 放置位姿规划

你需要定义：

```text
place_pose
pre_place_pose
retreat_pose
```

例如：

```text
place_pose:
  x: 0.35
  y: -0.20
  z: 0.08
  roll: 3.14
  pitch: 0.0
  yaw: 1.57

pre_place_pose:
  在 place_pose 上方 8~12 cm

retreat_pose:
  放置后垂直上抬 8~12 cm
```

### 2. 夹爪状态管理

状态机里不要只写“夹爪闭合”，要明确：

```text
gripper_open
gripper_close
gripper_wait
gripper_check，可选
```

### 3. 规划场景更新

如果你使用 MoveIt / PlanningScene，需要在抓取后把物体设置为 attached object，放置后再 detach。

简化版也可以先不做真实物理 attach，而是用任务逻辑模拟：

```text
抓取成功后：认为物体随 TCP 移动
放置成功后：更新物体位置到 place_pose
```

### 4. 放置成功判定

建议先定义简单判据：

```text
TCP 到达 place_pose 上方
夹爪打开成功
机械臂 retreat 成功
无碰撞
```

如果有视觉或传感器，后续可以加入物体实际位置检测。

## 第一阶段验收标准

```text
单臂能连续完成 10 次 pick-and-place
成功率 >= 80%
每次任务结束后机械臂能回 home
出现失败时不会继续危险运动
```

这一步是你双臂项目的地基。

# 六、第二阶段：双臂坐标系统一

双臂项目最重要的不是一开始就规划，而是先把坐标系搞清楚。

## 推荐 TF 结构

```text
world
├── left_base_link
│   └── left_link1
│       └── ...
│           └── left_tcp
│
└── right_base_link
    └── right_link1
        └── ...
            └── right_tcp
```

两个机械臂必须在同一个 `world` 坐标系下。

## 你需要做的事情

### 1. 机械臂安装位置建模

例如两台机械臂面对面安装在桌子两侧：

```text
left_base:
  x: 0.0
  y: 0.35
  z: 0.0
  yaw: -90 deg

right_base:
  x: 0.0
  y: -0.35
  z: 0.0
  yaw: 90 deg
```

具体数值要根据你真实桌面布置量尺。

### 2. 写静态 TF

用 `static_transform_publisher` 或 YAML 配置：

```text
world -> left_base_link
world -> right_base_link
```

### 3. 验证 TCP 位姿

让左右臂分别移动到你定义的公共点附近，检查：

```text
左臂 TCP 坐标是否正确
右臂 TCP 坐标是否正确
两个 TCP 是否能到达同一个 handover 区域
```

## 第二阶段验收标准

```text
RViz 中能同时看到两台机械臂
左右臂 base 坐标位置正确
左右臂 TCP 位姿反馈正确
两臂工作空间存在交集
```

# 八、第四阶段：双臂同步运动

这一步开始进入真正“双臂协同”。

## 最小目标

让两个机械臂同时从 home 移动到指定姿态：

```text
left_arm -> left_ready_pose
right_arm -> right_ready_pose
```

要求：

```text
同时启动
大致同时到达
过程中不碰撞
```

## 同步策略

先用最简单稳定的方式：

```text
1. 分别规划左臂轨迹
2. 分别规划右臂轨迹
3. 取两条轨迹中较长的执行时间
4. 对较短轨迹做时间拉伸
5. 同时发送执行命令
```

同步误差可以这样定义：

```text
sync_error = abs(left_arrival_time - right_arrival_time)
```

## 验收标准

```text
双臂可以同时运动到 ready pose
到达时间误差 <= 200 ms
无碰撞
执行失败时两臂都停止或回安全位
```

这一步做完，项目已经开始有协同系统的味道了。

# 九、第五阶段：双臂递物交接

这是最适合你当前机械臂条件的核心任务。

## 为什么先做交接，而不是先做共同搬运？

因为交接任务更容易真机落地：

```text
不需要两个夹爪同时刚性抓住同一个物体
不容易出现内力冲突
对夹爪和物体建模要求更低
演示效果也很清楚
```

## 推荐流程

```text
1. 左臂从桌面抓取物体
2. 左臂移动到 handover_pose
3. 右臂移动到 receive_pose
4. 两臂进入低速模式
5. 右夹爪闭合
6. 左夹爪打开
7. 右臂抬起
8. 右臂移动到 place_pose
9. 右臂放置
10. 双臂回 home
```

## handover pose 设计

先不要做复杂优化，第一版可以手动定义：

```text
handover_pose:
  x: 0.35
  y: 0.00
  z: 0.25
```

这个点应该满足：

```text
左臂能舒服到达
右臂能舒服到达
离桌面足够高
远离两臂底座
不会接近奇异位形
```

## receive_pose 设计

右臂接收姿态应该和左臂末端错开一点，不要让两个夹爪正面硬碰。

可以设计成：

```text
左臂从物体左侧夹持
右臂从物体右侧夹持
两个夹爪方向相差 180 度
```

或者：

```text
左臂水平递出
右臂从上方/侧方接收
```

## 第五阶段验收标准

```text
左臂能稳定抓物
左臂能到达交接位姿
右臂能到达接收位姿
右夹爪闭合后左夹爪释放
右臂能完成放置
连续 10 次成功率 >= 70%
```

# 十、第六阶段：双臂协同搬运

这个任务更高级，但要注意真实机械臂风险。

## 推荐从简化版开始

第一版不要让两个真夹爪刚性夹住一个硬物体，否则容易出现双臂内力冲突。

建议按这个顺序做：

```text
版本 1：虚拟长条物体，双臂保持相对位姿运动
版本 2：轻质泡沫棒 / 纸盒，低速真机搬运
版本 3：加入同步误差统计
版本 4：加入障碍物避障
```

## 双臂搬运约束

核心是保持两个 TCP 的相对位姿：

```text
T_left_tcp_to_right_tcp = constant
```

也就是搬运过程中：

```text
左臂 TCP 和右臂 TCP 的距离基本不变
两个末端姿态相对关系基本不变
```

## 推荐物体

一开始用安全轻量物体：

```text
泡沫棒
纸箱
塑料空盒
3D 打印轻质横梁
```

不要一开始搬硬质重物。

## 第六阶段验收标准

```text
双臂能同步接近物体两端
双臂能同步抬起
双臂能保持相对距离
双臂能移动到目标区域
任务过程中无碰撞、无明显拉扯
连续 10 次成功率 >= 60%
```

真机双臂协同搬运做到 60% 以上已经很不错；仿真里可以做到 80% 以上。

# 十一、安全规划，非常重要

因为你是真机械臂，不是纯仿真，这部分一定要做，简历里也可以写。

## 建议加入安全模块

```text
safety.yaml
```

里面配置：

```text
max_joint_velocity
max_cartesian_velocity
workspace_limit
handover_safe_zone
emergency_stop_topic
min_distance_between_arms
```

## 真机测试顺序

每个新动作都按这个流程：

```text
1. RViz / MoveIt 预览轨迹
2. 空载低速执行
3. 单臂执行
4. 双臂错时执行
5. 双臂同步低速执行
6. 加入轻物体
```

## 必须避免

```text
不要一开始双臂高速同步
不要一开始搬硬物
不要让两个夹爪刚性夹死同一个硬物
不要让两臂在没有限速的情况下进入交接区
不要跳过急停测试
```

慧灵官方参数页显示部分六轴型号支持碰撞检测和自定义碰撞等级，但项目里仍然要自己实现软件侧限速、工作空间限制和任务超时保护。([慧灵科技][3])

# 十四、你现在下一步最应该做什么

从你的当前状态出发，下一步不是直接上双臂，而是：

# 先完成单臂 Pick-and-Place

具体做这 5 件事：
