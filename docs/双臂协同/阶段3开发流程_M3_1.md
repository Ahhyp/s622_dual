## M3.1.2 MuJoCo 加载生成 MJCF 骨架

写一个转换脚本:

```python
# ~/s622_embodied/s622_mujoco/scripts/convert_urdf.py
"""URDF -> MJCF 骨架转换."""
import mujoco
from pathlib import Path

URDF_PATH = Path(__file__).parent.parent / "mjcf" / "s622_dual_arm.urdf"
OUTPUT_MJCF = Path(__file__).parent.parent / "mjcf" / "s622_generated.xml"

# MuJoCo loader 需要 <mujoco> 根标签, 用一个 wrapper URDF 指定 meshdir
wrapper_content = f"""<?xml version="1.0"?>
<robot name="s622">
    <mujoco>
        <compiler meshdir="assets" balanceinertia="true" 
                  discardvisual="false" strippath="false"/>
    </mujoco>
"" + URDF_PATH.read_text().split("<robot", 1)[1].split(">", 1)[1]

tmp_urdf = URDF_PATH.parent / "s622_dual_arm_mj.urdf"
tmp_urdf.write_text(wrapper_content)

# 加载并导出 MJCF
model = mujoco.MjModel.from_xml_path(str(tmp_urdf))
print(f"loaded: {model.nq} qpos, {model.nv} nv, {model.nu} nu")
print(f"joints: {[mujoco.mj_id2name(model, mujoco.mjtObj.mjOBJ_JOINT, i) for i in range(model.njnt)]}")

# 保存 MJCF
mujoco.mj_saveLastXML(str(OUTPUT_MJCF), model)
print(f"saved MJCF to {OUTPUT_MJCF}")
```

**可能的问题 & 修复**:

| 症状                                 | 原因                               | 修复                                                              |
| ------------------------------------ | ---------------------------------- |
| Mesh 显示为灰色简单块                | 路径错                             | 检查 `assets/` 下 STL 是否全,`meshdir` 是否对                     |
| 模型倒着或位置错                     | URDF 的 world → base_link 变换缺失 | 转换前手动加根 link 或改 fix joint                                |
| 加载报错 `mesh has degenerate faces` | STL 有退化三角面                   | 用 meshlab 清理,或加 `<compiler strippath="false" fitab="true"/>` |
| Continuous joint 报错                | MuJoCo 不支持无限旋转              | URDF 里改成 revolute 带大 limit(±2π 或 ±10 rad)                   |
| 手指 collision 与 wrist3 自碰        | URDF 没 collision exclude          | 后面 MJCF 精修加 `<contact><exclude>`                             |

## 合并 body 树的两种方法

### 方法 A: 手动复制粘贴(一次性,简单)

```bash
# 打开 s622_generated.xml, 复制 <body name="left_shoulder_link" ...> 到 </body> 整块
# 粘贴到 s622_dual_arm.xml 的 left_base_link 内部(替换 PLACEHOLDER)
# 同理 right
```

但这样每次重新从 URDF 生成,都要重新复制。

### 方法 B: Python 脚本自动合并(推荐)

写一个脚本读 `s622_generated.xml`,提取 body 树,注入到模板:

```python
# ~/s622_embodied/s622_mujoco/scripts/build_scene.py
"""合并生成的骨架到主场景文件."""
import xml.etree.ElementTree as ET
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent / "mjcf"
GENERATED = ROOT / "s622_generated.xml"
TEMPLATE = ROOT / "s622_dual_arm_template.xml"
OUTPUT = ROOT / "s622_dual_arm.xml"


def extract_arm_tree(xml_path: Path, arm_prefix: str):
    """从 generated.xml 提取 arm body 子树."""
    tree = ET.parse(xml_path)
    root = tree.getroot()
    worldbody = root.find("worldbody")
    shoulder_body = worldbody.find(f".//body[@name='{arm_prefix}_shoulder_link']")
    if shoulder_body is None:
        raise ValueError(f"{arm_prefix}_shoulder_link not found")
    return shoulder_body


def inject_arms(template_path: Path, left_tree, right_tree, output_path: Path):
    """注入 arm 树到模板."""
    tree = ET.parse(template_path)
    root = tree.getroot()
    wb = root.find("worldbody")
    
    # 找占位 body
    left_base = wb.find(".//body[@name='left_base_link']")
    right_base = wb.find(".//body[@name='right_base_link']")
    
    # 清空并注入
    left_base.clear()
    left_base.attrib = {"name": "left_base_link", "pos": "0.35 0 0", "euler": "0 0 3.14159"}
    left_base.append(left_tree)
    
    right_base.clear()
    right_base.attrib = {"name": "right_base_link", "pos": "-0.35 0 0"}
    right_base.append(right_tree)
    
    tree.write(output_path, encoding="utf-8", xml_declaration=True)


def main():
    left = extract_arm_tree(GENERATED, "left")
    right = extract_arm_tree(GENERATED, "right")
    inject_arms(TEMPLATE, left, right, OUTPUT)
    print(f"[ok] built {OUTPUT}")


if __name__ == "__main__":
    main()
```

**先用方法 A(手动复制)快速推进**,方法 B 留到 M3.2 优化。
