## M2.4 方案

**决策要点**:

* move_group 也用 Gazebo URDF(不用 M2.3 那份纯运动学 URDF),避免两份同步问题
* M2.4 launch 只启核心环境(Gazebo + 双臂 + move_group + planning_scene + camera bridge + RViz)
* **不启** fairino_ik_service 和 obb_node(它们是单臂配置,M2.6/M2.7 改造双臂后再启)
* World SDF 需要新增双臂版(桌子中心 x=0),M1.7 的 `table_world.sdf` 保留不动
* 时序:Gazebo→spawn robot→JSB(8s)→四个 arm/hand controller(12s)→move_group(15s)→RViz(16s)

## 产出 3: `gz_launch/launch/s622_dual_arm.launch.py`(新建)

```python
# s622_dual_arm.launch.py
# M2.4: 双臂完整环境启动
# 组件: Gazebo(world+双臂+桌子+cube) + RSP + CM(gz_ros2_control) + 5 controllers
#       + move_group + RViz + planning_scene_service(双臂 touch_links) + camera_bridge
# 不含: fairino_ik_service(M2.6 改造), obb_node(M2.7 改造), servo(M2.5)
import os
import yaml
from launch import LaunchDescription
from launch.actions import (
    IncludeLaunchDescription, TimerAction, SetEnvironmentVariable,
)
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch_ros.actions import Node
from ament_index_python.packages import get_package_share_directory
from moveit_configs_utils import MoveItConfigsBuilder


def generate_launch_description():
    this_pkg = get_package_share_directory("gz_launch")
    robot_desc_pkg = get_package_share_directory("s622_moveit_descriptions")
    robot_moveit_pkg = get_package_share_directory("s622_moveit_config")
    fairino_planning_pkg = get_package_share_directory("fairino_planning_ros")

    # ============ 环境变量: gz sim model search path ============
    set_model_path = SetEnvironmentVariable(
        "IGN_GAZEBO_RESOURCE_PATH",
        os.path.join(this_pkg, "models")
        + ":" + os.environ.get("IGN_GAZEBO_RESOURCE_PATH", ""),
    )

    # ============ 1. Gazebo + world ============
    world_file = os.path.join(this_pkg, "worlds", "dual_arm_world.sdf")
    gazebo = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            os.path.join(get_package_share_directory("ros_gz_sim"),
                         "launch", "gz_sim.launch.py")
        ),
        launch_arguments=[("gz_args", world_file + " -r")],
    )

    # ============ 2. Bridges ============
    clock_bridge = Node(
        package="ros_gz_bridge",
        executable="parameter_bridge",
        arguments=["/world/dual_arm_world/clock@rosgraph_msgs/msg/Clock[gz.msgs.Clock"],
        parameters=[{"use_sim_time": True}],
        remappings=[("/world/dual_arm_world/clock", "/clock")],
    )

    camera_bridge = Node(
        package="ros_gz_bridge",
        executable="parameter_bridge",
        arguments=[
            "/camera/image@sensor_msgs/msg/Image@gz.msgs.Image",
            "/camera/depth_image@sensor_msgs/msg/Image@gz.msgs.Image",
            "/camera/camera_info@sensor_msgs/msg/CameraInfo@gz.msgs.CameraInfo",
        ],
        remappings=[
            ("/camera/image", "/camera/color/image_raw"),
            ("/camera/depth_image", "/camera/depth/image_raw"),
            ("/camera/camera_info", "/camera/color/camera_info"),
        ],
        parameters=[{"use_sim_time": True}],
        output="screen",
    )

    # ============ 3. MoveIt config (双臂 URDF+SRDF) ============
    dual_arm_gazebo_xacro = os.path.join(
        this_pkg, "config", "s622_dual_arm_gazebo.urdf.xacro"
    )
    moveit_config = (
        MoveItConfigsBuilder("s622_dual_arm", package_name="s622_moveit_config")
        .robot_description(file_path=dual_arm_gazebo_xacro)
        .robot_description_semantic(file_path="config/s622_dual_arm.srdf")
        .robot_description_kinematics(file_path="config/dual_arm_kinematics.yaml")
        .trajectory_execution(file_path="config/dual_arm_moveit_controllers.yaml")
        .planning_pipelines(pipelines=["ompl"], default_planning_pipeline="ompl")
        .planning_scene_monitor(
            publish_robot_description=True,
            publish_robot_description_semantic=True,
        )
        .to_moveit_configs()
    )

    # 自定义 planning pipeline 参数 (M1.7 有的话保留)
    fairino_planning_yaml = os.path.join(
        fairino_planning_pkg, "config", "fairino_planning.yaml"
    )
    with open(fairino_planning_yaml, 'r') as f:
        pipeline_params = yaml.safe_load(f)

    # ============ 4. Spawn robot ============
    # 把 package:// URI 替换成绝对路径, 让 gz sim 能找到 mesh
    gz_urdf = moveit_config.robot_description["robot_description"].replace(
        "package://s622_moveit_descriptions", robot_desc_pkg
    )
    spawn_robot = Node(
        package="ros_gz_sim",
        executable="create",
        arguments=[
            "-string", gz_urdf,
            "-x", "0.0", "-y", "0.0", "-z", "0.0",
            "-R", "0", "-P", "0", "-Y", "0",
            "-name", "s622_dual_arm",
        ],
        output="screen",
    )

    # ============ 5. Spawn target cube ============
    # 双臂布置: cube 放桌面中间偏左, 靠近左臂工作区
    spawn_box = TimerAction(
        period=7.0,
        actions=[
            Node(
                package="ros_gz_sim",
                executable="create",
                arguments=[
                    "-world", "dual_arm_world",
                    "-file", os.path.join(this_pkg, "models", "target_box", "model.sdf"),
                    "-name", "target_box",
                    "-x", "0.15", "-y", "0.0", "-z", "0.05",
                    "-R", "0", "-P", "0", "-Y", "0.0",
                ],
            )
        ],
    )

    # ============ 6. robot_state_publisher ============
    robot_state_pub = Node(
        package="robot_state_publisher",
        executable="robot_state_publisher",
        parameters=[moveit_config.robot_description, {"use_sim_time": True}],
    )

    # ============ 7. Controllers spawner (分两轮: JSB 先, arm/hand 后) ============
    dual_arm_controllers_yaml = os.path.join(
        robot_moveit_pkg, "config", "dual_arm_controllers.yaml"
    )

    jsb_spawner = TimerAction(
        period=8.0,
        actions=[
            Node(
                package="controller_manager",
                executable="spawner",
                arguments=[
                    "-p", dual_arm_controllers_yaml,
                    "joint_state_broadcaster",
                ],
                parameters=[{"use_sim_time": True}],
                output="screen",
            )
        ],
    )

    arm_hand_spawner = TimerAction(
        period=12.0,
        actions=[
            Node(
                package="controller_manager",
                executable="spawner",
                arguments=[
                    "-p", dual_arm_controllers_yaml,
                    "left_arm_controller",
                    "left_hand_controller",
                    "right_arm_controller",
                    "right_hand_controller",
                ],
                parameters=[{"use_sim_time": True}],
                output="screen",
            )
        ],
    )

    # ============ 8. planning_scene_service (双臂 touch_links, table 中心 0,0) ============
    planning_scene = TimerAction(
        period=13.0,
        actions=[
            Node(
                package="s622_arm_actions",
                executable="planning_scene_service",
                name="planning_scene_service",
                parameters=[{
                    "use_sim_time": True,
                    "base_link": "world",
                    "default_object_size": [0.04, 0.04, 0.04],
                    "default_touch_links": [
                        "left_finger1", "left_finger2", "left_grasp_frame",
                        "right_finger1", "right_finger2", "right_grasp_frame",
                    ],
                    "publish_table": True,
                    "table_size": [1.5, 0.8, 0.03],
                    "table_center": [0.0, 0.0, -0.015],
                }],
                output="screen",
            )
        ],
    )

    # ============ 9. move_group (等 controller_manager 起来后) ============
    move_group = TimerAction(
        period=15.0,
        actions=[
            Node(
                package="moveit_ros_move_group",
                executable="move_group",
                parameters=[
                    moveit_config.to_dict(),
                    pipeline_params,
                    {"use_sim_time": True},
                ],
                output="screen",
            )
        ],
    )

    # ============ 10. RViz ============
    rviz_config = os.path.join(robot_moveit_pkg, "config", "dual_arm.rviz")
    rviz = TimerAction(
        period=16.0,
        actions=[
            Node(
                package="rviz2",
                executable="rviz2",
                arguments=["-d", rviz_config],
                parameters=[
                    moveit_config.robot_description,
                    moveit_config.robot_description_semantic,
                    moveit_config.robot_description_kinematics,
                    {"use_sim_time": True},
                ],
            )
        ],
    )

    return LaunchDescription([
        set_model_path,
        gazebo, clock_bridge, camera_bridge,
        spawn_robot, spawn_box,
        robot_state_pub,
        jsb_spawner, arm_hand_spawner,
        planning_scene,
        move_group, rviz,
    ])
```

## 常见坑

### 1. spawner 超时:`controller_manager not available`

gz_ros2_control 启动 CM 有时较慢(WSL2 尤其)。若日志见:

```
[spawner-...] [ERROR] Controller manager not available at /controller_manager
```

把 `jsb_spawner` 的 period 从 8 加到 12,`arm_hand_spawner` 从 12 加到 18,`planning_scene` 15,`move_group` 20,`rviz` 22。**顺序不能乱**:JSB → arm/hand → move_group。move_group 起时若 controllers 还没 active,它加载 trajectory_execution 会 warn 但不 crash,后续能自愈,不是致命。

### 2. gz_ros2_control 找不到 `dual_arm_controllers.yaml`

`$(find s622_moveit_config)/config/dual_arm_controllers.yaml` 里 `find` 是 xacro 时被替换,不是运行时。所以只要**编译时** `s622_moveit_config/install/share/.../config/dual_arm_controllers.yaml` 存在就行。

```bash
ls install/s622_moveit_config/share/s622_moveit_config/config/dual_arm_controllers.yaml
```

不存在就 CMakeLists.txt 没 install 到,补 `install(DIRECTORY config ...)`。

### 3. `s622_gazebo_ros2_control.xacro` name 冲突

M2.1 macro 头是 `<ros2_control name="${prefix}${name}">`,双次调用生成 `left_GazeboSimSystem` / `right_GazeboSimSystem`——不冲突。

**若 M2.1 忘了这样改**(name 硬编码不带 prefix),两次实例化后 name 都是 `GazeboSimSystem`,gz_ros2_control 会报"duplicate ros2_control name"。检查方法:

```bash
grep -A1 '<ros2_control' /tmp/dual_gz.urdf
# 期望看到 name="left_GazeboSimSystem" 和 name="right_GazeboSimSystem"
```

### 4. planning_scene_service 的 `base_link=world` 服务代码兼容性

服务代码可能内部把 CollisionObject 的 `header.frame_id` 设成 `base_link` 参数值,`world` 是 URDF 里的真 link,MoveIt 能接受。但若服务内部有类似 `tf.transform_to_target_frame("base_link")` 的硬编码逻辑,`world` 就成了硬编码不存在的 frame。

**验证**:V6 若看不到 table CollisionObject,或 table 位置在 world 里错位(比如出现在双臂之间上方),说明服务处理 base_link 参数有问题。M2.7 时看代码再改。

**M2.4 阶段绕过**:若真出问题,把 `base_link` 参数改回 `left_base_link`,`table_center` 用左臂坐标系表达(需算变换),但不推荐——先按 world 试,不通再说。

### 5. cube 掉出桌面

桌面高度 z=0,cube 在 (0.15, 0, 0.05) → cube 底面 z=0.03(cube 4cm),浮在桌面上方 3cm。物理 sim 一开会掉到桌面上停下——预期。如果一直掉穿桌面,说明桌子 collision 没生效,检查 `model://table` 里 SDF collision 段。

### 6. 相机 pose 反了

D435 macro 里 camera_link 的 x 是镜头方向(RealSense 惯例)。当前 `rpy="0 π/2 0"`:

* 初始 camera_link: x=前 y=左 z=上
* 绕 y 转 π/2: 新 x=下, y=左, z=前
* 光轴(原 x)现在朝下 ✓

若显示不对,尝试:

* `rpy="0 -π/2 0"`(向上看)
* `rpy="π 0 0"`(倒挂 z 朝下但 x 还是前)
* `rpy="0 π/2 π/2"`(俯视但转过 90°)

调对后 M1.7.1 相机反投影的**外参需要重做**(相机位置从原本 (0.35,0.5,0.9) 变到 (0,0,0.75))。这不是 M2.4 的锅,M2.7 前更新一次校准即可。

### 7. RViz 里 `dual_arm.rviz` config 找不到

M2.3 时保存到 `src/s622_moveit_config/config/dual_arm.rviz`。install 段要包含 `config`:

```cmake
install(DIRECTORY config launch DESTINATION share/${PROJECT_NAME})
```

`ls install/s622_moveit_config/share/s622_moveit_config/config/dual_arm.rviz` 检查。

### 8. `use_sim_time` 遗漏

任一节点漏了 `{"use_sim_time": True}`,该节点用 wall time,与 sim time 不同步会导致 TF 时间戳错乱、planning_scene 显示滞后等。上面 launch 里全部节点都传了,只要照抄别删。

### 9. `s622_dual_arm.srdf` 里 `<robot name="s622_dual_arm">`

URDF `<robot name="s622_dual_arm">`,SRDF 也是,`MoveItConfigsBuilder("s622_dual_arm", ...)` 也是——三者一致才能 MoveIt 正确加载。有任何一个不一致会静默失败。
