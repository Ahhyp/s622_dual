## 一、对先前计划的修正说明

以下条目在上一版方案中不准确或不严谨,本次全部修正:

**1. 环境版本假设错误**

* 上一版直接给出 `mujoco==3.1.6 + PyTorch 2.2 + lerobot main`,并把这个组合套用到原版 ACT
* 错误在于:原版 ACT (tonyzhao/act) `requirements.txt` 固定在 `mujoco==2.3.7 / dm_control==1.0.9 / torch==1.11.0`,和 LeRobot 主分支所需的 mujoco 3.x 不兼容
* 修正:两套独立 conda 环境,分别锁版本(见第二节)

**2. `data.qpos[:14]` 直接等同双臂状态**

* 上一版隐含 MuJoCo 原始 qpos 前 14 维就是双臂关节
* 错误:场景里有 cube free joint(7 qpos, 6 dof)、gripper mimic 关节、tendon 等,原始 qpos 顺序由 MJCF 决定,不是"关节 XML 声明顺序"
* 修正:显式维护 `LogicalJointOrder` + `qposadr/dofadr/actadr` 三套mapping(见第四节)

**3. DLS IK 代码变量语义错误**

* 上一版伪代码 `data.qpos[arm_qpos_ids] += dq`,其中 `dq` 来自 Jacobian 求逆
* 错误:MuJoCo Jacobian 是 `3 x nv` 维,列对应 **DoF index**;而 `qpos` 是 nq 维,索引对应 **qpos address**;两者对旋转关节相等,但对 free joint 或 ball joint 不等
* 修正:分别用 `dof_ids` 抽 Jacobian 列,用 `qposadr` 累加位置(见第六节)

**4. Action schema 左右穿插**

* 上一版把 gripper 放在末尾,`[left_6, right_6, grip_l, grip_r]`
* 修正:按你要求,每只臂 6+1 连续,`[left_j1..6, grip_l, right_j1..6, grip_r]`,Cartesian 版本 `[left_pos3+rotvec3+grip, right_pos3+rotvec3+grip]`

**5. Chunk execution / receding horizon / temporal aggregation 混用**

* 上一版把三者说成"rolling horizon + ensemble",混淆
* 修正:三种执行模式分开设计,分开 config(见第九节)

**6. MoveIt Servo 接口误用**

* 上一版说"policy joint delta 输出 → 直接 JointJog"
* 错误:JointJog 语义是 **单步位移或速度**,不是绝对目标;绝对 joint target 应走 controller 或差分成 velocity
* 修正:policy 输出与 Servo 消息的转换层单独实现(见第十节)

**7. 双臂用两个独立 Servo 直接跑**

* 上一版依赖两个 `/left/servo_node` `/right/servo_node` 各自独立发命令
* 错误:M2.8 handover 已经暴露两臂执行时间可差 70s+(左右规划轨迹不同长度)
* 修正:新增 `BimanualCommandCoordinator` 节点做同步(见第十一节)

**8. 验收以 loss 阈值为准**

* 上一版设"L1 loss < 0.5,val/train gap < 20%"
* 错误:归一化决定 loss 数量级,无普适阈值
* 修正:验收全部以 rollout 指标为准(见每个 milestone 的验收节)

## 四、JointOrder / Actuator Mapping(单一真值)

`s622_mujoco/joint_order.py`:

```python
"""S622 双臂逻辑关节顺序与 MuJoCo 映射.

Logical state: 14 维, 每只手臂 6 关节 + 1 归一化夹爪, 左右连续排布.
数据集、策略输入输出、ROS 接口必须遵循此顺序.
"""
from dataclasses import dataclass
from typing import List
import mujoco
import numpy as np

# ---- 逻辑顺序 (14 维) ----
LOGICAL_ORDER: List[str] = [
    "left_j1", "left_j2", "left_j3", "left_j4", "left_j5", "left_j6",
    "left_gripper",     # 归一化 [0=闭合, 1=打开]
    "right_j1", "right_j2", "right_j3", "right_j4", "right_j5", "right_j6",
    "right_gripper",
]
LOGICAL_DIM = 14
ARM_JOINT_NAMES_LEFT  = LOGICAL_ORDER[0:6]
ARM_JOINT_NAMES_RIGHT = LOGICAL_ORDER[7:13]

# ---- MJCF 中的原始关节名 (可能与逻辑名不同) ----
MJCF_ARM_JOINTS_LEFT  = ["left_j1", ..., "left_j6"]  # 与 URDF/MJCF 一致
MJCF_ARM_JOINTS_RIGHT = ["right_j1", ..., "right_j6"]
# gripper 在 MJCF 里可能是双 finger joint + tendon, 需要单独处理
MJCF_GRIPPER_FINGERS_LEFT  = ["left_finger1_joint", "left_finger2_joint"]
MJCF_GRIPPER_FINGERS_RIGHT = ["right_finger1_joint", "right_finger2_joint"]

# 夹爪归一化: raw finger position -> [0,1]
GRIPPER_RAW_CLOSED = 0.0     # finger joint position when closed
GRIPPER_RAW_OPEN   = 0.025   # 需依 MJCF 实际 limit 填写


@dataclass(frozen=True)
class ArmMapping:
    """一只手臂的 MuJoCo 索引集合.""
    joint_ids:     np.ndarray  # (6,) mujoco joint id, from mj_name2id
    qpos_adr:      np.ndarray  # (6,) qpos indices, from model.jnt_qposadr
    dof_adr:       np.ndarray  # (6,) DoF indices,  from model.jnt_dofadr
    actuator_ids:  np.ndarray  # (6,) actuator ids
    ee_site_id:    int         # end-effector site id, for mj_jacSite
    ee_body_id:    int         # end-effector body id, for xpos/xquat access

    gripper_joint_ids: np.ndarray  # (_finger_joints,) 
    gripper_qpos_adr:  np.ndarray
    gripper_actuator_id: int       # 单个 actuator 驱动 tendon 或第一个 finger


@dataclass(frozen=True)
class DualMaping:
    left:  ArmMapping
    right: ArmMaping

    def logical_to_mujoco_qpos(self, logical: np.ndarray, qpos_out: np.ndarray):
        """把 14 维逻辑状态写到 MuJoCo qpos 的对应索引.
        注意: 不覆盖 qpos 里的其它自由度 (cube free joint 等)."""
        qpos_out[self.left.qpos_adr]  = logical[0:6]
        qpos_out[self.right.qpos_adr] = logical[7:13]
        # gripper: 逻辑 [0,1] -> raw finger position
        left_raw  = GRIPPER_RAW_CLOSED + logical[6]  * (GRIPPER_RAW_OPEN - GRIPPER_RAW_CLOSED)
        right_raw = GRIPPER_RAW_CLOSED + logical[13] * (GRIPPER_RAW_OPEN - GRIPPER_RAW_CLOSED)
        qpos_out[self.left.gripper_qpos_adr]  = left_raw   # broadcast if 2 fingers mimic
        qpos_out[self.right.gripper_qpos_adr] = right_raw

    def mujoco_to_logical(self, model, data) -> np.ndarray:
        out = np.zeros(LOGICAL_DIM, dtype=np.float64)
        out[0:6]  = data.qpos[self.left.qpos_adr]
        out[7:13] = data.qpos[self.right.qpos_adr]
        # 夹爪取第一根手指的 qpos, 归一化
        l_raw = data.qpos[self.left.gripper_qpos_adr[0]]
        r_raw = data.qpos[self.right.gripper_qpos_adr[0]]
        out[6]  = np.clip((l_raw - GRIPPER_RAW_CLOSED) 
                          / (GRIPPER_RAW_OPEN - GRIPPER_RAW_CLOSED), 0.0, 1.0)
        out[13] = np.clip((r_raw - GRIPPER_RAW_CLOSED) 
                          / (GRIPPER_RAW_OPEN - GRIPPER_RAW_CLOSED), 0.0, 1.0)
        return out


def build_mapping(model: mujoco.MjModel) -> DualMapping:
    def build_arm(arm_joints, fingers, ee_site_name, ee_body_name, grip_act_name):
        jids = np.array([mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_JOINT, n)
                          for n in arm_joints])
        assert (jids >= 0).all(), f"missing joint in {arm_joints}"
        return ArmMapping(
            joint_ids=jids,
            qpos_adr=np.array([model.jnt_qposadr[j] for j in jids]),
            dof_adr =np.array([model.jnt_dofadr[j]  for j in jids]),
            actuator_ids=np.array([
                mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_ACTUATOR, f"{n}_act")
                for n in arm_joints]),
            ee_site_id=mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_SITE, ee_site_name),
            ee_body_id=mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_BODY, ee_body_name),
            gripper_joint_ids=np.array([
                mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_JOINT, f)
                for f in fingers]),
            gripper_qpos_adr=np.array([
                model.jnt_qposadr[
                    mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_JOINT, f)]
                for f in fingers]),
            griper_actuator_id=mujoco.mj_name2id(
                model, mujoco.mjtObj.mjOBJ_ACTUATOR, grip_act_name),
        )
    return DualMapping(
        left =build_arm(MJCF_ARM_JOINTS_LEFT,  MJCF_GRIPPER_FINGERS_LEFT,
                        "left_grasp_site",  "left_grasp_frame", "left_gripper_act"),
        right=build_arm(MJCF_ARM_JOINTS_RIGHT, MJCF_GRIPPER_FINGERS_RIGHT,
                        "right_grasp_site", "right_grasp_frame", "right_gripper_act"),
    )
```

**关键点**:

* `qpos_adr` ≠ `dof_adr`,IK 中 Jacobian 用 `dof_adr` 索引列
* `ee_site` 在 MJCF 里显式定义为 `grasp_frame` 位置,不用 body origin
* Gripper 归一化在这层处理,策略只见 [0,1]

### Action (策略输出)

两种 mode 共享 14 维 shape,不同 mode 语义不同:

```python
# Mode A: joint_target (M3.3 baseline)
#14 维绝对关节目标, 直接送 position controller
action_A = np.array([
    left_j1_target, ..., left_j6_target,    # 6, 弧度
    left_gripper_target,                     # 1, [0,1]
    right_j1_target, ..., right_j6_target,   # 6
    right_gripper_target,                    # 1
])

# Mode B: cartesian_delta (M3.4)
# 双臂 EE 增量在 base frame; 旋转使用 3维 rotation vector (axis-angle small delta)
action_B = np.array([
    left_dx, left_dy, left_dz,               # 3, meter, base_frame
    left_dr_x, left_dr_y, left_dr_z,         # 3, rotation vector, base_frame
    left_gripper_target,                     # 1, absolute [0,1]
    right_dx, right_dy, right_dz,            # 3
    right_dr_x, right_dr_y, right_dr_z,      # 3
    right_griper_target,                    # 1
])
```

**Cartesian delta 关键约定**:

* **参考 frame**: base (world 系),不用局部 E frame,避免 rotation 分布随姿态变化
* **旋转表示**: 3 维 rotation vector `r = θ * axis`,axis-angle 的小量近似

  * 从 quat delta 转 rotation vector: `q_delta = q_target * q_current⁻¹`, 然后 `rotation_vector(q_delta)`
  * 大转角避免:每步 clip `|r| ≤ 0.1 rad`(约 5.7°)
* **单位**: 米、弧度
* **最大 delta**(clip):`|dx|,|dy|,|dz| ≤ 0.02 m/step`(50Hz 下 = 1m/s)
* **Gripper**: **绝对值**而非 delta,因为夹爪状态离散、delta 累积漂移

## 六、DLS IK 正确实现

**核心接口**:

```python
# s622_mujoco/ik.py
import mujoco
import numpy as np
from typing import Optional, Tuple

def quat_to_rotvec(q_wxyz: np.ndarray) -> np.ndarray:
    """quaternion (w,x,y,z) -> rotation vector (axis * angle). 
    小角度稳定,大角度 wrap."""
    w = np.clip(q_wxyz[0], -1.0, 1.0)
    xyz = q_wxyz[1:4]
    norm_xyz = np.linalg.norm(xyz)
    if norm_xyz < 1e-9:
        return np.zeros(3)
    angle = 2.0 * np.arctan2(norm_xyz, w)
    # angle wrap to [-pi, pi]
    if angle > np.pi:
        angle -= 2 * np.pi
    return (xyz / norm_xyz) * angle


def quat_mul(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    """Hamilton product, wxyz."""
    aw, ax, ay, az = a
    bw, bx, by, bz = b
    return np.array([
        aw*bw - ax*bx - ay*by - az*bz,
        aw*bx + ax*bw + ay*bz - az*by,
        aw*by - ax*bz + ay*bw + az*bx,
        aw*bz + ax*by - ay*bx + az*bw,
    ])


def quat_conj(q: np.ndarray) -> np.ndarray:
    return np.array([q[0], -q[1], -q[2], -q[3]])


def compute_pose_error(
        current_pos: np.ndarray, current_quat: np.ndarray,
        target_pos: np.ndarray, target_quat: np.ndarray) -> np.ndarray:
    """6-vec error: [pos_err(3), rot_vec_err(3)] in world/base frame."""
    pos_err = target_pos - current_pos
    q_err = quat_mul(target_quat, quat_conj(current_quat))
    rot_err = quat_to_rotvec(q_err)
    return np.concatenate([pos_err, rot_err])


def dls_ik_single_arm(
        model: mujoco.MjModel,
        data_scratch: mujoco.MjData,     # 临时 MjData, 不改真实 rollout data
        target_pos: np.ndarray,          # (3,) in world frame
        target_quat: np.ndarray,         # (4,) wxyz
        arm_qposadr: np.ndaray,         # (6,) 
        arm_dofadr:  np.ndarray,         # (6,)
        ee_site_id:  int,
        q_current:   np.ndarray,         # (6,) starting guess
        joint_lower: np.ndarray,         # (6,) rad
        joint_upper: np.ndarray,         # (6,) rad
        damping:     float = 0.05,
        max_iter:    int   = 30,
        pos_tol:     float = 1e-3,       # meters
        rot_tol:     float = 5e-3,       # rad
        step_clip:   float = 0.2,        # per-iter delta cap (rad)
) -> Tuple[np.ndarray, bool]:
    """
    Returns:
        q_solution: (6,) joint values
        converged: bool
    关键:
        1. data_scratch 是独立副本, 不污染真实 rollout state.
        2. Jacobian 3xnv, 用 arm_dofadr 抽 6 列.
        3. qpos 累加用 arm_qposadr, 对旋转关节 dofadr==qposadr, 但保持通用性.
        4. 每步 clip delta 和 clip 到 joint limits.
        5. 使用 site 而非 body 作为 E.
    """
    # 载入初始 guess 到 scratch
    data_scratch.qpos[arm_qposadr] = q_current
    mujoco.mj_forward(model, data_scratch)

    jac_pos = np.zeros((3, model.nv))
    jac_rot = np.zeros((3, model.nv))

    for it in range(max_iter):
        # 当前 site 位姿
        cur_pos  = data_scratch.site_xpos[ee_site_id].copy()
        # site_xmat 是 3x3 行主序, 转quat
        xmat = data_scratch.site_xmat[ee_site_id].reshape(3, 3).copy()
        cur_quat = np.zeros(4)
        mujoco.mju_mat2Quat(cur_quat, xmat.flatten())

        err = compute_pose_error(cur_pos, cur_quat, target_pos, target_quat)
        if (np.linalg.norm(err[:3]) < pos_tol
                and np.linalg.norm(err[3:]) < rot_tol):
            return data_scratch.qpos[arm_qposadr].copy(), True

        # Jacobian at site, indexed by DoF
        mujoco.mj_jacSite(model, data_scratch, jac_pos, jac_rot, ee_site_id)
        J = np.vstack([jac_pos, jac_rot])[:, arm_dofadr]   # (6, 6)

        # DLS: dq = J^T (J^T + λ²I)⁻¹ e
        JJt = J @ J.T
        dq = J.T @ np.linalg.solve(
            Jt + (damping**2) * np.eye(6), err)

        # Clip step
        dq_norm = np.linalg.norm(dq)
        if dq_norm > step_clip:
            dq *= (step_clip / dq_norm)

        # Update via qposadr, clip to limits
        q_new = data_scratch.qpos[arm_qposadr] + dq
        q_new = np.clip(q_new, joint_lower, joint_upper)
        data_scratch.qpos[arm_qposadr] = q_new
        mujoco.mj_forward(model, data_scratch)

    return data_scratch.qpos[arm_qposadr].copy(), False
```

**用法**:

```python
# 在 CartesianController 里

    mapping.left.qpos_adr, mapping.left.dof_adr,
```

## 七、Scripted Expert 状态机

`s622_mujoco/experts/scripted_pick.py`:

```python
class ScriptedPickExpert:
    """Privileged-state expert for pick task.
    
    使用 cube_pos + cube_quat 直接计算目标, 加入噪声保证数据多样性.
    输出 action_mode='joint_target' 的 14 维动作.
    """
    STATES = ["INIT", "APROACH", "PRE_GRASP", "DESCEND",
              "CLOSE", "LIFT", "DONE", "FAILED"]

    def __init__(self, env, cfg):
        self.env = env
        self.cfg = cfg
        self.state = "INIT"
        self.t_in_state = 0
        # 每episode 随机化的策略级参数
        self.approach_height = 0.15 + np.random.uniform(-0.02, 0.02)
        self.overshoot_prob = 0.15   # 15% episode 加入 overshoot 与 recovery
        self.approach_noise_std = 0.005  # xy 加高斯扰动

    def reset(self, obs, privileged):
        self.state = "APROACH"
        self.t_in_state = 0
        self.overshoot_done = False

    def step(self, obs, privileged) -> np.ndarray:
        """返回 14 维 joint_target action."""
        cube_pos = privileged.cube_pos          # (3,) world
        cube_yaw = quat_to_yaw(privileged.cube_quat)
        left_ee = obs.ee_pose[0:3]
        left_grip = obs.qpos[6]

        # ---- 状态转移 ----
        if self.state == "APPROACH":
            target_ee = cube_pos + [0, 0, self.approach_height]
            target_ee[0:2] += np.random.normal(0, self.approach_noise_std, 2)
            if (not self.overshoot_done
                    and np.random.rand() < self.overshoot_prob
                    and self.t_in_state == 5):
                # 故意超调, 后面自动修正
                target_ee[0:2] += np.array([0.03, 0.0])
                self.overshot_done = True
            if np.linalg.norm(left_ee - target_ee) < 0.01:
                self.state = "PRE_GRASP"; self.t_in_state = 0
            action = self._go_to_ee_pose(
                target_ee, cube_yaw, griper=1.0, arm="left")

        elif self.state == "PRE_GRASP":
            target_ee = cube_pos + [0, 0, 0.05]
            if np.linalg.norm(left_ee - target_ee) < 0.005:
                self.state = "DESCEND"; self.t_in_state = 0
            action = self._go_to_ee_pose(
                target_ee, cube_yaw, gripper=1.0, arm="left")

        elif self.state == "DESCEND":
            target_ee = cube_pos + [0, 0, 0.005]
            if np.linalg.norm(left_ee - target_ee) < 0.003:
                self.state = "CLOSE"; self.t_in_state = 0
            action = self._go_to_ee_pose(
                target_ee, cube_yaw, gripper=1.0, arm="left")

        elif self.state == "CLOSE":
            # 保持 ee pose, 关爪
            if self.t_in_state > 15:   # 15 steps @ 50Hz = 0.3s
                self.state = "LIFT"; self.t_in_state = 0
            action = self._hold_ee(gripper=0.0, arm="left")

        elif self.state == "LIFT":
            target_ee = cube_pos + [0, 0, 0.20]
            if left_ee[2] > cube_pos[2] + 0.15:
                self.state = "DONE"; self.t_in_state = 0
            action = self._go_to_ee_pose(
                target_ee, cube_yaw, gripper=0.0, arm="left")

        elif self.state == "DONE":
            action = self._hold_ee(griper=0.0, arm="left")

        self.t_in_state += 1
        return action

    def _go_to_ee_pose(self, target_pos, target_yaw, gripper, arm):
        """内部走一步 IK, 返回 14 维 joint_target.""
        target_quat = yaw_to_quat_grasp_down(target_yaw)  # z轴朝下
        q_left, ok = self.env.ik(arm="left",
                                  target_pos=target_pos,
                                  target_quat=target_quat)
        if not ok:
            self.state = "FAILED"
            return self._hold_ee(gripper=0.0, arm="left")
        # 右臂: 固定 dual_home 关节
        q_right = self.env.dual_home_right_joints
        return np.concatenate([q_left, [gripper], q_right, [1.0]])

    def is_success(self, obs, privileged) -> bool:
        return self.state == "DONE" and privileged.cube_pos[2] > 0.08
```

**关键**:

* 专家有 privileged access,但**数据集只保存 non-privileged 部分**给策略学
* 加入受控噪声 + overshoot,让数据里有"错了如何修"的样本
* 记录 `/action`(实际执行,含噪声)和 `/action_planned`(状态机内部规划)两份

## 九、执行模式:Chunk / Receding / Temporal Aggregation

**严格区分**三种模式:

### Mode 1: Chunk Execution

```
t=0:   predict → chunk[0..99]
t=0..99: execute chunk sequentially
t=100: predict → chunk[100..199]
```

* 简单,推理次数少
* 缺点:100 步(2s)不看新 obs,cube 移位则失败
* 用途: M3.3 baseline 快速评估

### Mode 2: Receding Horizon

```
t=0:   predict → chunk (K=100)
t=0..M-1: execute first M steps (M=25)
t=M:   predict → new chunk
```

* 有视觉闭环,但相邻 chunk 之间可能不连续
* M/K 比例常见 25/100 = 25% 覆盖
* 用途: M3.4/M3.5 主力模式

### Mode 3: Temporal Aggregation (ACT 原论文)

```
每个控制 step 都重新预测:
t=0:   predict → chunk_0[t=0..99]
t=1:   predict → chunk_1[t=1..100]
...
t=k:   预测 chunk_k[t=k..k+99]
每个时刻 t 的执行动作 = 加权平均所有覆盖 t 的历史 chunk:
  a_t = Σ_i w_i * chunk_{t-i}[i]     for i in [0, K-1]
  w_i = exp(-c * i),  c=0.01
```

* 平滑,鲁棒
* 缺点:每个控制 step 都推理,推理频率必须 ≥ 控制频率

### 频率设计

| 层                          | 频率            | 备注                           |
| --------------------------- | --------------- |
| MuJoCo 物理仿真             | 500 Hz (dt=2ms) | 由 MJCF 决定                   |
| 控制循环 (env.step)         | 50 Hz           | 每 10 个物理 step 一次         |
| 数据记录                    | 50 Hz           | 与控制一致                     |
| Policy 训练时 label频率     | 50 Hz           | ACT chunk 内 K=100 = 2s        |
| Policy 推理 (Chunk mode)    | 0.5 Hz          | 每 100 步一次                  |
| Policy 推理 (Receding M=25) | 2 Hz            | 每 25 步一次                   |
| Policy 推理 (Temp Agg)      | 50 Hz           | 每步一次,GPU 必须够快          |
| Control lop → Servo         | 50-100 Hz       | 独立于推理,由 action buffer 填 |

**实测再调**:M3.5 部署时用 `time.perf_counter` 测单次推理,决定实际能跑哪种模式。

### Action Buffer 设计

```python
class ActionBuffer:
    """线程安全 buffer, 生产者(policy)与消费者(control loop)解耦.""
    def __init__(self, max_size=200, dim=14):
        self.buf = deque(maxlen=max_size)
        self.lock = threading.Lock()
        self.last_predict_t = 0

    def push_chunk(self, chunk: np.ndarray, t_predict: int):
        """Receding/ag 时调用.""
        with self.lock:
            if MODE == "receding":
                self.buf.clear()
                for a in chunk[:M_EXECUTE]:
                    self.buf.append(a)
            elif MODE == "temporal_agg":
                # 加入 ensemble history, pop 时才聚合
                self.history.append((t_predict, chunk))

    def pop(self, t_current: int) -> np.ndarray:
        """由 control loop 调用.""
        with self.lock:
            if MODE == "temporal_agg":
                return self._aggregate(t_current)
            if len(self.buf) == 0:
                return None  # 无 action, watchdog 处理
            return self.buf.popleft()
```

## 十、MoveIt Servo 桥

**核心约定**(Humble 版):

* 消息类型:

  * Cartesian: `geometry_msgs/TwistStamped` → `~/delta_twist_cmds`
  * Joint: `control_msgs/JointJog` → `~/delta_joint_cmds`
* **Servo 期望速度/位移增量,不是绝对目标**
* `header.stamp` 必须近似当前时间(Servo 有 timeout 参数)
* `header.frame_id` 对 Twist 必须匹配 Servo config `planning_frame`

### 从 Policy Action 到 Servo 命令

**Mode A joint_target policy** → JointJog:

```python
# 每个控制 step:
def joint_target_to_jog(q_target, q_current, dt, joint_names):
    """把绝对目标转成 velocity JointJog."""
    dq = q_target - q_current    # (6,)
    v  = dq / dt                 # (6,) rad/s
    # clip 到 Servo 允许速度
    v = np.clip(v, -MAX_V, MAX_V)
    jog = JointJog()
    jog.header.stamp = clock.now().to_msg()
    jog.header.frame_id = ""     # JointJog 不用 frame
    jog.joint_names = joint_names
    jog.velocities = v.tolist()
    jog.duration = dt
    return jog
```

**Mode B cartesian_delta policy** → TwistStamped:

```python
def cart_delta_to_twist(delta, dt, planing_frame):
    """delta = [dx dy dz drx dry drz] in base frame."""
    v = delta / dt   # linear+angular velocities
    twist = TwistStamped()
    twist.header.stamp = clock.now().to_msg()
    twist.header.frame_id = planing_frame     # e.g. "left_base_link"
    twist.linear.x  = v[0]
    twist.twist.linear.y  = v[1]
    twist.twist.linear.z  = v[2]
    twist.twist.angular.x = v[3]
    twist.twist.angular.y = v[4]
    twist.angular.z = v[5]
    return twist
```

## 十一、BimanualCommandCoordinator

**动机**: 两个独立 Servo 节点各自 rate/latency 不同,双臂关键任务(handover)必须同步。

**设计**:

```
┌─────────────────────────────────────────────────┐
│           BimanualCommandCoordinator (ROS2 node)         │
│                                                          │
│  订阅:                                    │
│    /learned_policy/action_chunk  (自定义 msg)             │
│    /left/joint_states, /right/joint_states                │
│    /planning_scene                        │
│    /safety_events (from safety_monitor)                   │
│                                                          │
│  内部:                                                    │
│    ActionBuffer                                          │
│    interpolator (线性 or 三次样条, 补齐控制频率)          │
│    watchdog timer                                         │
│    per-arm state machine (READY / EXECUTING / STOPPED)   │
│                                                          │
│  发布:                                                    │
│    /left/servo_node/delta_twist_cmds  同一 stamp          │
│    /right/servo_node/delta_twist_cmds 同一 stamp          │
│    /left/set_gripper (service call)                       │
│    /right/set_gripper                     │
│    /cordinator/status                                    │
└─────────────────────────────┘
```

**同步保证**:

1. 每个 control tick,取当前 t 的双臂 action(从 buffer),用**同一个 header.stamp** 发左右 twist
2. 任一臂收到 safety event → 立即两臂发 zero twist,状态转 STOPPED
3. Gripper 命令去重:上次状态和目标状态相同则不发 service call
4. Watchdog: 若 action buffer 空超过 100ms → 两臂 zero twist stop
5. **规划场景共享**:两个 Servo 在同一个 move_group 下配置,PlanningScene 由 move_group 全局单例发布,已经保证

**接口 msg**:

```
# BimanualCommand.msg
Header header
string action_mode              # "cartesian_delta" | "joint_target" | "joint_delta"
float64[7] left_action          # dim depends on mode; here 3+3+1 for cart, 6+1 for joint
float64[7] right_action
float64 dt                      # 该 action 覆盖的时间跨度 (s)
uint32 chunk_step_idx
uint32 chunk_total_steps
```

**Cordinator 内部循环** (伪代码):

```python
def control_tick(self):
    now = self.get_clock().now()
    action = self.buffer.pop(now)
    if action is None:

        right_twist = self._cart_to_twist(action.right, action.dt, "right_base_link")
        left_twist.header.stamp  = stamp
        right_twist.header.stamp = stamp
        self.left_twist_pub.publish(left_twist)
        self.right_twist_pub.publish(right_twist)
    elif action.mode == "joint_target":
        # 转 JointJog velocity
        ...

    # 处理 gripper
    if abs(action.left[-1] - self.last_grip_l) > 0.1:
        self._call_gripper("left", action.left[-1])
        self.last_grip_l = action.left[-1]
    # 同 right
```

### 固定 Rollout Seed 集

### Rollout Runer

```python
def run_rollouts(policy, env, seeds, max_steps=1000) -> RoloutReport:
    results = []
    for seed in seeds:
        obs = env.reset(seed=seed)
        priv = env.get_privileged()
        cube_init = priv.cube_pos.copy()
        buf = ActionBuffer()
        for t in range(max_steps):
            action = buf.pop() or policy.predict(obs)
            obs, _, done, info = env.step(action)
            if done: break
        priv_end = env.get_privileged()
        results.append(RolloutResult(
            seed=sed,
            success=classify_success(priv_end, obs),
            failure_mode=classify_failure(priv_end, obs, info) if not success else None,
            duration_s=t * env.dt,
            cube_init_pos=cube_init,
            cube_final_pos=priv_end.cube_pos,
        ))
    return RolloutReport(results)
```

### Failure Taxonomy

```python
class FailureMode(Enum):
    MIS_APROACH  = "miss_approach"       # EE 从未接近 cube
    OVERSHOOT      = "overshoot"           # 撞掉 cube
    GRASP_MISS     = "grasp_miss"          # 爪合上但 cube 没进指间
    GRASP_SLIP     = "grasp_slip"          # 抓到但 lift 时掉
    LIFT_TIMEOUT   = "lift_timeout"        # 没提到目标高度
    COLLISION      = "collision"           # 撞桌 or self-collision
    IK_FAILURE     = "ik_failure"          # DLS 不收敛
    SAFETY_STOP    = "safety_stop"         # Servo/cordinator emergency stop
    UNKNOWN        = "unknown"
```

Classifier 用 privileged info + trajectory 后处理判定。

### 常见故障排查

| 症状                       | 检查项                    | 修复                                           |
| -------------------------- | ------------------------- | ---------------------------------------------- |
| Train loss 高但收敛        | action stats 是否合理     | 重算 stats,检查异常值                          |
| Val loss >2x Train loss    | 数据太少或多样性不足      | 增采,加 randomization                          |
| Rollout 全 fail success 0% | obs shape / dtype 是否对  | 单元测 policy 输入 pipeline                    |
| Grasp miss 集中于某区域    | 该区域数据密度            | 补采,或调 expert 覆盖                          |
| Cart delta 累积漂移        | Receding M 太大           | 降低 M,或加入 temp ag                          |
| Gazebo sim2sim gap 大      | 物理参数不一致            | 调 gripper contact,cube 摩擦                   |
| Servo 报奇异区             | Policy 想去奇异 pose      | 训练数据加入奇异区 recovery,或 IK 加大 damping |
| 两臂时间差                 | Coordinator watchdog 触发 | 检查 coordinator timing log                    |

## 十四、从 ACT 扩展到 DP / VLA 的接口

**统一 Policy 接口**:

```python
class Policy(abc.ABC):
    @abc.abstractmethod
    def load(self, ckpt_path: str, stats: dict): ...

    @abc.abstractmethod
    def predict(self,
                obs: Observation,
                language: Optional[str] = None,
                task_id: Optional[int]  = None) -> np.ndarray:
        """Returns action chunk (K, 14)."""

    @abc.abstractmethod
    def get_config(self) -> PolicyConfig: ...


class ACTPolicy(Policy): ...        # ACT
class DiffusionPolicy(Policy): ...  # DP, drop-in replacement
class RDTPolicy(Policy): ...        # RDT-1B, uses language
class OpenPIPolicy(Policy): ...     # π0
```

Cordinator 和 BT 只依赖抽象接口,切换模型不改 ROS 代码。

**Dataset 前向兼容**:

* 数据格式已含 `language_instruction, task_id`(即使 ACT 忽略)
* LeRobot Dataset 是 DP/RDT 官方支持格式,不用重转
* VLA 需要额外元数据(camera intrinsics,base transform)时,加字段不破坏旧策略
