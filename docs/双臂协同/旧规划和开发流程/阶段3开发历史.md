URDF rpy 在 MuJoCo 里被反向理解

URDF 的 mount_joint:
```xml
<!-- 左: yaw=π 让臂朝 -x -->
<origin xyz="0.35 0 0" rpy="0 0 3.14159" />

<!-- 右: yaw=0 让臂朝 +x -->
<origin xyz="-0.35 0 0" rpy="0 0 0" />
```

MuJoCo 加载后:

左臂 yaw=π → 臂实际朝 +x(应该 -x),差 180°

右臂 yaw=0 → 臂实际朝 -x(应该 +x),也差 180°

结论: MuJoCo URDF loader 对 yaw 符号或旋转方向的约定与 URDF/Gazebo 相反。
