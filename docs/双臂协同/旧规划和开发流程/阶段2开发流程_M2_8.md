## M2.8.1: Handover 位姿几何设计

### 关键决策 A: 谁 pick,谁 place

M2.7 里 cube spawn 在 world **(0.15, 0, 0.05)** → 更靠**左臂**工作区。

**约定 M2.8**: 左臂 pick,右臂 place。左 → 右 交接。M2.7.5 里跑通右臂 pick 的场景我们最后再考虑镜像。

### 关键决策 B: Handover 位姿的形式

有 3 种候选:

**候选 1: 面对面水平伸出(垂直抓取 → 水平交接)**

* 左臂从上方 pick 后翻转 90°,让 grasp_frame 水平指向 world +y(对面手方向)
* 右臂 grasp_frame 水平指向 world -y(对面手方向)
* Cube 在中间被左夹爪握住(垂直方向),右夹爪从水平方向合拢抓 cube 侧面
* **两个 grasp z 轴相反**,cube 有两组夹持面被同时抓
* 优点:符合真实交接物理,cube 稳定
* 缺点:抓取姿态 90° 旋转,需要 wrist joint 转动大

**候选 2: 上下对峙(同向抓取)**

* 左臂托着 cube(grasp_frame z 轴向下 = pick 后的姿态)
* 右臂从**侧面**接近,水平抓 cube
* 左开右关
* **两个 grasp z 轴垂直**
* 优点:左臂不需要额外翻转
* 缺点:交接瞬间只有右夹爪咬合 cube 侧面,不太稳

**候选 3: 简化托举(不同时夹持)**

* 左臂 pick 后到达 handover 位,cube 悬在中间
* 左臂**先开手**放开 cube(短暂下落)
* 右臂**立即** attach + close 抓住 cube
* 这实际上不算真正的双臂交接,而是"抛接"
* 优点:实现最简单
* 缺点:cube 会短暂下落,不可靠;不算严格意义 handover

**推荐候选 1**——最像真实机器人手臂交接。中等复杂度,cube 全程受夹持,可视化清晰。

### 关键决策 C: 位姿具体空间点

初步建议(world 系):

* Handover 位置: **world (0, 0, 0.35)** — 桌面上方 35cm,双臂 base 正中间
* 左臂 grasp_frame:

  * 位置: world (0, -0.02, 0.35) — 稍往右偏,给右夹爪留空间
  * 姿态: z 轴指向 world +y = 面向右臂
* 右臂 grasp_frame:

  * 位置: world (0, +0.02, 0.35)
  * 姿态: z 轴指向 world -y = 面向左臂

在各自 base 系里(需要坐标变换,后面 teach 时会用 TF 直接读出),先不算数值。

## M2.8.1 请你做的事

**目标**: sim 里手动摆出 handover 姿态,读出 12 个 joint values。

### 步骤

1. **启动双臂 sim**:

   ```bash
   pkill -f "ros2 launch"
   ros2 launch gz_launch s622_dual_arm.launch.py
   # 等 30s
   ```

2. **RViz Motion Planning 面板**:

   * Planning Group 下拉选 **`dual_arm`**
   * 应该能看到两个交互 marker(左右各一个 EE)
   * **左臂 marker**: 拖到 world (0, -0.02, 0.35) 附近,z 轴调成指向 +y(可以先大致,不用完美)
   * **右臂 marker**: 拖到 world (0, +0.02, 0.35) 附近,z 轴调成指向 -y
   * 或者直接用 "Query Goal State" → 手动调 joint sliders
   * 目标:两只手掌面**面对面**,中间留 4cm 缝隙

3. **看看是否碰撞**:

   * RViz 里若 marker 变红说明 self-collision,微调直到全绿
   * "Plan" 试试能否从 dual_home 规划过去
   * 能规划成功就说明位姿有效

4. **读出 12 个 joint values**:
   在 RViz Motion Planning **Joints** tab 里,或者:

   ```bash
   # 摆到位后, 直接读 /joint_states
   ros2 topic echo /joint_states --once
   ```

   把 left_j1..j6 和 right_j1..j6 的 12 个值贴给我。
