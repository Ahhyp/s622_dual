## 2. M1.7.0：Baseline 采集（30min）

### 2.1 目的

### 2.2 修改点

`bt_executor_node.cpp` 里，在每个 MoveToPose / VisualAlign 完成后，把节点名和耗时写到一个文件 `/tmp/m17_baseline.log`。或者更简单：直接 grep 现有日志。

后者更简单，写个 python 脚本：

```python
# scripts/parse_bt_log.py
import re, sys
from datetime import datetime

# 匹配 [1782804710.055] 时间戳的日志行
TS_RE = re.compile(r'\[bt_executor_node-1\] \[INFO\] \[(\d+\.\d+)\] \[bt_executor\]: (.+)')

def parse(log_path):
    events = []
    with open(log_path) as f:
        for line in f:
            m = TS_RE.match(line)
            if not m:
                continue
            ts = float(m.group(1))
            msg = m.group(2)
            events.append((ts, msg))
    
    # 提取每个 phase
    phases = []
    current_phase = None
    phase_start = None
    for ts, msg in events:
        if 'sending goal' in msg or 'VisualAlign[' in msg:
            if current_phase is not None:
                phases.append((current_phase, phase_start, ts))
            current_phase = msg[:60]
            phase_start = ts
        elif 'SUCCESS' in msg or 'FAILED' in msg:
            if current_phase is not None:
                phases.append((current_phase, phase_start, ts))
                current_phase = None
    
    for name, start, end in phases:
        print(f'{end-start:6.2f}s  {name}')

if __name__ == '__main__':
    parse(sys.argv[1])
```

### 3.2 判断误差模式

看 5 个点误差的规律：

| Pattern       | 判断依据                           | 根因                              | 修法                           |
| ------------- | ---------------------------------- | --------------------------------- | ------------------------------ |
| **常数偏移**  | 5 个点 Δx 都 ≈ -11mm，Δy 都 ≈ +2mm | 相机 TF 有 rigid 偏移             | 改 URDF 相机 pose 或加常数补偿 |
| **径向缩放**  | 距相机远的点误差大，近的误差小     | fx/fy 或 depth 错误               | 校准 intrinsics                |
| **随机 ±3mm** | 各方向误差无规律                   | YOLO 检测抖动                     | 多帧平均                       |
| **系统旋转**  | Δx/Δy 呈线性相关                   | camera_optical_frame 有 roll 偏差 | 改 URDF 旋转                   |

### 3.3 修复分两种做法

#### 做法 A：治本（改 URDF / camera_info）

先看两个源：

```bash
# 1. 相机 topic 上的 intrinsics
ros2 topic echo /camera/color/camera_info --once | head -30

# 2. URDF/SDF 里的相机 pose
grep -B 2 -A 10 "camera" /path/to/your/urdf.xacro
```

对比 `arm_config.yaml` 的 `fx=465.6, fy=625.2, cx=320, cy=240` 是不是和 camera_info 一致。**如果 fx/fy 不一致，直接改 arm_config.yaml**。

如果 TF 有偏移，改 URDF 相机 `<origin xyz="..." rpy="..."/>`。

时间：1-2h（含 gazebo 重启验证）。

#### 做法 B：empirical 校准（快速）

在 `arm_config.yaml` 加：

```yaml
yolo_projection_correction:
  # 常数偏移 (M1.7.1 测出来的)
  offset_x: 0.011
  offset_y: -0.002
  # 径向缩放 (可选)
  radial_scale: 1.0
```

`grasp_nodes.cpp` 的 `GenerateGraspCandidate::tick` 末尾：

```cpp
// 反投影后应用校准
double corr_x = node_->get_parameter("yolo_projection_correction.offset_x").as_double();
double corr_y = node_->get_parameter("yolo_projection_correction.offset_y").as_double();
double radial = node_->get_parameter("yolo_projection_correction.radial_scale").as_double();

if (radial != 1.0) {
    double cx = camera_xy_[0], cy = camera_xy_[1];
    double dx = grasp_x - cx, dy = grasp_y - cy;
    grasp_x = cx + dx * radial;
    grasp_y = cy + dy * radial;
}
grasp_x += corr_x;
grasp_y += corr_y;
```

时间：30 分钟。

## 4. M1.7.2：规划耗时优化（2h）

### 4.1 目标

M1.7.0 baseline 应该显示两个瓶颈：

* MoveToPose 单段 30-60s
* VisualAlign xy 15-25s

分别攻。

### 4.2 MoveToPose 减速根因

从 M1.6 的日志看，MoveToPose 慢是因为 `plan_to_pose_smart` 依次尝试 top-8 IK 解，前几个都失败才成功。每次失败要花 `allowed_planning_time=5s`，前 3 个失败就是 15s。

**优化 1**：把 IK 评分改成"预筛"，用 collision-free check 提前砍掉肯定不通的解：

```python
def _prefilter_solutions(self, solutions, current):
    """筛掉离当前太远（>π）的解, 减少无效尝试。"""
    filtered = []
    for sol in solutions:
        max_delta = max(abs(a - b) for a, b in zip(sol, current))
        if max_delta > math.pi:   # 有关节超过 π 就跳过
            continue
        filtered.append(sol)
    return filtered
```

**优化 2**：`allowed_planning_time` 从 5s 降到 2s，`num_planning_attempts` 从 10 降到 3。IK 已经给了好解，OMPL 不该找那么久。

**优化 3**：`max_candidates` 从 8 降到 3。前 3 个解基本涵盖所有合理选择。

```python
def plan_to_pose_smart(self, position, quat_xyzw,
                      planner_id=None,
                      max_candidates=3,      # 8 -> 3
                      cartesian=False):
    ...
```

`moveit2.allowed_planning_time = 2.0` 在 `__init__` 里。

### 4.3 VisualAlign xy 减速根因

看 M1.6 日志，align_xy 15-30s 走 3cm（pregrasp offset）。速度只有 1-2mm/s，远低于 `xy_max_speed=0.05m/s`。

原因是 kp=1.0 太保守：

```python
vx = kp * dx  # dx=0.03m 时 vx=0.03 m/s,再被 max_speed=0.05 限住
```

**优化**：`arm_config.yaml`：

```yaml
xy_kp: 3.0            # 1.0 -> 3.0
xy_max_speed: 0.08    # 0.05 -> 0.08
xy_min_pixel_err_to_move: 2.0  # 保持
```

理论时间：dx=0.03m 时 vx=0.09 → 被限到 0.08 m/s → 0.03/0.08 = 0.4s 走完。收敛加减速考虑进去，5s 内应能到 tol=2mm。

**收敛判据**：现在 `stable >= 5` 是 5 帧稳定 = 5/30 = 0.17s，其实 OK。不用改。

## 5. M1.7.3：Recovery 子树 + failure_node 记录（2h）

### 5.1 Blackboard key 约定

```
last_failure_node : string    # 上次失败的 BT 节点名
last_failure_msg  : string    # 失败原因
is_grasped        : bool      # VerifyGrasp 结果
is_attached       : bool      # AttachObject 后置 true, DetachObject 后置 false
```

### 5.2 让 BT 节点写入 failure 信息

BT.CPP v4 用 `TreeObserver`：

```cpp
// bt_executor_node.cpp
#include <behaviortree_cpp/loggers/bt_observer.h>

// tree 加载后
BT::TreeObserver observer(tree);

// tick 循环里
auto status = tree.tickWhileRunning();

if (status == BT::NodeStatus::FAILURE) {
    // 遍历 observer 找最后一个 FAILURE 节点
    std::string failed_node = "unknown";
    for (const auto& [uid, stats] : observer.statistics()) {
        if (stats.last_result == BT::NodeStatus::FAILURE &&
            !stats.transitions_count == 0) {
            failed_node = observer.getFullPath(uid);
        }
    }
    // 写到 blackboard 给 Recovery 用
    tree.rootBlackboard()->set("last_failure_node", failed_node);
    RCLCPP_ERROR(node->get_logger(),
                 "BT FAILURE at node: %s", failed_node.c_str());
}
```

### 5.3 Recovery 子树

新增文件 `pick_place_with_recovery_tree.xml`：

```xml
<root BTCPP_format="4">
  <BehaviorTree ID="PickPlaceWithRecovery">
    <Fallback name="MainWithRecovery">

      <!-- ============ 主任务 (M1.6 全流程) ============ -->
      <Sequence name="MainTask">
        <!-- 直接 include 或复制 M1.6.4 树的全部内容 -->
        <!-- ...省略,和 pick_place_full_tree.xml 一致... -->
      </Sequence>

      <!-- ============ Recovery ============ -->
      <Sequence name="Recovery">
        <PrintMessage message="=== ENTERING RECOVERY ==="/>

        <!-- 1. 立即停止 servo (强制,幂等) -->
        <StopServo/>

        <!-- 2. 松开夹爪 -->
        <ForceSuccess>
          <SetGripper command="open" timeout_sec="3.0"/>
        </ForceSuccess>

        <!-- 3. 如果之前 attach 过, detach; ForceSuccess 让 detach 失败也不阻塞 -->
        <ForceSuccess>
          <DetachObject object_name="cube"
                        put_back_in_world="false"
                        timeout_sec="3.0"/>
        </ForceSuccess>

        <!-- 4. 尝试回 safe pose (可能失败, 用 ForceSuccess) -->
        <ForceSuccess>
          <MoveToPose named_pose="safe"
                      velocity_scale="0.2" acceleration_scale="0.2"
                      timeout_sec="15.0"
                      ensure_servo_stopped="true"/>
        </ForceSuccess>

        <!-- 5. 再回 home -->
        <ForceSuccess>
          <MoveToPose named_pose="home"
                      velocity_scale="0.2" acceleration_scale="0.2"
                      timeout_sec="15.0"
                      ensure_servo_stopped="true"/>
        </ForceSuccess>

        <PrintMessage message="=== RECOVERY DONE ==="/>

        <!-- 让整个 Fallback 返回 FAILURE, 外层能知道任务失败 -->
        <AlwaysFailure/>
      </Sequence>

    </Fallback>
  </BehaviorTree>
</root>
```

**关键设计**：Recovery 子树的每个步骤都用 `ForceSuccess` 包起来，避免 Recovery 自己失败卡住。安全动作宁可跳过也不阻塞。

### 6.2 实现方案

BT 外部 python 脚本抓 log。已经在 M1.7.0 写了 `parse_bt_log.py`，扩展它：

```python
# scripts/collect_trials.py
import re, csv, sys, os
from datetime import datetime

TS_RE = re.compile(r'\[(\d+\.\d+)\] \[bt_executor\]: (.+)')

def parse_trial(log_path, trial_id):
    events = []
    with open(log_path) as f:
        for line in f:
            m = TS_RE.search(line)
            if m:
                events.append((float(m.group(1)), m.group(2)))
    
    if not events:
        return None
    
    row = {
        'trial_id': trial_id,
        'timestamp': datetime.fromtimestamp(events[0][0]).isoformat(),
        'total_time': events[-1][0] - events[0][0],
        'detect_ok': False,
        'grasp_ok': False,
        'attach_ok': False,
        'place_ok': False,
        'failure_node': '',
        'error_msg': '',
    }
    
    for ts, msg in events:
        if 'DetectObject' in msg and 'conf=' in msg:
            row['detect_ok'] = True
        elif 'VerifyGrasp: GRASPED' in msg:
            row['grasp_ok'] = True
        elif 'attached cube' in msg or 'AttachObject: SUCCESS' in msg:
            row['attach_ok'] = True
        elif 'detached cube' in msg or 'DetachObject: SUCCESS' in msg:
            row['place_ok'] = True
        elif 'BT FAILURE at node:' in msg:
            row['failure_node'] = msg.split('BT FAILURE at node:')[1].strip()
        elif 'ENTERING RECOVERY' in msg and not row['failure_node']:
            # Recovery 触发但没记 failure_node,标为 unknown
            row['failure_node'] = 'unknown'
    
    return row


def main(log_dir, output_csv):
    rows = []
    for i, fname in enumerate(sorted(os.listdir(log_dir))):
        if not fname.startswith('trial_'):
            continue
        path = os.path.join(log_dir, fname)
        row = parse_trial(path, i + 1)
        if row:
            rows.append(row)
    
    with open(output_csv, 'w', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=[
            'trial_id', 'timestamp', 'total_time',
            'detect_ok', 'grasp_ok', 'attach_ok', 'place_ok',
            'failure_node', 'error_msg'
        ])
        writer.writeheader()
        writer.writerows(rows)
    
    # 打印统计
    n = len(rows)
    if n == 0:
        print('no trials')
        return
    all_ok = sum(1 for r in rows
                 if r['detect_ok'] and r['grasp_ok']
                 and r['attach_ok'] and r['place_ok'])
    grasp_ok = sum(1 for r in rows if r['grasp_ok'])
    print(f'Total trials: {n}')
    print(f'End-to-end success: {all_ok}/{n} = {all_ok/n*100:.0f}%')
    print(f'Grasp success: {grasp_ok}/{n} = {grasp_ok/n*100:.0f}%')
    print(f'Avg time: {sum(r["total_time"] for r in rows)/n:.1f}s')


if __name__ == '__main__':
    main(sys.argv[1], sys.argv[2])
```

```bash
    sleep 2
done

echo "===== ALL TRIALS DONE ====="
python3 scripts/collect_trials.py $LOG_DIR experiments/results/phase1_pick_place_trials.csv
```
