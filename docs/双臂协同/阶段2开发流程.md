## 2. M2.1：Xacro 参数化（3-4h）

### 2.1 修改策略

`s622_moveit_descriptions.urdf` 是 URDF 不是 xacro（从你的描述看），但入口是 `robot_gazebo.urdf.xacro`。**先要确认**：

```bash
head -30 ~/my_S622/src/s622_moveit_descriptions/urdf/s622_moveit_descriptions.urdf
```

如果是 `<robot>` 开头没有 `xmlns:xacro`，就是纯 URDF。需要**先转成 xacro**（30 分钟工作）：

* 改扩展名为 `.urdf.xacro`
* 顶部加 `<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="s622">`
* 用 `<xacro:property name="prefix" default=""/>` 引入参数
* 所有 `link name="link1"` → `link name="${prefix}link1"`
* 所有 joint 的 `parent`, `child`, `<axis>` 等引用都要前缀

### 2.2 参数化改造

`s622_moveit_descriptions.urdf.xacro`（转成 xacro 后）：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="s622">
  <!-- 声明参数,默认空前缀保持向后兼容 -->
  <xacro:arg name="prefix" default=""/>
  <xacro:property name="prefix" value="$(arg prefix)"/>
  
  <link name="${prefix}base_link">
    <!-- ...原有内容... -->
  </link>
  
  <joint name="${prefix}j1" type="revolute">
    <parent link="${prefix}base_link"/>
    <child link="${prefix}shoulder_link"/>
    <!-- ... -->
  </joint>
  
  <!-- 其他所有 link/joint 都加 ${prefix} -->
</robot>
```

**Ros2_control 部分**（如果在同一个 xacro 里）：

```xml
<ros2_control name="${prefix}s622_hardware" type="system">
  <hardware>
    <plugin>gz_ros2_control/GazeboSimSystem</plugin>
  </hardware>
  <joint name="${prefix}j1">
    <command_interface name="velocity"/>
    <state_interface name="position"/>
    <state_interface name="velocity"/>
  </joint>
  <!-- ... -->
</ros2_control>
```

**Gazebo plugin** 传参数文件路径也要用前缀化的（M2.2 里会给出）。

### 2.3 顶层 `robot_gazebo.urdf.xacro`

改成：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="$(arg robot_name)">
  <xacro:arg name="prefix" default=""/>
  <xacro:arg name="robot_name" default="s622"/>
  <xacro:arg name="include_camera" default="true"/>
  <xacro:arg name="controllers_yaml" 
             default="$(find s622_moveit_config)/config/ros2_controllers.yaml"/>

  <!-- 引入本体 -->
  <xacro:include filename="$(find s622_moveit_descriptions)/urdf/s622_moveit_descriptions.urdf.xacro"/>

  <!-- 相机可选(双臂共享相机,只在其中一臂或独立描述里加) -->
  <xacro:if value="$(arg include_camera)">
    <xacro:include filename="$(find s622_moveit_descriptions)/urdf/camera.xacro"/>
  </xacro:if>

  <!-- Gazebo plugin 挂载 -->
  <xacro:include filename="$(find s622_moveit_descriptions)/urdf/rgbd_split.gazebo.xacro"/>
</robot>
```

### 2.4 相机独立化

**关键决策**：相机现在挂在 `base_link` 上（eye-to-hand，M1.7 的方式）。双臂下如果两臂共用一个相机，相机必须**独立于任一臂**，挂在 world 上。

改造 `camera.xacro`：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro">
  <xacro:arg name="camera_parent" default="base_link"/>
  <xacro:arg name="camera_xyz" default="0.3825 0.4838 1.0"/>
  <xacro:arg name="camera_rpy" default="0 1.5708 0"/>
  
  <link name="camera_link">
    <!-- ... -->
  </link>
  
  <joint name="camera_mount" type="fixed">
    <parent link="$(arg camera_parent)"/>
    <child link="camera_link"/>
    <origin xyz="$(arg camera_xyz)" rpy="$(arg camera_rpy)"/>
  </joint>
  <!-- 其他相机 link (color/depth/optical frames) 保持不变 -->
</robot>
```

**用法**：双臂 launch 里把 camera 单独作为一个 URDF 加载，`parent=world`，或者只让 left 臂的 xacro 包含 camera（另一臂 `include_camera=false`）。**推荐前者**，M2.7 里会展开。

## 4. M2.3：MoveIt 单实例双 group（3-4h）

### 4.1 合并 URDF：`dual_arm.urdf.xacro`

新建 `s622_moveit_config/config/dual_arm.urdf.xacro`：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="dual_s622">
  <!-- world 根节点 -->
  <link name="world"/>
  
  <!-- 桌子 (可选,MoveIt collision 用) -->
  <link name="table_link"/>
  <joint name="world_to_table" type="fixed">
    <parent link="world"/>
    <child link="table_link"/>
    <origin xyz="0 0 -0.015" rpy="0 0 0"/>
  </joint>
  
  <!-- Left arm -->
  <xacro:include filename="$(find s622_moveit_descriptions)/urdf/s622_moveit_descriptions.urdf.xacro">
    <xacro:arg name="prefix" value="left_"/>
  </xacro:include>
  <joint name="world_to_left_base" type="fixed">
    <parent link="world"/>
    <child link="left_base_link"/>
    <origin xyz="0.35 0 0" rpy="0 0 3.14159"/>  <!-- yaw=π -->
  </joint>
  
  <!-- Right arm -->
  <xacro:include filename="$(find s622_moveit_descriptions)/urdf/s622_moveit_descriptions.urdf.xacro">
    <xacro:arg name="prefix" value="right_"/>
  </xacro:include>
  <joint name="world_to_right_base" type="fixed">
    <parent link="world"/>
    <child link="right_base_link"/>
    <origin xyz="-0.35 0 0" rpy="0 0 0"/>

  <xacro:include filename="$(find s622_moveit_descriptions)/urdf/camera.xacro">

```

**注意**：`xacro:include` 传参数需要 xacro 2.0 语法，或者用 xacro namespaces。这里给的是伪代码，具体语法我 M2.3 展开时给准确版本。

### 4.2 SRDF：`dual_arm.srdf`

**关键**：定义 4 个 planning group：

```xml
<?xml version="1.0"?>
<robot name="dual_s622">
  <group name="left_arm">
    <chain base_link="left_base_link" tip_link="left_grasp_frame"/>
  </group>
  <group name="right_arm">
    <chain base_link="right_base_link" tip_link="right_grasp_frame"/>
  </group>
  <group name="left_hand">
    <joint name="left_finger1_joint"/>
    <joint name="left_finger2_joint"/>
  </group>
  <group name="right_hand">
    <joint name="right_finger1_joint"/>
    <joint name="right_finger2_joint"/>
  </group>
  
  <group name="dual_arm">
    <group name="left_arm"/>
    <group name="right_arm"/>
  </group>
  
  <end_effector name="left_hand_ee" parent_link="left_grasp_frame" 
                group="left_hand"/>
  <end_effector name="right_hand_ee" parent_link="right_grasp_frame" 
                group="right_hand"/>
  
  <!-- Disable collisions (仿照 fairino3_v6_moveit2_config 的 srdf) -->
  <!-- 每个 arm 内部的相邻 link 之间 disable -->
  <disable_collisions link1="left_base_link" link2="left_shoulder_link" reason="Adjacent"/>
  <!-- ... 大量类似条目 ... -->
  
  <!-- 两臂之间不 disable! MoveIt 会自动检查两臂之间碰撞 -->
</robot>
```

这个 SRDF 需要生成。用 MoveIt Setup Assistant 是最靠谱的方式（可选，也可以手写）：

* 手写：复制原 fairino3_v6 srdf 两份，一份改 left_ 一份改 right_，合并
* Setup Assistant：`ros2 launch moveit_setup_assistant setup_assistant.launch.py`，加载 dual_arm URDF，自动检测碰撞对

**推荐 Setup Assistant**，1 小时能出准确 SRDF。

## 5. M2.4：双 arm_actions 命名空间化（2h）

### 5.1 现有 arm_actions 的 launch 改造

`s622_arm_actions/launch/arm_actions.launch.py` 加 `arm_prefix` 参数：

```python
def generate_launch_description():
    arm_prefix = LaunchConfiguration('arm_prefix')
    move_group_name = LaunchConfiguration('move_group_name')
    end_effector = LaunchConfiguration('end_effector')
    
    return LaunchDescription([
        DeclareLaunchArgument('arm_prefix', default_value=''),
        DeclareLaunchArgument('move_group_name', default_value='left_arm'),
        DeclareLaunchArgument('end_effector', default_value='left_grasp_frame'),
        
        Node(
            package='s622_arm_actions',
            executable='move_to_pose_server',
            namespace=arm_prefix,   # 'left' or 'right'
            name='move_to_pose_server',
            parameters=[{
                'move_group_name': move_group_name,
                'end_effector': end_effector,
                'base_link': 'world',   # 从 base_link 改到 world
                'joint_names': PythonExpression([...]),  # 前缀化的 joint 名
                # ...
            }],
        ),
        # visual_align_server, gripper_service, servo_lifecycle 类似
        # planning_scene_service 是共享的,不加 namespace,放在最外层 launch
    ])
```

## 3. 步骤 1.2：参数化 link/joint 名（1-1.5h）

### 3.1 半自动 sed 脚本

**已知 link 列表**（根据你提供的信息）：

```

wrist1_link, wrist2_link, wrist3_link, grasp_frame,
```

写一个转换脚本 `~/my_S622/scripts/parameterize_urdf.sh`：

```bash
#!/bin/bash
# 参数化 s622_moveit_descriptions.urdf.xacro
# 用法: parameterize_urdf.sh <input.urdf.xacro>
# 会原地修改文件, 先备份!

set -e
FILE="$1"
[[ -z "$FILE" ]] && { echo "usage: $0 <file>"; exit 1; }

# 备份
cp "$FILE" "$FILE.before_prefix"

# ============ Links ============
LINKS=(base_link shoulder_link upperarm_link forearm_link
       wrist1_link wrist2_link wrist3_link grasp_frame
       finger1_link finger2_link aruco_link)

for L in "${LINKS[@]}"; do
    # link name="X" -> link name="${prefix}X"
    sed -i "s/\(link name=\"\)$L\"/\1\${prefix}$L\"/g" "$FILE"
    # parent link="X" -> parent link="${prefix}X"
    sed -i "s/\(parent link=\"\)$L\"/\1\${prefix}$L\"/g" "$FILE"
    # child link="X" -> child link="${prefix}X"
    sed -i "s/\(child link=\"\)$L\"/\1\${prefix}$L\"/g" "$FILE"
done

# ============ Joints ============
JOINTS=(j1 j2 j3 j4 j5 j6 finger1_joint finger2_joint)

for J in "${JOINTS[@]}"; do
    # joint name="X" -> joint name="${prefix}X"
    sed -i "s/\(joint name=\"\)$J\"/\1\${prefix}$J\"/g" "$FILE"
    # <joint>X</joint> (mimic, safety_controller etc.) 也要
    sed -i "s/<joint>$J</<joint>\${prefix}$J</g" "$FILE"
    # mimic joint="X"
    sed -i "s/\(mimic joint=\"\)$J\"/\1\${prefix}$J\"/g" "$FILE"
done

# ============ ros2_control joint 名 ============
for J in "${JOINTS[@]}"; do
    # <joint name="X"> 在 ros2_control 段
    # 上面已经处理过了(joint name=X 通用)
    :
done

echo "Done. Backup: $FILE.before_prefix"
echo "Diff summary:"
diff --stat "$FILE.before_prefix" "$FILE" || true
```

## 5. 步骤 1.4：相机 xacro 独立化（30 min）

### 5.1 现在的 `camera.xacro` 需要改造两处

假设现状类似：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro">
  <link name="camera_link">...</link>
  <joint name="camera_mount" type="fixed">
    <parent link="base_link"/>      <!-- 硬编码! -->
    <child link="camera_link"/>
    <origin xyz="0.3825 0.4838 1.0" rpy="..."/>   <!-- 硬编码! -->
  </joint>
  <link name="camera_color_frame">...</link>
  <link name="camera_color_optical_frame">...</link>
  ...
</robot>
```

改造为：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro">
  <xacro:arg name="camera_parent" default="base_link"/>
  <xacro:arg name="camera_xyz" default="0.3825 0.4838 1.0"/>
  <xacro:arg name="camera_rpy" default="0 0 0"/>
  <xacro:arg name="camera_name" default="camera"/>
  
  <link name="$(arg camera_name)_link">...</link>
  <joint name="$(arg camera_name)_mount" type="fixed">
    <parent link="$(arg camera_parent)"/>
    <child link="$(arg camera_name)_link"/>
    <origin xyz="$(arg camera_xyz)" rpy="$(arg camera_rpy)"/>
  </joint>
  <link name="$(arg camera_name)_color_frame">...</link>
  <link name="$(arg camera_name)_color_optical_frame">...</link>
  ...
</robot>
```

**注意**：如果 camera topic 名依赖 frame 名（比如 `/camera/color/image_raw`），这里改了会影响 topic。**保持 `camera_name` 默认 `camera` 就行**。
