## 1. 仿真设置

**GT（来自双臂 URDF，无需跑 Gazebo）**：
- `world_T_left_base = (0.35, 0, 0), yaw=π`；`world_T_right_base = (-0.35, 0, 0), yaw=0`
- → `{}^{B_L}T_{B_R}^{GT} = Rz(180°) + t = (0.7, 0, 0)`（纯数学推导，已由单测固化）

**协议模拟**（对应 M2.5 真机流程）：左右臂分别触碰 3D fixture 上的共同物理点，
每臂报出自己在自身基座系下的点坐标 → Kabsch/SVD 刚性对齐恢复 `{}^{B_L}T_{B_R}`。

**噪声模型**：
| 噪声 | 大小 | 性质 |
|---|---|---|
| touch（接触重复性） | 0.5 mm | 每点独立高斯 |
| TCP（probe 标定残差） | 1.0 mm | **每臂系统性**（同臂所有点共享同一偏移） |
| FK（关节-末端误差） | 0.5 mm | 每点独立高斯 |

**采样数**：N = 4/6/10/15/20/30，每个 N 跑 500 trials。

**两种空间覆盖**：
- **WIDE**：铺满交接区 ~0.5m 体积（x∈[-0.3,0.3], y∈[0.05,0.55], z∈[0.02,0.4]）
- **SMALL**：小簇 ~0.1m 立方（交接区中心一小块）

## 3. 关键结论

1. **空间覆盖 >> 点数（验证了 M2 规划的核心假设）**：
   - SMALL 即使 N=30 也只有 9.5mm（默认噪声），而 WIDE 在 N=10 就到 4.96mm。
   - 差 ~2-4 倍。真机必须铺满交接区，别在局部密集采样。

2. **系统性 TCP 误差给精度封顶，加 N 也没用**：
   - 默认噪声（含 1mm 系统性 TCP）WIDE 曲线从 N=10 到 N=30 几乎不动（4.96→4.33mm）。
   - 无 TCP 时 WIDE 能随 N 持续下降（3.38→1.73mm）。
   - → **真机 M2.5 第一步必须把 TCP probe 标准**（M2 规划已强调），否则采再多点也是白费。

3. **WIDE 策略下 N=15~20 是合理选择**：
   - 默认噪声：N=15（4.92mm）→ N=20（4.43mm）边际收益已小。
   - 但要注意：**4.4mm 的 P95 超了 M2.5 的 2mm 验收线**——这不是 N 的错，是 1mm 系统性
     TCP 造成的封顶。真机把 TCP 标到 0.3~0.5mm 后，WIDE N=20 预计可回到 ~2-2.5mm。
   - **建议真机：采 20 点 WIDE + TCP 标定目标 ≤0.5mm**。

4. **rotation P95**：WIDE N≥15 都在 0.2° 以内，远好于 M2.8 的 0.2~0.5° 交叉验证目标，
   旋转不是瓶颈；平移才是。

## 4. 对 M2.5 真机方案的直接影响

| 项 | 建议 |
|---|---|
| 采样数 | **20 点**（15 fit + 5 hold-out）|
| 空间覆盖 | **铺满交接区 ~0.5m 体积**（x、y、z 三个方向都要变化，不共线共面）|
| TCP probe | **必须先行标定，目标 ≤0.5mm**（否则精度封顶 ~4mm）|
| 预期精度 | TCP≤0.5mm + WIDE 20 点 → fit/holdout RMS ~2mm 可期 |
| hold-out | 5 点 hold-out（与 fit 不重叠），验收 fit RMS ≤2mm / holdout ≤2mm / MAX ≤3mm |
