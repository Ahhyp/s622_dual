  kL≈0.9975 kR≈0.9965，均值 3.70mm）；k=1 逐对表见章 10.2-C（L2×R1=2.73mm 唯一全过组合）。

## 三、卡点

`T_L_R_cam` vs URDF GT(700,0,0)mm：9 组合 2.73~7.14mm，**均值 4.93±1.55mm**，旋转 ≤0.71°。
单臂误差组合后**同向叠加** → 系统性相关；**离线证明非均匀尺度、不可按臂 marker_size 补偿**；
误差方向（非大小）决定组合结果（左 run1 单臂最优 0.4mm 却组合全挂，左 run2 单臂最差 2.55mm
组合最优 2.73mm）。

## 四、关键排查结论（供复核）

1. gz-sim Fortress 分离 camera **渲染跟随 lens fx**（render≈0.9957×lens）→ 改 lens 自抵消，
   focal_scale 无效杠杆（已证伪并还原 1.0）。
2. 偏差 ≈ ~1px 角点内缩（深度相关）+ ~0.5% 常量 → marker_size 0.1988 是唯一独立杠杆（不动渲染）。
3. root 构型显著影响左臂求解收敛（同质量数据 4.3mm 或 0.4mm）。
4. 轴门 2→3mm 对齐验收④（每轴 2mm 为 EIH 遗留）。
5. **⑤ 尺度补偿不可行**（2026-09-04 离线双扫证伪，见章 10.2）。

## 五、剩余
