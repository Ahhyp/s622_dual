## 三、卡点

`T_L_R_cam` vs URDF GT(700,0,0)mm：10 组合（9 旧 + 新 20/20 对）2.73~7.27mm，
均值 ~5mm 级，旋转 ≤0.71°。**冻结交付对 = L2×R1（2.73mm ≤3mm ✅，doc 章十.4）**；
M2.7-I 均值 4.93mm 记为仿真记录值（验收⑥冻结门限）。离线证明非均匀尺度、不可按臂
marker_size 补偿；误差方向（非大小）决定组合结果。

## 四、关键排查结论（供复核）

1. gz-sim Fortress 分离 camera **渲染跟随 lens fx**（render≈0.9957×lens）→ 改 lens 自抵消，
   focal_scale 无效杠杆（已证伪并还原 1.0）。
2. 偏差 ≈ ~1px 角点内缩（深度相关）+ ~0.5% 常量 → marker_size 0.1988 是唯一独立杠杆（不动渲染）。
3. root 构型显著影响左臂求解收敛（同质量数据 4.3mm 或 0.4mm）与丢组模式。
4. 轴门 2→3mm 对齐验收④（每轴 2mm 为 EIH 遗留）。
5. ⑤ 尺度补偿不可行（离线双扫证伪）；T_L_R 由两臂残差方向经旋转耦合决定。
6. 运行可复现性：杀 obb_node/rviz2 提速；杀 gz gui 会拆整树；渲染异常需干净重启；
   ROS_HOME 指向工作区（沙箱）。
