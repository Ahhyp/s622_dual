## 验证步骤

### 1. 启动标定仿真环境

```bash
source install/setup.bash
ros2 launch gz_launch s622_calibration_sim.launch.py
# 可选：板位置参数（默认 board_x=0.30 board_y=0.30 board_z=0.55 pitch=-90° yaw=180°）
# ros2 launch gz_launch s622_calibration_sim.launch.py board_x:=-0.05 board_y:=0.25
```

预期：Gazebo 出现双臂 + 桌子，**标定板平放在右臂前方桌面上（marker 朝上）**；`/wrist_camera/color/image_raw` 有图（rqt_image_view 查看）。

### 2. 确认右腕相机能看到标定板

```bash
rqt_image_view /wrist_camera/color/image_raw   # 或 rviz 添加 Image display
```

- 板不在视野 → 调 `board_x/y/z/roll/pitch/yaw` 参数重启：
  默认**平放桌面 marker 朝上**（board_x=-0.10 board_y=0.20 board_z=0.01 board_roll=-90° pitch/yaw=0）。
  robotarm 参考：单臂板相对 base 在 (0.29, 0, 0) 平放；我们右臂 base 在 (-0.35, 0, 0) → 板约 (-0.1, 0.2, 0.01)。
  板模型板面法线沿 y（marker 在 y=±0.0016），平放朝上必须 roll=-90°。
- 检查 aruco 检测：`ros2 topic echo /aruco_markers`（应出现 marker_ids: [1]）

### 3. 运行标定采集（collector）

```bash
# 终端 2
ros2 run hand_eye_calibration auto_calibration_collector.py --ros-args \
  -p use_sim_time:=true -p auto_start:=true \
  -p calibration_output_directory:=$HOME/my_S622/src/hand_eye_calibration/calib/sim
```

预期流程（collector 自动）：
1. 右臂 MoveIt 规划执行 20 槽固定关节位姿（robotarm 标定姿态，含旋转激励）
2. 每槽：运动 → settle 1s → 关节静止 0.3s → 视觉连续 10 帧稳定观测 → 记录样本
3. 达到 15 个有效样本 → Park/Horaud 求解（Tsai-Lenz 诊断）→ 固定 marker 优化 → 残差剔除
4. **GT 检查**（`ground_truth_check_enabled=true`）：tool0→camera 估计 vs URDF 真值
   （总平移 ≤3mm、X/Y/Z 各 ≤2mm、旋转 ≤1°，通过才保存 `.calib`）

### 4. 查看结果

```bash
ls src/hand_eye_calibration/calib/sim/   # robot_calibration_*.calib + .samples
```

`.calib` 内容：求解的 `grasp_frame → wrist_camera_color_optical_frame` 变换 + 误差指标。

## 已知问题 / 注意

1. **初始位姿下板可能不在视野**：双臂初始是"肘部收纳"姿态，collector 会先动到 slot 1（robotarm 标定姿态）——**板位置按 robotarm 参考放**（右臂前方平放），collector 运动到位后视觉门控应通过；若 slot 1 看不到，用 rqt_image_view 调板位置。
2. **右臂可达性**：robotarm 的 20 槽 waypoint 是单臂的（右臂与单臂同向 yaw=0），理论上可达；若某槽不可达/视野差，改 config waypoints 或调整。
3. **沙箱无 GPU**：本机 DSH 沙箱渲染失败（相机空白图）——必须在有正常渲染的环境跑。
4. **robotarm 原版 yaml**：已被双臂右臂版替换，原版在 git 历史可回溯（commit 23a0630 前）。
5. **M2.2 待办**：`evaluate_calibration.py` 的 eye-in-hand placeholder（T_pred=T_obs 构造 0 误差）——仿真 GT 验证通过后再修独立 evaluator。
