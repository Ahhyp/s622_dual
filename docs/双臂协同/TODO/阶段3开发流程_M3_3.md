## M3.3.1 LeRobotDataset 格式简介

LeRobot 的数据格式:

```
data/s622_pick_v1_lerobot/
├── data/chunk-000/
│   └── episode_000000.parquet   # (T, ...) 每条 episode 一个 parquet
├── videos/chunk-000/observation.images.top/
│   └── episode_000000.mp4       # 图像编码成 mp4
├── meta/
│   ├── info.json                # 数据集元信息
│   ├── stats.json               # 归一化统计
│   ├── tasks.jsonl              # 任务描述
│   └── episodes.jsonl           # 每条 episode 元信息
```

**核心 features**:

* `observation.state`: (T, 14) qpos
* `observation.images.top`: (T, H, W, 3) 编码为 mp4
* `action`: (T, 14)

## M3.3.2 转换脚本

先在**本地机器**上生成 LeRobotDataset,再上传服务器。或直接把 HDF5 传服务器再转。

**推荐**: 在服务器上直接转,因为需要 ffmpeg encoding。

### 上传 HDF5 到服务器

```bash
# 本地:
cd ~/s622_embodied/s622_mujoco
tar -czf s622_pick_v1.tar.gz data/s622_pick_v1/

# 上传(替换成你的服务器)
scp s622_pick_v1.tar.gz user@server:~/

# 服务器上:
mkdir -p ~/s622_data
tar -xzf ~/s622_pick_v1.tar.gz -C ~/s622_data/
```

**大小估计**: 200 ep × 168 步 × 640×480×3 uint8 ≈ 30 GB(未压缩),HDF5 gzip 后应该 3-5 GB。

---

### 转换脚本

在服务器上创建:

```python
# ~/convert_to_lerobot.py
"""HDF5 → LeRobotDataset 转换."""
from pathlib import Path
import numpy as np
import h5py
from tqdm import tqdm
import torch

from lerobot.datasets.lerobot_dataset import LeRobotDataset


# 配置
HDF5_DIR = Path("~/s622_data/data/s622_pick_v1/success").expanduser()
OUTPUT_REPO_ID = "s622_pick_v1"  # 本地 repo id
FPS = 50  # 控制频率
IMAGE_KEY = "images/top"  # HDF5 里的 image dataset key


# 定义 features schema
FEATURES = {
    "observation.state": {
        "dtype": "float32",
        "shape": (14,),
        "names": [
            "left_j1", "left_j2", "left_j3", "left_j4", "left_j5", "left_j6",
            "left_gripper",
            "right_j1", "right_j2", "right_j3", "right_j4", "right_j5", "right_j6",
            "right_gripper",
        ],
    },
    "action": {
        "dtype": "float32",
        "shape": (14,),
        "names": [
            "left_j1", "left_j2", "left_j3", "left_j4", "left_j5", "left_j6",
            "left_gripper",
            "right_j1", "right_j2", "right_j3", "right_j4", "right_j5", "right_j6",
            "right_gripper",
        ],
    },
    "observation.images.top": {
        "dtype": "video",
        "shape": (480, 640, 3),
        "names": ["height", "width", "channels"],
    },
}


def main():
    # 收集所有 HDF5
    hdf5_files = sorted(HDF5_DIR.glob("episode_*.hdf5"))
    print(f"Found {len(hdf5_files)} episodes")
    
    # 创建 LeRobotDataset(空,即将填入)
    dataset = LeRobotDataset.create(
        repo_id=OUTPUT_REPO_ID,
        fps=FPS,
        features=FEATURES,
        robot_type="s622_dual_arm",
        use_videos=True,
    )
    
    # 逐个 episode 加入
    for hdf5_path in tqdm(hdf5_files, desc="Converting"):
        with h5py.File(hdf5_path, 'r') as f:
            qpos = f['qpos'][:]      # (T, 14)
            action = f['action'][:]  # (T, 14)
            images = f[IMAGE_KEY][:] # (T, H, W, 3) uint8
        
        T = len(qpos)
        
        # 逐帧添加
        for t in range(T):
            frame = {
                "observation.state": torch.from_numpy(qpos[t]).float(),
                "action": torch.from_numpy(action[t]).float(),
                "observation.images.top": torch.from_numpy(images[t]),  # uint8 HWC
                "task": "pick_cube",  # LeRobot 需要 task 字段
            }
            dataset.add_frame(frame)
        
        # 保存这条 episode
        dataset.save_episode()
    
    print(f"[ok] Dataset saved to: {dataset.root}")
    print(f"  {dataset.num_episodes} episodes, {dataset.num_frames} frames")


if __name__ == "__main__":
    main()
```

**运行**:

```bash
cd ~
python3 convert_to_lerobot.py
```

**注意**: LeRobot 0.5.1 的 API 可能与我写的略有差异,如果报错贴出来。特别是:

* `LeRobotDataset.create` 的参数名
* `add_frame` / `save_episode` 的用法

## M3.3.3 ACT 配置文件

LeRobot 用 hydra 或直接命令行传参训练。

```yaml
# ~/configs/act_s622.yaml
policy:
  type: act
  n_obs_steps: 1
  chunk_size: 100          # ACT 的核心超参,一次预测 100 步
  n_action_steps: 100
  
  vision_backbone: resnet18
  pretrained_backbone_weights: ResNet18_Weights.IMAGENET1K_V1
  
  input_features:
    observation.state:
      type: STATE
      shape: [14]
    observation.images.top:
      type: VISUAL
      shape: [3, 480, 640]
  
  output_features:
    action:
      type: ACTION
      shape: [14]
  
  # Transformer 结构
  dim_model: 512
  n_heads: 8
  dim_feedforward: 3200
  n_encoder_layers: 4
  n_decoder_layers: 1
  
  # VAE 部分(可选)
  use_vae: true
  latent_dim: 32
  kl_weight: 10.0

training:
  batch_size: 8
  num_epochs: 50           # 200 ep × 168 步 = 33k 帧, 8 batch → 4200 iter/epoch
  learning_rate: 1e-5
  weight_decay: 1e-4
  
dataset:
  repo_id: s622_pick_v1
  local_files_only: true
```

## M3.3.4 启动训练(LeRobot CLI)

LeRobot 0.5+ 有官方训练 CLI:

```bash
# 训练命令(具体参数以 lerobot 版本为准)
lerobot-train \
    --dataset.repo_id=s622_pick_v1 \
    --policy.type=act \
    --policy.chunk_size=100 \
    --output_dir=outputs/act_s622_v1 \
    --training.num_epochs=50 \
    --training.batch_size=8 \
    --training.learning_rate=1e-5 \
    --training.device=cuda
```

**但 LeRobot API 变化很快**,你的版本 0.5.1 的实际命令可能不同。

**先确认 CLI**:

```bash
lerobot-train --help
# 或
python -m lerobot.scripts.train --help
```
