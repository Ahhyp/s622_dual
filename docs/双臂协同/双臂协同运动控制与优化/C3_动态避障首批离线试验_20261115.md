# 动态避障首批离线试验（2026-11-15）

## 做了什么

按照[实施规划](C3_动态避障实施规划_20261115.md)，复跑原 C2.7 臂间 CBF 测试，并新增移动障碍速度项及 4 项测试。新增代码没有接入当前 C43 运行控制器，也没有启动或关闭 Gazebo。

代码位置：

- `src/dual_arm_collision/include/dual_arm_collision/moving_obstacle_cbf.hpp`：从距离、关节梯度、法向和障碍最近点速度生成 QP 不等式，非法输入返回明确的无效标记。
- `src/dual_arm_qp_core/test/test_moving_obstacle_cbf.cpp`：速度方向、输入检查、无解处理和离线双臂闭环试验。

## 结果

| 检查 | 结果 |
|---|---|
| 原 C2.7 臂间 CBF | 通过，保留原结果：开启后最小距离约 116.9 mm，关闭时出现负距离 |
| 移动速度的方向 | 静止时回到原公式；靠近时约束收紧，远离时放松 |
| 错误输入 | 过期、未来、穿透、错误法向、非有限数据及非法增益被拒绝 |
| 没有可行运动 | 构造无法满足的约束，QP 返回未收敛，没有应用其关节增量 |
| 移动球体与双臂 QP | 500 拍、每拍 8 ms，关闭/开启均无求解失败，开启后产生退让运动 |

移动球体案例使用默认双臂运动学、相同初始关节位置和相对抓持目标，物体任务关闭；没有附加被搬物体。球半径 50 mm，球心初始距左 TCP 150 mm，以 10 mm/s 接近；要求的表面距离为 80 mm。关节理想执行每拍求得的增量，无伺服延迟。

| 指标 | 约束关闭 | 约束开启 |
|---|---:|---:|
| 逐拍执行后最小表面距离 | 60.000 mm | 80.003 mm |
| 最终关节变化的 12 维范数 | 0 rad | 0.06205 rad |
| 求解失败次数 | 0 | 0 |

开启后的相对位姿 Log 误差分量：平移最大约 **0.06860 mm**，旋转最大约 **0.000914°**。约束行最大正残差约 `4.07e-20`。这说明移动障碍速度项确实参与求解，并使两臂协调退让；没有证明能绕过障碍后继续完成搬运。

本次实际通过 **2/2 CTest 套件、5 个测试**。原始输出位于 `log/c3_dynamic_20261115/`，仓库内保存 `evidence/c3_dynamic_first_20261115.json` 和紧凑测试输出。摘要记录源码与日志校验值。
