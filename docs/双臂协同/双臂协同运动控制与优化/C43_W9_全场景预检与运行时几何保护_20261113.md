# C43 W9：全场景启动预检与运行时几何保护（2026-11-13）

接续接触白名单/外载试验，本批实现全场景离散参考路径预检门禁，以及 QP 更新中的有界解析物体—环境保护。运行命令和结果按下文实际范围解释，不能把参考路径预检称为精确未来 QP 反馈轨迹或连续碰撞证明。

## 全场景预检：实现与验证

新增 `c43_scene_precheck.py` 和非实时工具 `c43_scene_path_check`，复用既有 DualArmScene、MoveItCollisionBackend、SRDF ACM 与 FCL，不复写机器人运动学或 QP。

- 从生成的 world SDF 及实际 include/model/link/collision 变换读取桌面、四条桌腿、源/目标支撑和物理地面。固定环境不随样件移动。旧 mock TransportChecker 的 applyWorld 会把支撑放到样件当前位置下方，不能直接当本物理场景的全路径检查器。
- 加载实际 URDF 的 18 个碰撞形状，验证所有 mesh 文件与加载数；保留原 SRDF 自碰豁免，不新增两臂互碰豁免。机器人底座仅对实际安装的地面/桌面 surface 接触豁免，不豁免桌腿、腕或其他机器人部位。
- 检查机器人自身、机器人—环境、样件—静态环境。四指—样件豁免必须匹配抓持/释放相位及样件侧面；支撑允许走精确圆盘/底面顶面几何条件，不用外接盒授权接触。
- 检查完整参考接近、抓持、抬升、横移、放置、张手、后退和归位。每段 16 采样，总 4976 样本；显式插入手指闭合与张开，四指状态不再一直用默认值。
- `--scene-precheck` 将它接到启动门禁。任何输入/几何/采样失败均先返回 `precheck_failed`，不会启动 Gazebo 或动作；默认不启用，以免改变既有入口。

首轮有效结果 `log/c43_w9d_20261113/full_scene_r2/summary.json`：4976 样本全部通过，8 个固定世界碰撞形状、18 个机器人形状，最小检查间距 5.394 mm，要求 2 mm。逐样本 JSONL、源 SDF、路径与 mesh SHA256 全部保留。

`gate_positive_r1` 正常路径通过；`gate_obstacle_r1` 已知障碍路径在仿真启动前拒绝。11 个离线反例 `counterexamples_r2` 通过，包括桌面/桌腿、支撑侧壁、提前目标支撑接触、非手指腕部、机器人与新障碍、机器人与桌腿、缺失几何、未知相位和非法样件四元数。

### 遇到的问题与处理

1. 当前 MoveIt/FCL 的 mesh—plane **距离**查询在首样本崩溃。保留 FCL 平面碰撞查询，地面距离改用实际机器人 mesh 顶点到 SDF 平面的精确线性距离；没有把真实无限物理平面伪装成有限厚盒。崩溃诊断保留，不计通过。
2. 最初两个“腕部碰撞”反例按腕坐标系原点放小盒，没有保证碰撞 mesh 真正相交。改用已证实与腕 mesh 相交的样件尺寸盒；验证实际碰撞对，而不是预填某个腕 link 必撞。失败反例输入与修正后结果都保留。
3. 桌面位置/几何沿用上一批读取到的实际值：中心 X=0.4，顶面 Z=0；圆柱顶面才是 Z=0.25。没有为满足旧文字断言移动桌面。

### 预检的边界

门禁检查的是版本化参考关节路径及样件参考位姿；它覆盖所有参考相位，但不是逐相位拿当前反馈重新规划/复检，也不是精确未来 QP rollout。当前反馈偏差、动态障碍更新与采样间隙不能由这份预检自动担保。所有不一致和失败输入保留，不通过删样本获得通过。

## 运行时解析保护：实现

新增 `FiniteGeometryGuard`，配置阶段从同一导出的静态 SDF 场景读入最多 32 个 primitive，更新时固定容量、无 FCL 调用。盒—盒使用 15 轴 SAT；圆柱禁止方向用外接 OBB 保守拒绝，允许方向仍用底面与精确顶面圆盘交集。2 mm 清距通过膨胀样件 OBB 实现，对旋转配置是保守包络；`margin` 是该 SAT/平面保护裕度，不应冒充精确欧氏最近距离。目标落座沿用现有 1 mm 支撑带和 0.2 mm 有界过行程。

保护显式开启：`--enable-finite-guard`。它覆盖 QP 持有双臂期间，沿用已知 lift/settle/transport/lower/settle_post 相位；接近和后退的 JTC 路径由非实时预检/物理接触层覆盖。失败码沿用 `object_table_clearance`，锁存控制器与执行器 ABORT，并确认真实停止。

更新分别检查左锚定估计、右锚定估计、期望物体位姿，随后补上第四路带原生时间戳的 Gazebo 物体真值。真值仅用于仿真保护观测，不是 FT 力反馈，也不改 QP 数学。输入用 lock-free 原子序列快照传入，读取不等待；短暂写入重叠时沿用上个一致且仍新鲜的快照，避免引入阻塞。超过现有 100 ms 新鲜度或时间非法则受控停止，不能静默退回只看模型。

### 为什么增加第四路真值

初版 `finite_clearance_r1` 已在碰撞前锁存清距 ABORT，但冻结后约 0.2 s 仍出现原生障碍接触：物理样件与运动学锚定估计有偏差，停车过程中还有残余运动。其“停止命令链”检查通过，**不能计作停车后零接触验证通过**。原始结果保留。

只读探测还确认当前 `/c43/weld_pose` 的 TransformStamped 时间戳为 0，不能把接收时刻或当前 `/clock` 填作原生测量时间。第四路直接复用原生 Pose_V 记录器中的全局 stamp 与同包 c43_sample 位姿；不依赖零时间戳 TF。配置只支持当前零碰撞偏移的单盒样件，其他未适配的偏移模型明确拒绝。

几何守卫测试包含独立 FCL 200 个膨胀盒对照、有限桌沿/支撑反例、非法输入、新鲜度边界及 8 障碍场景的 10000 次零分配检查。几何块计时与状态证据记录在新 TransportStatus 字段；观察到的几何耗时不等于整个控制器实时周期 Gate 已通过。

## 仍不能关闭的范围

完整 W9/安全总 Gate 未自动关闭：参考路径逐相位当前反馈复检、物理停车余量/清距和跟随阈值标定，以及当前几何合同差异仍须分别收口。持续卡开执行器的载荷保留是保留的物理风险。动态环境完整重建、连续碰撞安全证明和真机安全认证不是本批声明，也不能额外算成已经通过的结果；原规划本来就不承诺连续碰撞证明。原 12 个未批准失败码没有注册或改写。

### 停车残余运动的第二次定位与提交前门禁

`native_clearance_r2` 表明，仅补当前原生真值仍不足：当前物体尚安全时，已经发出但尚未执行完的位置目标仍可能让它继续前移。该轮原生障碍接触没有消失，不能计作最终零接触验证通过。

因此在 TransportTask 的“求解收敛 → 提交增量 → 推进轨迹时钟”之间新增可选的无分配 CommitGuard。它检查即将真正写出的限位裁剪后 q_cmd，包括左右命令锚定物体位姿，以及按当前原生真值与锚定估计的世界变换偏差外推的位置目标。此预测服务于当前固定姿态的平移搬运试验，不是对任意旋转轨迹、快速滑移或制动过程的安全证明。

不安全增量在提交前被拒绝，dq 不写出、committed=false、t_traj 不推进，锁存 `object_table_clearance`。未开启有限几何保护时回调为空，既有 QP 默认路径不变；没有改动目标函数、约束或求解器。新增测试验证：拒绝候选时不提交不走时钟，允许候选时与无回调默认数值结果一致。连同 ULP、冻结基线、几何、HOLD ACK 与健康保护，共 6 个定向 CTest 套件通过。

运行时几何证据的 source 编号为：0 左状态锚定，1 右状态锚定，2 期望位姿，3 原生真值，4 左命令锚定，5 右命令锚定，6 原生偏差外推的命令物体位姿。几何耗时覆盖状态和提交前检查，但不包含整个控制器周期或 DDS 端到端延迟。状态观察者与执行器使用各自接收时刻，不能把二者差值（甚至可能为 -2 ms）伪称为反应时延。


### 实测位置锁存及停车余量对照

`native_commit_clearance_r3` 验证了提交前拒绝，但停车后仍有障碍接触，因此不能计作物理零接触通过。随后 `measured_brake_clearance_r4` 在有限几何紧急停止时一次锁存 **q_state 的实测位置**（限位裁剪后）作为 q_cmd，之后不再追随新测量，避免继续追赶原来的前置目标。该策略仅在显式有限几何保护模式下生效；健康的操作 HOLD 与默认旧模式不改变。新任务/合法恢复重置锁存。

r4 首个 ABORT 状态 q_cmd 与 q_state 一致，之后双臂命令冻结；原生障碍接触由 r3 的 191 条减至 21 条，但未归零，仍不计作物理零接触通过。这说明固定的 2 mm 几何间距不能直接当本物理夹持系统的停车距离保证。

新增显式实验参数 `--finite-stop-reserve-mm`，默认 0，非负且只会收紧保护：基础几何清距仍为 2 mm，附加停车余量单独记录。以 8 mm 附加余量（总解析停车带约 10 mm，旋转 OBB 包络保守）做本工况对照。此值来自本轮残余运动问题的保守候选，**未获得标定批准**，不能推广为所有质量、速度、采样延迟或真实硬件的停车界限。

该余量仅作用于运行时物体—环境保护；全场景 FCL 门禁的基础 2 mm 要求未改动，机器人自身最小间距也没有被暗中提高到 10 mm。门禁通过并不保证任意附加余量都能执行完成；运行时仍可能保守拒绝。

```bash
docker exec -w /workspace s622_yep bash -lc 'source install/setup.bash; ros2 run gz_launch c43_run_contact_transport.py --backend qp-executor --ros-domain-id 167 --scene-precheck --enable-finite-guard --finite-stop-reserve-mm 8 --enable-contact-safety --inject-executor hold-resume --out /workspace/log/NEW_w9d_guarded_hold'
```
