## §3.1–§3.3 时钟与数据结构（第 77–103 行）
```
### 3.1 时钟

- 唯一时间源：`clock_gettime(CLOCK_MONOTONIC)`（当前 `nowNs()` 的实现，`dual_arm_qp_controller.hpp:104-113`）。
- **不使用** `rclcpp::Time`（可被仿真时间 / `use_sim_time` 改变）、**不使用** `gettimeofday`（可被 NTP 阶跃）。
- 已有 `interval_us` 用 `t_begin - t_prev_begin` 计算，并带 `have_prev_ && t_begin > t_prev_begin` 守卫（`timing_recorder.cpp:62-65`），对时钟回退安全——相位差沿用同一守卫。

### 3.2 数据结构（扩展现有 `TimingRecorder`）

```cpp
static constexpr int kPhases = 6;     // P1..P6
std::vector<float> phase_us_[kPhases]; // 与 wall_ns_ 同长度，configure() 一次性分配
float phase_acc_[kPhases];             // 当前周期累计（不参与落盘）
uint64_t t_mark_ns_;                   // 最近一次 mark()
```

- **容量**：与 `capacity_` 同（默认 `timing_capacity=8000`，见 `config/c43_s4_realtime_params.yaml`），按 8 ms 周期 ≈ 64 s；超出即 `dropped`（沿用现有 `capacity_` 语义）。
- **溢出处理**：`n >= capacity_` 时**不扩不覆盖**，仅 `++dropped`（现有行为 `timing_recorder.cpp:68`），并且只统计前 `capacity_` 个样本——即“多次运行拼接”由外部脚本负责，控制器绝不 realloc。
- **精度**：`float` 存微秒，8 ms 量级下有效位约 0.5 µs，足够区分相位；聚合（`summarize()`）用 `double` 重算分位数，避免浮点累加误差。
- **单次写入**：`mark()` 只做 `t_mark_ns_ = nowNs(); phase_acc_[i] += ns→us`；`end()` 里一次性把 6 个 `phase_acc_` 写进当前样本槽并把 `phase_acc_` 清零。⇒ 每相位 1 次 `clock_gettime` + 1 次 `float` 累加，**不触碰缓存行之外的内存**。

### 3.3 非 RT 数据导出

- 现有 `~/timing_dump`（`std_srvs/Trigger`，`onTimingDump` `:619`，executor 线程）继续用：`dumpCsv(timing_csv_path_)`。
- CSV 新增列：`branch,exit_code,p1_read_us,p2_dispatch_us,p3_safety_us,p4_task_solve_us,p5_write_us,p6_publish_us`。
- **导出期间 RT 侧只读**：`count_` 是 release-store（`timing_recorder.cpp` 已有），dump 只读 `[0, n)` 的已完成样本 ⇒ dump 不会看到半样本，也不会阻塞 RT。
- 落盘在 executor 线程，`fprintf` 不在 RT 内发生。

```

### 4.2 ON/OFF 与相位开关的三态对照

不新增构建选项，改用**运行时参数** `timing_phases`（`0` = 关；`0x3F` = 全开）：

| 轮次 | `timing_enable` | `timing_phases` | 目的 |
|---|---|---|---|
| A（基准） | `false` | — | 无记录器的基准 `cycle_us`（外部用 `/proc` 或 `ros2 topic` 观测不足，故 A 轮只作为“控制器无额外分支”的对照） |
| B（仅总量） | `true` | `0` | 只有 P0/P7：分离“记录器本身”的开销 |
| C（全相位） | `true` | `0x3F` | 全量相位：C − B = 6 个 mark 的净开销 |

判据：`|p99(C) − p99(B)| ≤ 100 µs`（≈ 记录器总开销上限 2 倍余量）；若超出，先怀疑 `mark()` 实现而非采样噪声（因为 350 ns × 638 周期不可能聚成 100 µs）。

## §6.1–§6.2 OFF 隔离与恢复步骤（第 161–182 行）
```
### 6.1 隔离原则

- 相位计时**不是**测试 hook：它由运行时参数 `timing_enable`/`timing_phases` 控制，与 `C43_ENABLE_TEST_HOOKS` 正交。
- 唯一需要 `#ifdef` 的地方是 T-H17 的注入点（已存在），本设计不新增。
- ON 构建下相位计时同样默认关闭；OFF 构建下相位代码仍存在但零开销（`timing_enable=false` 时 `mark()` 不被调用，因为 `TimingScope`/相位块由 `if (timing_.enabled())` 守卫）。
- 若实施时发现必须在 `#ifdef` 内才能零开销，需**单独审批**（授权令禁止新增 hook）。
