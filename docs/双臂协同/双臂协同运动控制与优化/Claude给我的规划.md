**十四项里十一项完整,两项缺失,一项打折。** 换个说法:工业双臂运动控制工程师日常做的事,你能覆盖大部分;缺的是力控这一条支线。

再具体一点,你能做到的程度:

* 从零构建一个 12 自由度冗余系统的**实时约束优化控制器**,而不是调 MoveIt 的 API
* 对一个**黑盒商用控制器**做系统辨识并设计补偿,而不是假设它是理想执行器
* 在**无外部计量设备**的条件下完成参数辨识并量化精度提升
* 把避障从"检测到就停"提升到**在保持任务约束前提下的在线安全优化**
* 每一项都有实机数字和可复跑的实验脚本

这个水平不是"学生做了个双臂 demo",是"有系统性工程方法的运动控制开发"。

力控缺失的实际影响:损失"力控"这条标签,不损失"双臂"和"运动控制"两条。第 22 轮那个论证成立——JD 里六项要求零项需要力矩接口。

## 二、需要完善的七项

前面 22 轮讨论过的内容已经够撑起项目主体,以下是能明显拉开差距的补充。

### 1. 双臂工作空间与可操作度分析(新增,建议做)

采样双臂构型空间,计算并可视化:

* 双臂**共同可达空间**(交接与协同操作只能发生在这里)
* 相对位姿约束下的可操作度场 (\sqrt{\det(J_{rel}J_{rel}^T)})
* 零空间维度分布,以及退化区域(接近奇异的位置)

**为什么值得做:** 它是所有双臂任务的设计依据——交接位、待机位、协同工作区该选在哪,不是靠示教猜,而是从可操作度图上选最优区域。产出是一张热力图,视觉直观,面试时一张图能讲五分钟。同时它让你的后续参数选择有依据,而不是"试出来的"。

### 2. 交接 / 相对位姿的优化选取

第 16 轮提过但没展开:双臂共同约束一个物体时,可行的相对位姿不是一个,是一族。绕物体轴旋转、两臂上下互换、整体平移,都是自由度。

把它写成优化问题:

$$\max_{T_{rel} \in \mathcal{F}} ; w_1,\sigma_{\min}(J_1) + w_2,\sigma_{\min}(J_2) + w_3,d_{\min}(\mathcal{A}_1,\mathcal{A}_2) - w_4,|q - \bar{q}|^2$$

约束是 IK 有解、无碰撞、在共同可达空间内。

**为什么值得做:** 大多数人的做法是手动示教一个能用的位姿。你把它变成一个优化问题并量化收益(IK 成功率提升、最小奇异值提升、规划耗时下降),这是从"能跑"到"做优化"的分界线。而且它直接用到第 1 项的产出。

### 3. 误差预算与溯源实验(最能体现真机经验)

实机偏差总是多源叠加。设计交叉验证实验,逐项分离并量化贡献:

| 误差源          | 分离方法              |
| ------------ | ----------------- |
| URDF 运动学参数误差 | 辨识前后对比            |
| 双基座标定残差      | 双臂互触重复性           |
| 手眼标定误差       | 视觉给位置 vs 实际抓取位置偏差 |
| 伺服跟踪误差       | 指令-反馈偏差统计         |
| 气爪打滑偏移       | 抓取前后腕部相机复检        |
| 深度噪声         | 同一目标多次测量方差        |

最终给出一张误差预算表:总偏差 X mm 中各源占比多少。

**为什么值得做:** 这是仿真里根本不存在的问题——仿真可以单独开关每个误差源,实机必须设计实验去分离。第 17 轮说过,这是真机经验里最难替代的部分,也是面试最能区分人的地方。"我的抓取偏差 4.2mm,其中标定 1.8mm、气爪打滑 1.5mm、深度噪声 0.6mm" 这种回答,没做过的人说不出来。

### 4. 消融实验与评测规范

不要只报最终数字,报**对比**。建一套可复跑的评测:

| 实验       | 对照组           | 指标                  |
| -------- | ------------- | ------------------- |
| 零空间优化    | 开 / 关         | 最小奇异值下界、限位余量、双臂最小距离 |
| 前馈补偿     | 开 / 关         | 跟踪误差 RMS、相位滞后       |
| 输入整形     | 开 / 关         | 残余振动幅值、衰减时间         |
| jerk 限制  | TOTG / Ruckig | jerk 峰值、末端抖动、节拍     |
| 运动学辨识    | 辨识前 / 后       | 绝对定位精度              |
| 12 轴联合规划 | 顺序 / 协同       | 节拍、规划耗时 P95         |
| CBF 避障   | 阈值停机 / CBF    | 最小距离、任务完成率、轨迹平滑度    |

评测协议参考 ISO 9283 简化版(位姿重复性 RP、位姿准确度 AP、轨迹偏差 AT),测试点和重复次数固定。

**为什么值得做:** 消融表是"做了工程优化"和"跑通了一个 demo"的分水岭。而且它让你的每个数字都有意义——单独的"跟踪误差 0.3mm"没信息量,"从 1.1mm 降到 0.3mm,降低 73%"才有。

### 5. 气爪表征 + 抓后位姿复检补偿

气动夹爪是你的弱项硬件,但把它**表征清楚**本身就是内容:

* 开合响应延迟随气压的变化曲线(50~200ms 量级)
* 抓取后物体在爪内的位姿偏移分布(用腕部相机测,多次统计)
* 不同表面/重量下的打滑概率

然后做补偿:抓取后用腕部 RGBD 复检物体实际位姿,更新 `AttachedCollisionObject` 并修正后续放置目标。

**为什么值得做:** 这是纯实机问题,仿真里 fixed joint 完美夹持,根本不会想到要做。而"把一个不精确的执行器表征清楚并设计补偿"正是工程能力的体现。

### 6. 沿约束的时间最优参数化

轨迹层再深一层:TOPP-RA(Time-Optimal Path Parameterization by Reachability Analysis)。它在给定路径上求满足速度/加速度/jerk 约束的时间最优参数化,比 MoveIt 默认的 TOTG 更严格且能处理更多约束类型。

在双臂场景里可以额外加入"相对位姿保持误差不超过阈值"作为约束,这是单臂没有的题目。

**为什么值得做:** 让轨迹层从"能用"变成"有优化目标",而且和主线的约束优化思路一致。

### 7. 交付物:仓库 + 技术报告 + 演示视频

这一项最容易被忽略,但对简历的杠杆最大:

* **GitHub 仓库**:README 带架构图、快速启动、模块说明;代码有注释和单元测试
* **技术报告**(10~20 页):问题定义、方法、实验、结论、局限。含所有公式推导和消融表
* **演示视频**(2~3 分钟):双臂保持相对位姿协同运动 → 人手侵入 → 在维持约束下避障 → 继续任务。一个视频同时展示三项核心能力
* **实验数据与脚本**:原始数据 + 一键复跑脚本

**为什么值得做:** 简历上的数字面试官无法验证,但一个能跑的仓库和一段视频可以。而且视频是你唯一能在简历投递阶段就传递"这是真机"的手段。

### 核心数学模型

层级任务 QP:

$$\min_{\dot q}; \sum_{k} w_k\left|J_k\dot q - \dot x_k^{des}\right|^2 + w_0\left|\dot q - \dot q_{null}\right|^2$$

$$\text{s.t.}\quad q^- \le q + \dot q,\Delta t \le q^+,\qquad |\dot q|\le \dot q^{max},\qquad \frac{\partial d}{\partial q}\dot q \ge -\alpha!\left(d - d_{safe}\right)$$

双臂相对位姿约束(最高优先级,(\dot x^{des}=0)):

$$J_{rel} = \begin{bmatrix}-J_1 & J_2\end{bmatrix} \in \mathbb{R}^{6\times12},\qquad \dim\ker(J_{rel}) = 6$$

零空间次级目标(冗余分配):

$$\dot q_{null} = -\sum_j \lambda_j \nabla_q H_j(q),\qquad H_j \in {\text{限位余量},; \sigma_{\min}(J),; d_{\min}(\mathcal{A}_1,\mathcal{A}_2)}$$

动态避障风险评估(制动距离模型):

$$d_{safe} = \frac{v_{rel}^2}{2a_{max}} + v_{rel},t_{react} + \delta_{margin}$$

### 决策门

**G1(阶段 0 后)—— 抖动决定协同形态**

| 抖动 3σ  | 决策                         |
| ------ | -------------------------- |
| < 2ms  | 12 轴同时运动协同正常做;闭链算法理论上可迁移实机 |
| 2~10ms | 12 轴只做互避(不依赖精确同步),这是主要价值   |

| 残差    | 决策                       |
| ----- | ------------------------ |
| ≤ 2mm | 正常推进                     |
| 2~5mm | 协同搬运加导向工装,放宽精度目标         |
| > 5mm | 回查 URDF 连杆参数与关节零位,不要硬往下走 |

**G3(阶段 2 后)—— QP 性能决定实时策略**

| P95 耗时 | 决策                    |
| ------ | --------------------- |
| < 1ms  | 250Hz 全速运行            |
| 1~3ms  | 降到 125Hz,或简化约束集       |
| > 3ms  | 分层:QP 在 50Hz 外环,内环做插值 |
