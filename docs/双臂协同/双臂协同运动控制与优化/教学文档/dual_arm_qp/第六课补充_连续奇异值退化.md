# 连续奇异值退化（C2.6）：按文档符号详细展开

文档第 9 章只给了公式骨架，没解释"为什么这么构造"。下面按文档的符号约定（$q, J_{rel}, \sigma_{\min}, f_\sigma, f_{e,\cdot}, f, w_{reg,eff}, w_{slack,eff}, v_{scale}$）把整件事讲透。

---

## 一、要解决的核心问题：**为什么不能硬开关**

接近奇异时，$\sigma_{\min}(J_{rel})\to 0$，伪逆的放大因子是 $1/\sigma$，会给出**巨大的关节速度**。传统做法是设一个阈值 $\sigma_{\text{th}}$，$\sigma_{\min}<\sigma_{\text{th}}$ 就"停任务/切模式"。问题是：

- **阈值附近抖动（chattering）**：$\sigma_{\min}$ 在阈值上下浮动时，控制输出在"正常"和"停止"之间来回跳；
- **不连续输出**：阶跃式切换对执行器不友好，加速度冲击大；
- **信息浪费**：$\sigma_{\min}$ 略高于阈值时完全正常，略低于就完全放弃，中间状态被浪费。

连续退化要做的：**不设硬开关，而是让"任务权威"随健康状况平滑变化**。健康时完全正常，退化时"变软"——不是放弃任务，而是以更保守的方式执行，允许部分误差。这就是文档里"连续奇异退化"名字的来源。

---

## 二、两个退化源：奇异值 + 误差

退化不只由奇异值触发。误差太大时，线性化本身失真（$\dot e\approx J\dot q$ 只在 $e$ 小时成立），硬推反而可能发散。所以定义**两个独立源**，各自映射到 $[0,1]$ 的健康因子。

### 2.1 奇异值因子 $f_\sigma$

文档定义：

$$
f_\sigma = S\!\left(\frac{\sigma_{\min}-\sigma_{\text{critical}}}{\max(10^{-9},\ \sigma_{\text{safe}}-\sigma_{\text{critical}})}\right)
$$

- $\sigma_{\text{safe}} > \sigma_{\text{critical}}$ 是两个阈值；
- 分子 $\sigma_{\min}-\sigma_{\text{critical}}$：$\sigma_{\min}$ 越大越健康；
- 分母归一化到 $[0,1]$：
  - $\sigma_{\min}\ge\sigma_{\text{safe}}$ → 比值 $\ge 1$ → $f_\sigma=1$（完全健康）；
  - $\sigma_{\min}\le\sigma_{\text{critical}}$ → 比值 $\le 0$ → $f_\sigma=0$（完全退化）；
  - 中间平滑过渡。

$\max(10^{-9},\cdot)$ 是防分母为零的兜底（若两个阈值配反了）。

### 2.2 误差因子 $f_{e,rel}, f_{e,obj}$

**注意方向是反的**：误差越小越健康。代码：

```cpp
const double e_denom = std::max(1e-9, params_.e_critical - params_.e_safe);
f_err_rel = smoothstep01((params_.e_critical - e_rel.norm()) / e_denom);
f_err_obj = smoothstep01((params_.e_critical - e_obj.norm()) / e_denom);
```

数学式：

$$
f_{e,\cdot} = S\!\left(\frac{e_{\text{critical}}-\|e_\cdot\|}{\max(10^{-9},\ e_{\text{critical}}-e_{\text{safe}})}\right)
$$

- $\|e\|\le e_{\text{safe}}$ → 分子 $\ge e_{\text{critical}}-e_{\text{safe}}$ → 比值 $\ge 1$ → $f_{e}=1$（健康）；
- $\|e\|\ge e_{\text{critical}}$ → 分子 $\le 0$ → $f_{e}=0$（退化）；
- 中间平滑过渡。

**两个因子的"方向"要统一**：都是 $f=1$ 健康、$f=0$ 退化。这是后面能取 $\min$ 的前提。

## 三、$S(t)$：为什么偏偏用 smoothstep

文档定义：

$$
S(t)=\begin{cases}0,&t\le 0\\ 3t^2-2t^3,&0<t<1\\ 1,&t\ge 1\end{cases}
$$

代码 `smoothstep01` 先 clamp 到 $[0,1]$ 再算 $t^2(3-2t)$——与 $3t^2-2t^3$ 是同一个多项式（展开即 $3t^2-2t^3$）。

**关键性质：两端导数为零。**

$$
S'(t)=6t-6t^2=6t(1-t)
$$

- $S'(0)=0$，$S'(1)=0$；
- 中间 $t=0.5$ 处 $S'=1.5$（最大斜率）。

对比三种选择：

| 函数 | 连续性 | 一阶导连续性 | 问题 |
|---|---|---|---|
| 阶跃 $\mathbf 1_{t\ge 1}$ | 不连续 | — | 阈值处跳变，chattering |
| 线性 $\mathrm{clamp}(t,0,1)$ | 连续 | 在 $t=0,1$ 处**不连续** | 参数一阶跳变，加速度冲击 |
| smoothstep $S(t)$ | 连续 | **连续**（两端为 0） | 过渡稍慢，但最平滑 |

**为什么一阶导连续重要**：$f$ 会乘到 $w_{reg}, w_{slack}, v_{scale}$ 上，而这些量又进 QP 的 $P,q$ 和约束。若 $f$ 的一阶导在阈值处跳变，控制输出的一阶导也跳变，等价于**加速度不连续**——对真实执行器就是冲击。smoothstep 保证 $f$ 和 $\dot f$ 都连续，从而控制量至少 $C^1$ 平滑。

**代价**：过渡带内 $S$ 的斜率不大（最大 1.5），所以 $f$ 变化较缓，退化"反应慢"一点。这是平滑性与响应速度的权衡，工程上通常可接受。

## 四、合成总因子 $f=\min(f_\sigma,f_{e,rel},f_{e,obj})$

```cpp
const double f = std::min({f_sigma, f_err_rel, f_err_obj});
```

**为什么取 min 而不是乘积/加权平均**：

- **任一条件触发就退化**（最保守）。比如奇异值很好但误差爆炸，$f_{e}=0$ 会把总因子拉到 0——这是对的，因为大误差下线性化已失真，不该硬推。
- 乘积会让"两个中等健康"变成"不健康"（$0.5\times0.5=0.25$），过于激进；
- 平均会掩盖单点危险（一个 0 一个 1 → 0.5，仍然"半健康"），不安全。

$\min$ 的语义最清晰：**最坏的那个条件决定整体健康**。

## 五、$f$ 如何翻译成三个有效参数

代码（文档第 9 章）：

$$
\begin{aligned}
w_{\text{reg,eff}} &= w_{\text{reg}}\big(1+\text{damp}_{\max}(1-f)\big)\\
w_{\text{slack,eff}} &= w_{\text{slack}}\cdot\max\!\big(0.05,\ 1-\text{slack}_{\text{relax}}(1-f)\big)\\
v_{\text{scale}} &= v_{\min}+(1-v_{\min})f
\end{aligned}
$$

逐个看端点行为：

| 参数 | $f=1$（健康） | $f=0$（退化） | 作用 |
|---|---|---|---|
| $w_{\text{reg,eff}}$ | $w_{\text{reg}}$ | $w_{\text{reg}}(1+\text{damp}_{\max})$ | **阻尼放大**：解更保守/平滑，抑制大关节速度 |
| $w_{\text{slack,eff}}$ | $w_{\text{slack}}$ | $w_{\text{slack}}\cdot\max(0.05,1-\text{slack}_{\text{relax}})$ | **松弛惩罚降低**：允许任务误差被 slack 吸收，不硬顶 |
| $v_{\text{scale}}$ | $1$ | $v_{\min}$ | **速度上限降**：物理限幅直接变小 |

三者共同作用，让机械臂在退化时**"变软"**：

- 不是"停任务"，而是"用更大的阻尼 + 允许更多误差 + 更小的速度上限"来执行；
- 这比硬停更安全（不会突然静止），也比硬推更安全（不会因 $1/\sigma$ 放大而爆速度）。

**为什么 $\max(0.05,\cdot)$**：即使 $\text{slack}_{\text{relax}}=1$，$w_{\text{slack,eff}}$ 也不会降到 0。完全放松 slack 惩罚会让任务完全失效（slack 无限大），保留 5% 下限是"允许误差但不允许放弃"。

**为什么 $v_{\text{scale}}$ 用线性**：速度上限是**硬约束**，不需要平滑（约束本身是硬的），线性足够，且 $f=1$ 时严格等于 1（不引入任何保守性）。

## 六、最关键的取舍：**为什么不降 $k_p$**

代码注释（C2.6）明确说：

> "we deliberately do NOT derate the feedback gain here. Stopping the push when |e| is large was measured to be counter-productive (it freezes the error instead of reducing it)."

直觉：

- 降 $k_p$ = 降低"纠偏意愿"。误差大时本来就需要更强的纠偏，降 $k_p$ 会让误差**冻结**在原地（因为每步只消掉更小比例），反而更危险。
- 降"权威"（阻尼、slack、速度）= 保持纠偏意愿，但**限制执行能力**。误差还是被尽力消除，只是以更保守的方式。

用比喻：**"想不想纠"（$k_p$）不该降，"能纠多快"（权威）才该降。** 这是 C2.6 与"朴素退化"思路的关键区别。

---

## 七、与零空间投影的区别（文档第 9 章强调）

两者都是"高级任务分配"，但**机制完全不同**：

| 维度 | 零空间投影（第 5–7 章） | 连续退化（第 9 章） |
|---|---|---|
| 改什么 | 次级偏好**方向** `dir → N·dir` | QP 的**权重和约束**（$P,q,l,u$） |
| 触发条件 | 始终启用（若 `w_null_*` > 0） | 由 $f<1$ 触发（近奇异/大误差） |
| 数学对象 | 投影矩阵 $N_\lambda$ | 健康因子 $f$ + 三个有效参数 |
| 目的 | 利用冗余做次要优化 | 在困难时**降权威**保安全 |
| 是否影响主任务 | 近似不影响（阻尼泄漏） | **主动影响**（放松 slack、降速） |

**它们可以同时工作**：退化时 $w_{\text{reg,eff}}$ 变大，同时零空间项仍在（但中心权重 `w_center` 不变），两者叠加。文档说"不是同一机制"就是这个意思——不要把 $f$ 当成"另一种零空间"。

## 八、代码对照（按文档符号）

```cpp
// ① 算奇异值
const double sigma_min_rel = sigmaMinRel(kin_, q);        // σ_min

// ② 三个因子
if (params_.enable_singularity) {
    const double denom = std::max(1e-9, params_.sigma_safe - params_.sigma_critical);
    f_sigma   = smoothstep01((sigma_min_rel - params_.sigma_critical) / denom);   // f_σ
    const double e_denom = std::max(1e-9, params_.e_critical - params_.e_safe);
    f_err_rel = smoothstep01((params_.e_critical - e_rel.norm()) / e_denom);      // f_e,rel
    f_err_obj = smoothstep01((params_.e_critical - e_obj.norm()) / e_denom);      // f_e,obj
}

// ③ 合成
const double f = std::min({f_sigma, f_err_rel, f_err_obj});   // f

// ④ 三个有效参数
const double w_reg_eff   = params_.w_reg   * (1.0 + params_.damp_max * (1.0 - f));
const double w_slack_eff = params_.w_slack * std::max(0.05, 1.0 - params_.slack_relax * (1.0 - f));
const double vel_scale   = params_.vel_scale_min + (1.0 - params_.vel_scale_min) * f;

// ⑤ 进入 QP
P_.block<12,12>(0,0) += (params_.w_center + w_reg_eff) * I12;  // 阻尼
P_.block<6,6>(kSRel0,kSRel0) += w_slack_eff * I6;               // slack
const double vlim = params_.v_max[i] * vel_scale * dt;          // 速度上限
```

**注意 `enable_singularity=false` 时**：三个因子保持初值 1，$f=1$，所有 $w_{\text{eff}}$ 等于原值，退化机制**完全旁路**。这是配置开关，不是运行时自适应。

## 九、两个工程陷阱（文档也点了）

**① `w_obj=0` 时 $f_{e,obj}$ 仍在算**

```cpp
f_err_obj = smoothstep01((e_critical - e_obj.norm()) / e_denom);
```

即使物体任务关掉（`object_on=false`、`w_obj=0`），`e_obj` 仍被算、$f_{e,obj}$ 仍参与 $\min$。所以"关掉物体任务"不等于"排除物体误差对退化因子的影响"。文档第 9 章明确提醒："关闭物体任务代价与彻底排除物体误差影响不是同一件事。"

若想彻底排除，应在 `f` 的 $\min$ 里条件性跳过 $f_{e,obj}$——当前代码没这么做。

**② 退化不是"修复 π 附近的物体中点问题"**

文档强调：$\sigma_{\min}$ 病态（运动映射问题）与"相对旋转 π 导致旧物体测地中点非唯一"（姿态定义问题）是**两类不同问题**。连续退化只处理前者，不能靠它修复后者。后者需要改物体姿态定义/微分，不是调 SVD 阈值能解决的。

---

## 十、一句话总结

> **连续奇异退化 = 用两个平滑健康因子（奇异值、误差）合成 $f=\min(\cdot)\in[0,1]$，再用 $f$ 连续地"放大阻尼、放松 slack、降低速度上限"——健康时完全正常，退化时以更保守的方式执行，而不是硬停。关键是 $S(t)$ 两端导数为零保证 $C^1$ 平滑、取 $\min$ 保证最坏条件主导、只降"权威"不降 $k_p$ 保证纠偏意愿不被冻结。它与零空间投影是两套独立机制，可同时工作。**
