## 2. 已实现：连续退化（无硬切换）

```
f_sigma = smoothstep(σ_critical → σ_safe,  σ_min(J_rel))
f_err   = smoothstep(σ_critical → σ_safe,  |e_rel|, |e_obj| 的同一映射)
f       = min(f_sigma, f_err)
```

用 `f` 连续调节三个权限：

| 旋钮 | 形式（f=1 无退化，f=0 最大退化） |
|---|---|
| 阻尼 | `w_reg · (1 + 50(1−f))` |
| 任务 slack | `w_slack · max(0.05, 1 − 0.9(1−f))` |
| 速度上界 | `v_max · (0.5 + 0.5f)` |

## 5. 未解决的根本问题（明确记录）

B 类（`|e|→π`）失效来自我们的一阶误差映射：

```
edot ≈ -Ad(T_err⁻¹) J dq        （实现里隐含 J_r^{SE3}(e) ≈ I）
```

严格关系是 `edot = -J_r^{SE3}(e)⁻¹ Ad(T_err⁻¹) J dq`。
