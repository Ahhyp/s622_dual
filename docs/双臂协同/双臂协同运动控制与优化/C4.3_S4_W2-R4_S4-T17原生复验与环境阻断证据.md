## 2. 为什么不在本环境跑“正式测试”

任务一第 2 条要求“**只有确认处于符合测试条件的原生 Linux 环境后，才执行正式实时测试**”。
本环境三项硬条件（原生内核 / `SCHED_FIFO` / 隔离核）全部不满足；
在 R3 已在同环境做过四组各 6380 周期的实测，最大间隔 15769 / 16009 / 16571 / 21291 µs，
**全部超过 12 ms**，且波动来自 WSL 调度层而非控制器代码。

因此本轮**不重复**已做过的压力测试（重复同一环境不产生新信息，也容易被误读为“又跑了一次”），
而是把阻断证据固定下来，并给出可复制的原生 Linux 复测步骤（见 `C4.3_S4_W2-R3_综合验收矩阵.md` §7，
本轮未改动该节）。

## 5. 解除阻断所需条件（不涉及代码变更）

1. 原生 Linux（非 WSL/容器）主机，内核 ≥ 5.15；
2. BIOS/内核允许 `isolcpus=`（至少 2 个核）；
3. 非 root 可 `SCHED_FIFO`（`/etc/security/limits.d` 的 `rtprio`）；
4. 空载运行（`loadavg < 0.3`），同一套 `test_realtime_budget --gtest_filter='*S4T17*'` 与 CSV 列序。
