## §0 结论

**通过。A1–A15 全部满足**，证据是 12 个 ctest 条目 / 46 个 gtest 用例（0 失败）、7 个场景的全长（638 周期）基线组、以及 5 个上游包 40+23+14+52+5 个用例的回归。

一句话结论：**在 mock 闭环里，用锚定物体帧作物体任务可以把样件沿冻结轨迹搬运到 1e-8 m 量级，而全程抓持关系（相对任务）残差 ≤ 4.3e-5、物体任务残差 ≤ 5.0e-5、锚定帧一致性 ≤ 4.1e-5 m / 8.8e-06 rad、最小净空 0.0131174 m 且零碰撞、零扫掠失败**；相对任务单独运行时样件一步都不动（终点差 6.0e-02 m = 轨迹要求的位移），这正是 S3 必须存在的理由。

同时必须说清**一条硬限制**：这些结论全部在 mock 包内成立。`dual_arm_qp_controller` 有 **12 个死参数**（W0 实测，见 §9.4），yaml 里的 `kp_obj / w_obj / w_slack_obj / enable_singularity …` 从未被读取，因此**生产路径上物体任务与 C2.6 奇异退化至今没有任何入口**。S3 交付的是算法、接口与可复现实验台；把它接进控制器是 S4 的第一件事，且必须先修死参数。

## §7 关键实测量（S4 会直接用到）

1. **`w_obj>0` 必须配 `w_slack_obj ≥ 1e3`。** `w_slack_obj=1e-6`（头文件默认，仅为保持 P 正定）时等效物体权重 ≈ `w_obj·w_slack_obj/(w_obj+w_slack_obj) ≈ 1e-6`，物体任务被 `s_obj` 完全吸收：`gap_toothless = 1.756e-07`，与关掉物体任务无法区分。真实配置（`dual_arm_qp_gazebo_controllers.yaml:60,62`）用的正是 `1.0 / 1e3`。
2. **`w_center=1e-2`（C2 默认）会与任务残差一阶竞争。** 实测（`fastSpec`，63 周期）：

   | `w_center` | `max e_rel` | `max e_obj` | 终点误差 | `max|dq|` |
   |---|---|---|---|---|
   | 0 | 1.1124e-05 | 1.0655e-04 | 1.06e-04 | 4.574e-03 |
   | 1e-4 | 1.6699e-05 | 1.0423e-04 | 9.37e-05 | 4.569e-03 |
   | 1e-3 | 2.0602e-04 | 4.0478e-04 | 6.20e-05 | 4.526e-03 |
   | 1e-2 | 1.6730e-03 | 3.4754e-03 | **1.99e-03（超 1 mm）** | 4.074e-03 |

   `w_center` 从 1e-2 降到 1e-4，权威性（步长）只损失 0.1%，残差降低两个量级。**S3 的全部运行用 `w_center=1e-4`。**
3. **秩与条件数**（`q_grasp12`，`[J_rel; J_O]` 12×12）：`σ_max=2.785634`、`σ_min=7.945620e-02`、`cond=35.05873`、`rank=12`。`J_O` 的右块按构造精确为零（`T̂_L` 只由 `q_left` 决定），堆叠仍满秩。
4. **净空被一对常量自碰撞「钉住」**：`right_wrist3_link <-> wrist_camera_link` 的距离恒为 0.0131174 m（两者之间是固定变换），所以任何「靠降阈值制造净空违规」的注入都不会生效；`robot_world` 才是会动的那个量（0.0314 m）。
5. **`capsule_arm_arm_m = −0.0206`**：胶囊代理在两臂之间本来就重叠，判据只用 FCL 的三条距离（`whole_robot`/`arm_arm`/`arm_proximal` + `robot_world`），胶囊值仅作诊断。

## §8 本轮发现并修正的真实缺陷（12 条）

按「会不会让人得出错误结论」排序：

1. **方案 §2.3.1 的符号推导写反。** 初稿说「`row.e = e_O`、`ff = −v_d`、无需取负」；代入槽位契约 `J dq = +α·row.e` 得 `d(e_O) = +α·e_O` ⇒ 误差**发散**。正确契约由已知正确的相对任务唯一确定：`row.J = J_O`、**`row.e = −e_O`**、**`row.body_twist_ff = +v_d`**，三者同属一个约定，改一处不改其余就变正反馈。已把错误本身写进方案作为警示，并用 T5f（闭环 50 周期单调衰减）+ T5g（`±v_d` 方向、`2v_d` 翻倍）锁死。
2. **QP 头文件的代价注释与代码相反**（`||J dq + α e − s||²` vs 实现出的 `||J dq − α e − s||²`）。注释是给人读的唯一接口说明，且很可能就是缺陷 1 的来源。已按代码订正并标注「comment only, no behaviour change」。
