## 3. 新增 P0/P1

| 级别 | 事项 | 影响 |
|---|---|---|
| **P0-1（新）** | 执行器发起的 HOLD 在控制器已 HOLD 时**永远不能被采纳为冻结**：`TransportTask::hold()` 仅在 RUNNING 时接受，否则回执 `result=2`；执行器此时记 `Done(frozen_by_controller)`。即「执行器请求冻结」路径在竞态下不产生冻结，只是接受既有安全态 | 阻断 T-H15/T-H16 的端到端签署；需契约层决策（审批），本轮未改 |
| P1-1 | 控制器台架类 gtest 在 `colcon test` 下因环境缺 overlay 而 launch 失败；必须在已 `source install/setup.bash` 的 shell 中跑 | 工具链问题，非代码缺陷 |
| P1-2 | `colcon test` 需显式 `LD_LIBRARY_PATH=$PWD/install/lib`（`libdual_arm_collision`→`libfairino_planning_core` 传递依赖） | 已在脚本与文档中标注 |
| P1-3 | R6 的碰撞证据经 `ControllerStatus.failure_code` 注入，状态机无直接 guard 钩子（未新造 ROS 接口） | 证据链为「码级联」而非「模块直连」，如实标注 |
