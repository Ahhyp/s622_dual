## 4. ABI / 兼容性实检（本轮现场编译探针）

```
sizeof(QpSolution)=48 alignof=8
offsetof x=0 converged=16 iterations=20 primal_res=24 dual_res=32 solve_time_ms=40
sizeof(QpProblem)=112
动态符号总数=143；含 solveInto 的符号=2（QpSolver / OsqpSolver 各一）
```

- **源码级兼容**：`solveInto` 是**新增虚函数**，`QpSolution` 布局不变 ⇒ 旧的调用方代码无需修改；`solve()` 语义不变（内部转调 `solveInto`）。
- **字节级不兼容**：vtable 多 1 槽、新增 10 个动态符号 ⇒ 混用新旧对象文件的风险存在（详见 §5 风险）。
- 已实测：用**基线库链接**的调用方程序加载新库并运行 → 正常、`dq` 与基线逐位相同（记录于 `C1_集成记录.md`）。
