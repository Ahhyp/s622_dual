# C4.3 S1 坐标系契约表

**地位**：本文件是 C4.3 正式执行规划 §3.1／§3.2 的细化，是 **W2 交付物 D2**。
**性质**：可判定条款。每一项都必须有**唯一解释**；凡本文写死的约定，代码与测试不得另立一套。
**上游**：`C4.3_正式执行规划.md`（唯一执行基准）、`C4.3_S0_审计报告.md` §A14（S1 方案）。
**下游**：`grasp_geometry.hpp` / `object_frame.hpp` / `closure_residual.hpp` 及其单测。

## 1. 坐标系与符号

| 符号 | 含义 | 来源／落点 |
|---|---|---|
| `W` | world frame | Gazebo／MoveIt 世界系，Z 轴向上 |
| `O` | 物体 frame | **任务给定** `T_WO,d(t)`，见 §2 |
| `L` / `R` | 左／右臂 TCP（即 grasp frame） | `T_WL(q_L)` / `T_WR(q_R)`，由 DH 正运动学给出 |
| `G_L` / `G_R` | 抓持时**冻结**的 TCP→物体常数变换 | `G_L = (T_WO*)⁻¹ T_WL*`，`G_R = (T_WO*)⁻¹ T_WR*` |
| `T̂_{O,L}` / `T̂_{O,R}` | 左／右**锚定**物体位姿估计 | `T̂_{O,X} = T_WX · G_X⁻¹` |
| `ξ̂_{O,X}` | 锚定残差 | `log( (T_WO,d)⁻¹ T̂_{O,X} )^∨ ∈ ℝ⁶` |
| `e_closure` | 双臂闭环残差 | 见 §6 |

**条款 1.1**：`G_L`、`G_R` 是**常数**，只在抓持确立时标定一次，之后**不随 `q` 变化**。
落点 `GraspGeometry::object_T_left_tcp` / `object_T_right_tcp`。

**条款 1.2**：冻结的相对抓持 `T_rel* = G_L⁻¹ G_R = (T_WL*)⁻¹ T_WR*`。
落点 `GraspGeometry::leftTrightStar()`。

**条款 1.3**：`G_L ≠ G_R`。两者相等属退化抓持（两个 TCP 重合），必须被拒绝而不是继续。
落点 `GraspGeometry::validate()`；单测 `GraspGeometry.RejectsIdenticalLeftAndRightGraspTransforms`。

## 2. `T_WO,d` 来自任务，**不是**对称测地中点 ★

**条款 2.1**：C4.3 的物体系由**任务轨迹**给定。**禁止**用 C2 的 `worldTobject()`
（两 grasp frame 的对称测地中点）作为 C4.3 的物体位姿来源，也禁止用它反推 `G_L/G_R`。

**理由（实测，非推断）**：中点算法对两个相差 π 的旋转做测地平均，在 `‖ξ_rel‖ → π`
时病态，实测相对误差 **66%／86%／74%**（§A14.1）；而**双端夹爪从两端夹同一物体时
`‖ξ_rel‖` 天然 ≈ π**，C4.2 仿真里双臂镜像 home 位形实测**精确等于 π**。

**条款 2.2**：锚定估计 `T̂_{O,X}` 是物体位姿的**反馈量／观测量**，**不是**它的定义。
不得出现"先算中点、再用中点定义物体系"的循环。

**条款 2.3**：中点接口在**正常构型**下仍被 C2／C4.2 使用，S1 **不修改它的数值语义**（见 §8）。

## 3. twist 约定：**body twist**（不二选一，已定死）

**条款 3.1**：`V^b = (T⁻¹ Ṫ)^∨ = [v^b ; ω^b] ∈ ℝ⁶`。

**条款 3.2**：**明确排除** spatial twist `(ṪT⁻¹)^∨`。两者**不可混用**。

**理由**：`relativeJacobian` 已是 body 约定且实测处处精确（含 π，最差 `4.6e-8`）；
物体任务沿用同一约定后，`e_rel` 与 `e_obj` 的 QP 行**直接可比**，无需在雅可比之间插 Adjoint。

**条款 3.3**：`v^b` 是**物体原点**的速度在**物体自身坐标系**下的表达；`ω^b` 是物体角速度
在物体坐标系下的表达。不要把它们误读为 world 系表达。

> ⚠️ **踩坑记录**：本次 S0 审计中第一版探针把 body 误差当成 spatial 误差比较，
> **得出过假结论**（误判锚定形式在 π 处也错）。两种约定必须写进测试注释。

## 4. 行排列

**条款 4.1**：`V^b = [v_x, v_y, v_z, ω_x, ω_y, ω_z]ᵀ` —— **平移在前、旋转在后**。

**条款 4.2**：该排列与仓库既有 `relativeJacobian` / `objectJacobianBody` 一致。
S1 内以下标常量固定，**不依赖"惯例"**。

**条款 4.3**：误差向量沿用同一排列，且**平移与旋转分量必须分开返回**（m / rad），
**不返回混合标量**。落点 `ClosureResidual{translation, rotation, translation_m, rotation_rad}`。

## 5. 锚定估计、参考点搬运，与对 §A14.2b(d) 的更正 ★

### 5.1 估计
```
T̂_{O,L} = T_WL · G_L⁻¹
T̂_{O,R} = T_WR · G_R⁻¹
```
落点 `anchoredObjectPose(world_T_tcp, object_T_tcp)`。

### 5.2 twist 映射 —— **没有负号**（更正 §A14.2b(d)）

推导：`T̂ = T_WX G_X⁻¹` ⇒ `T̂⁻¹ T̂̇ = G_X (T_WX⁻¹ Ṫ_WX) G_X⁻¹` ⇒

```
V̂^b_{O,X} = Ad(G_X) · V^b_X
```

**条款 5.2.1**：映射是 **`+Ad(G_X)·J_X`**。
§A14.2b(d) 手推的 `-Ad(G_L)` 是**错的**——当时把"残差的符号"错误地带进了"位姿的映射"。
本次以独立有限差分确认为 `+Ad(G_X)`，落点
`anchoredObjectTwistJacobian(J_body, G) = adjoint(G) * J_body`。

> 这正是 §A14.2b(d) 那句"**符号约定在 S1 内用有限差分确认，不靠推导结论直接采信**"
> 所要求的动作，现在执行完毕。

### 5.3 误差与变化率 —— 全局精确式

**条款 5.3.1**（解耦误差定义）：
```
e(T̂, T_d) = [ R_dᵀ (p̂ − p_d)  ;  log( R_dᵀ R̂ ) ]  ∈ ℝ⁶
```
前 3 行单位 **m**，后 3 行单位 **rad**。落点 `decoupledPoseError`。

**条款 5.3.2**（变化率）：
```
ė = A(T̂, T_d) · V̂^b ,        A = [  R_dᵀR̂            0                ]
                                   [    0        J_r⁻¹( log(R_dᵀR̂) )   ]
```
推导（两行独立）：
- 平移行：`ė_pos = R_dᵀ ṗ̂ = R_dᵀ R̂ v̂ = (R_dᵀR̂)·v̂` ✓
- 旋转行：`d/dt log(R_dᵀR̂) = J_r⁻¹(log(R_dᵀR̂))·ω̂`（`R_d` 固定，取 `R̂` 的 body 角速度）✓

落点 `decoupledErrorRateMap`，以及

```
J_{O,X}(q_X) = A( T̂_{O,X}, T_d ) · Ad(G_X) · J_X(q_X)          ∈ ℝ^{6×6}
```
落点 `anchoredObjectErrorJacobian`。

**条款 5.3.3 ★ 这是本表比 §A14.2b(d) 更强的一条**：`A` 里的 `J_r⁻¹` 只依赖
`log(R_dᵀR̂)`，其**奇异在 2π，不在 π**。因此上式是**全局精确**的，
**不要求残差小**。§A14.2b(d) 里"`-Ad(G_L)` 只是零残差附近的形式、必须再左乘
`Ad((T̂_{O,L})⁻¹ T_WO,d)`"的说法**不再需要**：那一项已经被解耦形式吸收进 `A`。

**实测证据（大残差工况，落 `test_object_jacobian_pi.cpp`）**：`T_d` 相对当前位姿平移
8–13 cm、旋转直到 π，中心差分一致到 **`2.6e-7`**（一般姿态 `3.3e-10`）；
近 π 处改用前向一致性（`O(h²)` 比值实测 **4.00**）以避免差分算子自身的病态。

### 5.4 为什么解耦形式 π 安全（根因，必须理解）

| | 对称测地中点 | 锚定＋解耦 |
|---|---|---|
| 对相差 π 的旋转做**平均** | ✅ 是 → log 的 π 二义性进入**被平均的量本身** | ❌ 不做平均 |
| log 的 π 二义性影响什么 | 物体位姿**本身**（66–86% 误差） | 只影响 `e_closure` 的**方向**；**幅值仍精确** |
| 雅可比是否 π 安全 | ❌ 实测 195% 最坏方向失配 | ✅ ≤`5.6e-10` |

**条款 5.4.1**：锚定形式只把**同一个物体位姿**用两条独立运动链各推算一次，再做**差**。
π 处每侧的**幅值**是精确的，只有单位方向向量有二义性 ⇒ 用
`ClosureResidual::rotation_direction_ambiguous` 单独标记，**不影响 Jacobian**。

## 6. 闭环残差

**条款 6.1**：
```
e_closure = log( (T̂_{O,L})⁻¹ T̂_{O,R} )^∨ ∈ ℝ⁶
```
落点 `closureResidual(object_L, object_R)`。

**条款 6.2**：平移行 = `R_Lᵀ (p_R − p_L)`，即**原始 frame 差**（单位 m），
**不是** `logSE3` 的线性部分 `J_l⁻¹·t`。契约按原始差定义，因为它更接近真实的相对位置测量。
两者的关系被**固定在测试里**：`t == J_l(φ) · logSE3(Δ).head<3>()`
（单测 `ClosureResidual.MatchesTheLogSE3Definition`，实测 `1.8e-15`）。

**条款 6.3**：旋转行 = `log(R_Lᵀ R_R)`（单位 rad）。
另提供 `position_gap_m = ‖p_R − p_L‖`（**与 frame 无关**，便于与视觉/激光测量直接比）。

**条款 6.4 ★**：`e_closure` **只能作为一致性监测／故障判据**，
**不得**再作为独立 QP 任务与 `e_obj` 叠加——`e_closure = ξ̂_{O,L} − ξ̂_{O,R}` 与
`e_obj` 线性相关，叠加会使 `J Jᵀ` 奇异。

**条款 6.5**：误差变化率雅可比 `closureErrorJacobian(object_L, object_R, J_{O,L}, J_{O,R})`
已在 S1 内实现并由有限差分验证（100 个位形，最大绝对差 `2.6e-7`）。
**该测试在开发中抓出过一个真实的符号错误**（见 §11 的 C-S1-2），是它存在的理由。

## 7. 左锚定 ≠ 固定左臂 ★（用户批复第 2 项明确要求澄清）

**条款 7.1**："左锚定物体任务"**只表示**用左臂推算的物体位姿 `T̂_{O,L}` 作为物体任务
的**反馈量**，**不表示左臂被固定**。两只臂仍然是两个独立的 6-DOF 决策变量。

**条款 7.2**（双臂如何协同）：
```
主任务（相对位姿约束）  e_rel  : T_WL⁻¹ T_WR → T_rel* = G_L⁻¹ G_R
物体任务（锚定）        e_obj,L: (T_WO,d)⁻¹ T_WL G_L⁻¹ → I
```
- `e_obj,L` 只约束「左臂 + 物体」这一条链；它**不会**让左臂不可动——
  `T_WO,d(t)` 是时间的函数，左臂照样跟随期望轨迹运动；
- 右臂**通过 `e_rel` 参与**：「两臂必须保持 `T_rel*`」这条硬约束把右臂锁定为左臂的函数；
- 若只用 `e_obj,L` 而**不加** `e_rel`，右臂完全不受约束（自由臂）——
  **这正是 C4.2 交接位优化要解决的那个自由度**，也是两条任务必须同时进 QP 的原因。

**条款 7.3**（S1 内可判定的机械化形式，落 `test_anchored_object_frame.cpp`）：
| 断言 | 实测 |
|---|---|
| `∂ T̂_{O,L} / ∂ q_R = 0`（左估计对其他臂**完全免疫**） | 精确 `0.000e+00` |
| `∂ T̂_{O,R} / ∂ q_L = 0` | 精确 `0.000e+00` |
| `∂ T̂_{O,L} / ∂ q_L ≠ 0`、`∂ T̂_{O,R} / ∂ q_R ≠ 0` | `3.0e-6` / `5.5e-6` |
| `e_closure` 对 `q_L` **和** `q_R` **都**有响应（耦合就在这里） | `1.9e-7` / `3.8e-7` |
| 刚体抓持时 `e_closure = 0`（两个独立估计一致） | `3.8e-16` |
| 左锚定物体任务**满秩 6**（可指令全部 6 个物体自由度） | `100/100`，`min σ = 1.19e-5` |

⇒ 「左锚定」的作用域被限制在**估计的来源**上；两臂耦合由 `e_closure`／`e_rel` 承载。

## 9. 旧对称中点接口的病态检测（用户批复第 1 项）

**条款 9.1**：旧接口**允许**在其奇异区显式拒绝或报告失败——但**不允许静默返回一个错值**。

**条款 9.2**：判据阈值
```
kMidpointSafeMinMarginRad = 1.5e-3 rad
isMidpointSafe(WL, WR)  :=  (π − ‖log(R_Lᵀ R_R)‖) > 1.5e-3
midpointUnsafeReason(...) 返回可读原因串
```
**阈值来历（实测，不是拍脑袋）**：要把中点误差压到 `1e-4` 需 `π − ‖ξ_rel‖ > 1.5e-3 rad ≈ 0.086°`。
双端夹持不可能保证 0.086°，所以**不能用"避开 π"来救 C4.3**——这正是新接口必须支持 π 的原因。

**条款 9.3**：该检测器**只**加在新头文件里，**不修改** `worldTobject`／`objectJacobianBody`
本身（避免影响 C2／C4.2 的现有调用）。

**条款 9.4**：新接口（任务给定物体系 + 左右锚定）**必须支持 `‖ξ_rel‖` 恰好等于 π**，
且在此处**精确**（实测 `2.6e-10`）。**不允许**通过限制 C4.3 抓持姿态来避开 π。

## 10. 日志要求（对齐 §3.2 的防作弊规则）

**条款 10.1**：每次试验必须**分别**记录 `T̂_{O,L}` 与 `T̂_{O,R}`（各自的位置 + 姿态），
以及 `e_closure` 的**平移分量（m）与旋转分量（rad）分开**。

**条款 10.2 ★**：**禁止**只记录"被显示物体的跟踪误差"。仿真里物体的运动学状态是
**理想抓持代理**（§4.4），它的误差**恒为 0 或由代理定义**，看它等于自证。
`e_closure` 由**左右两条独立链**算出，是唯一能发现"仿真在骗人"的量。

**条款 10.3**：时间标记一律记**消息 header stamp（仿真时基）**，并**同时**记墙钟；
**不要依赖 `now()`**（S0 审计 §A8 已定）。
