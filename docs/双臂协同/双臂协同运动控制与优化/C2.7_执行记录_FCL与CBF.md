## 1. C2.7a：FCL 距离模型

- 用 **DH 中间 frame**（0-1, 1-2, …, 5-6）为每条臂生成 **6 个 capsule**（半径可配，默认 0.06 m）
- 36 对 capsule 求最小距离（FCL `distance`），返回距离 / 最近点 / 法向 / 命中连杆
- `distanceGradient`：对**当前最近的一对**做中心差分（12 次单对查询）

| 验证 | 结果 |
|---|---|
| 最近点一致性 `\|\|p2−p1\|\| == d` | **2.22e-16** |
| 梯度 vs 全对有限差分 | **1.11e-12** |
| 沿 +梯度走一小步距离增大 | **63/63** |
| `distanceGradient` 耗时 | **38.8 µs/call** |
| 穿透 | FCL 返回**负距离**（=穿透深度），300 随机构型中 8 个交叠 |

## 2. C2.7b：离散 CBF 接进 QP

我们的决策变量是**一步增量** `dq`（不是速度），所以 CBF 必须离散推导：

```
h(q) = d(q) − d_safe ≥ 0
ḣ + α h ≥ 0,   ḣ = ∇d · q̇ = ∇d · dq/dt
=>   −∇d · dq  ≤  α h dt          ← 作为一行 C_ineq/d_ineq 注入
```

（`C_ineq` 是 C2.2 预留的通用不等式接口，无需改 QP 形式；因为 k>0，C2.R3 的 post-solve clamp 自动跳过。）

### 闭环对照（起始距离 0.58 m，`d_safe = 0.10 m`，目标把两爪拉近到 0.25×）

| | 最小距离 | 低于 d_safe 的步数 | 相对任务误差 |
|---|---|---|---|
| CBF **OFF** | **−0.0156 m（穿透）** | **462 / 500** | ~0 |
| CBF **ON** | **0.1169 m** | **0 / 500** | ~0 |

→ CBF 在**不牺牲相对位姿**的前提下避免了碰撞：它利用 6 维零空间换了另一组无碰撞姿态。
这正是"约束优化"相对"阈值停机"的价值。

## 3. C2.7c：独立安全层（不押注 CBF）

GPT 的提醒："不要把生命全押在 CBF 数学约束上"。因此在 ros2_control 控制器里加了
**独立硬阈值**（不走 QP、不走 CBF）：

```
每拍测 d(q)；若 d < collision_d_stop  →  双臂 HOLD（并 ERROR 日志）
```

- 参数：`collision_d_stop`（0=关闭）、`collision_link_radius`
- 与 D7 共用 hold 路径，**独立于 QP 求解是否成功**

⚠️ 目前只有"硬停"，**两级阈值（减速 + 停机）里的"减速"尚未实现**。

## 4. 边界与已知简化

1. capsule 是**简化几何**（等半径圆柱+半球），不是真实网格；真实碰撞体需要从 URDF 加载 mesh 到 FCL。
2. 只监控**双臂之间**，未含环境/桌面/物体。
3. `distanceGradient` 假设最近点对在差分步长内不变（近接触时可能失准，测试里已跳过 `d<0.10` 的样本）。
4. 视觉障碍（YOLO + 外推）属 C3.6。
