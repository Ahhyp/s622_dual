## 0. 一句话

在 S4 的候选池上做**局部精化**（V0 只动位置、V1 再加旋转向量范数 ≤10° 的姿态扰动），
把交接位从 M4 基线挪 **12.9 cm**；给出**待机位**（用"关节空间线段可行性"评价，不叫规划成功率）

## 3. 待机位

**⚠️ 指标命名**：规划里写的是"无碰撞**规划**成功率"。本阶段手上只有
`isSegmentValid`（**关节空间直线插值采样**），**不是运动规划器**，因此全程改称
**「关节空间线段可行性率」**，绝不写成"规划成功率"。这对应之前讨论的 (a) 方案。

| 项 | 值 |

| 从 C4.1 采样的候选池 | 6000（这些构型在 C4.1 里已被限位/地面/臂距过滤过） |

## 4. 协同区（cooperative zone）

**定义**：使 **S4 成立**的物心集合（V0 分层：姿态固定 = M4 姿态）。

| 项 | 值 |
|---|---|
| 体素数（2 cm） | **9839** |
| 等效体积 | **78.7 L** |
| bbox | x ∈ [−0.221, 0.413]，y ∈ [−0.488, 0.544]，z ∈ [0.035, 0.441] |
| 连通分量（2 cm，26 邻接） | **1 个**（见下方分辨率说明） |
| 最优子区 | 即整个分量：均值 score 0.7467，最高 0.86 |

**⚠️ 这条结论依赖体素分辨率，S7 已更正**（当时写成"协同区是单连通的"，**属于过度声称**）。
补做的分辨率/邻接敏感性：

| 体素 | 26 邻接 | 6 邻接 |
|---|---|---|
| 1.0 cm | **524 个分量**（最大者占 93.8% 体素） | 5913 个（最大 46.9%） |
| 1.5 cm | 41 个（最大 99.7%） | 702 个（最大 91.7%） |
| **2.0 cm** | **1 个** | 36 个（最大 99.5%） |
| 3.0 cm | 1 个 | 2 个 |
| 4.0 cm | 1 个 | 1 个 |

**正确表述**：协同区有**一个占绝对主导的连通区域**（1 cm 下即占 93.8% 的体素），
而不是字面意义上的"单个连通分量"。**"可连续走通"的结论仍然成立**（主体区域是连通的），
但"没有孤岛"不成立 —— 细分辨率下存在大量微小碎片。
对 C4.3 的可用结论是：**主体区连通、可连续规划，边缘有碎片需按体素尺寸约定处理**。

**与 C4.1 CRW 的关系（★ 定义修正）**

规划验收写的是"协同区 ⊆ CRW"。但：**CRW 是 TCP 点的集合，协同区是物心的集合**，
两者之间**不存在字面意义上的子集关系**。可断言的是：**协同区的每个候选都在 S0 层内**
（两个诱导 TCP 都落在各自臂的点可达掩码里）。

实测：**99.1%**（27934/28192）的物心落在 TCP 空间 CRW 的体素内；
而 **171 个 S4 候选（0.6%）的两个诱导 TCP 不在 C4.1 的采样掩码内** ——
这是 **C4.1 采样的覆盖缺口**（S0 只是代理，IK 才是更强的判据），不是逻辑矛盾。
协同区画在 CRW 轮廓之内（见 fig6），视觉上完全落在里面。

## 5. ★ 顺带修掉的一个自检缺陷（S3 遗留）

S3 的嵌套自检原本是**计数比较**：

```cpp
all.s4 <= all.s3 && all.s3 <= all.s2 && all.s2 <= all.s0   // 弱得多
```

这**不是**"S4⊆S3⊆S2⊆S1"这个命题——总数满足不代表每个候选都满足。
S5 期间检查 CSV 时发现 `S4 but not S0` 有 171 个，才把这个弱点暴露出来。

**已改成逐候选检查**（`Funnel::nested_violations`），实测：

```
per-candidate nesting S4 => S3 => S2 => (S1_L and S1_R); violations = 0/233288   PASS
```

**规划要求的 S4⊆S3⊆S2⊆S1 现在是真正被验证的**（0 违反）；
同时把 `S4 ∖ S0` 的 171 个作为**覆盖缺口**单独报告，而不是当成嵌套违反。

## 8. S5 的边界

1. **"可到达"仍未验证**：线段可行性只是**代理**，不是运动规划；已在命名与报告里显式区分。
2. **待机位指标只做了 (a)**：真规划器对照（方案 (b) 的一致性表）未做。
3. **局部精化增益很小**（§1），S4 池承担了主要优化。
4. **协同区是 V0 分层下的**（姿态固定 = M4 姿态）；V1 的协同区未单独重新体素化。
5. **Q1–Q4 未确认**、基线是 `provisional_rebuilt`，结论不得宣称适用于真实 M4 杆。
6. **未做**：S6 的消融/敏感性/多种子、S7 的总可视化与文档。
