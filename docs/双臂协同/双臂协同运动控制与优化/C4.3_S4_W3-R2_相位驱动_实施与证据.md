## 2. 相位语义（实现即文档）

- `mark` 式前缀累加：`PhaseDriver` 由**相位时长表**构建累积边界 `starts_[n+1]`，`indexAt(t_traj)` 用半开区间 `[starts_i, starts_{i+1})` 定位（末相位闭合）。
- **只允许 +1**：`observeLocal()/observeExternal()` 只在 `idx == index_ + 1` 时报 `Entered`；跳跃或回退报 `Desync`，调用方（状态机）立即 `HOLD("phase_desync")`。
- **未知相位名**：`isKnownPhaseName()` 白名单（`approach/lift/transport/lower/settle*`），未命中报 `UnknownName` → `HOLD("phase_name_mismatch")`。
- **中途加入**：首个观测不在 phase 0 时同样报 `Desync`（无法证明前序相位跑过）。
- **映射**：`approach→APPROACH`、`lift→LIFT`、`transport→TRANSPORT`、`lower→LOWER`；`settle*` 无状态映射，只记 `kind="phase"` 事件、不迁移。
- **前向补齐**：若目标状态在当前位置之后，逐级 `advance()`（最多 8 级），保证不跳级、不逆行；若执行器已领先于控制器相位则 `Desync`。
- **超时**：沿用 `checkTimeout()`（`phase_timeout_scale × duration`），相位驱动不新增超时路径。
- **兼容**：未挂驱动时 `phase_driven == false`，`tick()` 走原 W3-R1 的「轨迹到端点才推进」规则（由 `DetachingTheDriverRestoresTheW3R1Behaviour` 断言）。
