# C4.3 S4.1 W2-R3 任务3：ULP 候选 V1 独立验证报告

> 结论先行：
> 1. **候选 V1 本轮不生效**，W2 原判据（逐周期 `dq` ≤1 ULP）**仍为 FAIL**；
> 2. V1 的三项主要指标（`max|Δdq| ≤ 1e-6 rad`、`max|Δt| ≤ 1e-6 s`、末端 ≤1 mm）中，
>    **前两项的工程依据可由累积量重新推导**（本文 §3），第三项直接沿用 S3 验收 A1；
> 3. 但 V1 里“**对应编码器分辨率**”这一条**无依据可查**（无硬件/URDF 编码器数据）⇒ 该论据**作废**，
>    不得再作为阈值来源引用（`THRESHOLD_UNJUSTIFIED`）。

## 1. 三个阈值的独立溯源

| 阈值 | 出处 | 是否本轮新造 |
| --- | --- | --- |
| `max|Δdq| ≤ 1e-6 rad` | V1 侧；原 W2 侧是 §5 W2 行“`dq` 位相同（≤1 ULP）” | V1 新提，本文复核 |
| `max|Δt| ≤ 1e-6 s` | V1 侧 | V1 新提，本文复核 |
| 末端 ≤ 1 mm | **`docs/双臂协同/双臂协同运动控制与优化/C4.3_S3_验收记录.md:66` A1**：“跑完冻结轨迹，终点 `≤1e-3 m` / `≤1e-3 rad`”，实测 `ff_1` = 2.972e-08 m / 2.750e-10 rad | **沿用，非新造** |

## 2. `dq` 的物理意义与单位

- `DualArmQpResult::dq` = 本周期 12 关节的**位置增量**（rad），`q_{k+1} = q_k + dq_k`（两阶段提交后）；
- 冻结件 `s3_ff_1_dq.csv` 的 `dq` 列与 `q_prev` 列满足 `q_prev[k] + dq[k] == q_prev[k+1]` **逐位成立**（已核验）；
- 因此 `Δdq` 的单位是 rad，`1e-6 rad` 是“单周期增量差”。

## 3. 阈值能量级复核（本文的独立推导，非引用 V1）

设 638 周期全部偏差同号，则累积：

| 指标 | 累积最坏值 | 折算到末端直线位移 | 占 1 mm 的比例 |
| --- | --- | --- | --- |
| `1e-6 rad` × 638 | 6.38e-4 rad | × 力臂 0.05563 m（`G_L` 平移 `(0.0497, 0, 0.025)` 的模）= **3.55e-5 m** | **3.6%** |
| `1e-6 s` × 638 | 6.38e-4 s | × 轨迹速度 0.0333 m/s（`translate` 相位 0.05 m / 1.5 s）= **2.13e-5 m** | **2.1%** |

⇒ 两项阈值即使按“全部同号累积”这一最坏假设，也只吃掉 1 mm 预算的 3.6% 与 2.1%，**量级合理**。

**原 `1e-12 m` 绝对阈**：无任何累积推导或硬件依据，属**经验取值** ⇒ 标 `THRESHOLD_UNJUSTIFIED`。

## 4. `Δt` 的计算路径

- 冻结件 `t` 列为 `t = k·dt`（`k = 0..637`），`Δt = t_mine − t_baseline`；
- 实测 `max|Δt| = 3.553e-15 s`（≈ 16 ulp of 5.1），来源是 `k·dt`（乘）与控制器 `t += dt`（累加）的浮点路径差异，**不是时间语义差异**；
- 决定性实验（`test_ulp_semantics.cpp::S4T2_DifferenceIsTheTrajectoryClockNotTheSolver`）：用基线规则 `t = k·dt` 重算 638 周期 → 与冻结件 `dq` **逐位相同**；换成控制器规则 → 差异出现 ⇒ 差异**可完全归因于时钟表达式**。

## 5. 覆盖性与“近零/符号/翻转是否掩盖问题”

- 覆盖：638 周期 × 12 关节 = 7656 对，全部统计；
- 实测 `max|Δdq| = 9.024e-14`（cycle 6, joint 6；mine `-1.8145642984102369e-14` vs baseline `7.2097585154607034e-14`）；
- 该关节两任务都要求“别动”，`dq≈1e-14`，因此 1 ULP 比较的是两个不同的取整方向，ULP 距离 2.08e5；
- **近零退化**：`ulpDistance` 用 `int64` 位型单调映射，跨零号对会被映射到两端，最坏样本 `8.7e-324` vs `8.4e-324` 得 4.69e20 ULP ⇒ **该指标在近零区不可用**，这是它不能当硬判据的独立原因（与时钟差异无关）。

## 6. 与安全不变量是否冲突

- 同批次实测：`active_limit_count = 0`（无关节贴箱）、`σ_min(rel) = 7.945620e-02`、`cond = 35.06`；
- 说明 `1e-6 rad` 的容差下不会掩盖任何限位或奇异事件（这些事件本身有独立判据）。

## 7. 判定

| 项 | 判定 |
| --- | --- |
| V1 是否生效 | ❌ **未生效**（仅验证，未改任何测试预期与生产代码） |
| 原 W2 判据（≤1 ULP） | ❌ **仍 FAIL**（保持原样，未改写、未删除历史失败证据） |
| S4-T3 的 `== 0` | ✅ 不受影响，本轮复跑仍成立 |

| “编码器分辨率”论据 | ❌ **无依据**，作废 |

## 8. 未验证事项

1. 力臂取 `|G_L| = 0.05563 m` 是**抓持点到物体中心**的距离；若改用“物体到末端执行器的最远点”，数值会变大（最多 ×3），结论不变（仍 <11%）；
2. 未验证不同编译器/`-ffast-math` 下 `max|Δdq|` 是否仍 ≤1e-12（本轮 9.024e-14）。
