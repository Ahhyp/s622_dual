## 2. 本轮新增的决定性根因（独立复核结论）

### 2.1 事实链

| 步骤 | 证据 |

| S3 基线产物来自哪个版本 | `runs/c43_s3/w8/ff_1/cycles.csv` 的 PROVENANCE 记 `source git_head = 6e5cb262…` |

### 2.2 结论（三分法）

1. **非数学不可能**：同构建逐位一致证明位级可重复。
2. **现有架构下不可实现**：`≤1 ULP` 要求 S4 的物体行装配与 S3 legacy 逐操作一致；而 S4 已按 `0026130` 的设计改用外部锚定行（这是 S3 之后的产品演进，`w_obj` 与符号约定都被重写）。
3. **超授权**：唯一"修好"的办法是回退物体行装配约定（或让外部行逐操作复刻 legacy 表达式），属产品语义回退，超出本轮授权。

> 因此"7656/7656 超限"**不是回归**，是判据把"跨接口代际"当成了"同实验复现"。

### 2.3 与早前"五假设"的关系

时钟（7.18e-16）、warm start（7656/7656 零影响）、工作区（5.27e-16）都解释不了 9.02e-14；本轮给出解释：差异来自**装配路径**，其量级由 1e-13 级的近零 `dq` 条目放大成 1e9+ ULP（ULP 是相对度量）。
