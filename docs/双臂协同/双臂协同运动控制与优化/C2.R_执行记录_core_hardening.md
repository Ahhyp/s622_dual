## 1. R1 — OSQP 持久 workspace

**问题**：`OsqpSolver::solve()` 每拍都 `dense→CSC + malloc + osqp_setup + cleanup`。

**修改**：
- PIMPL 藏住 OSQP 类型（公共头不再泄漏 OSQP 依赖）
- 稀疏模式**固定**：P = 稠密上三角（n(n+1)/2），A = 稠密（m×n）
- `osqp_setup()` 只在结构 (n,m) 变化时调用一次；稳态只做
  `osqp_update_P_A + update_lin_cost + update_lower/upper_bound + warm_start_x + osqp_solve`
- 暴露 `setupCount()` 供测试断言

**中途抓到的 bug**：改版后把顺序写成"先 `osqp_setup` 再填 l/u"，OSQP 校验未初始化数据直接拒绝
（`Lower bound ... greater than upper bound`），部分 solve 静默不收敛。
修为 **alloc → fill → setup**。

**验收**：`test_qp_benchmark` 断言 `setupCount() == 1`（100k 周期不变）。

## 2. R4 — 100k 周期统计

| 指标 | `-O3` 前 | **`-O3` 后** |
|---|---|---|
| 100k 周期墙钟 | 56.7 s（1762 Hz） | **5.7 s（17457 Hz）** |
| solver mean | 0.0968 ms | **0.0530 ms** |
| solver median | 0.0907 ms | 0.0504 ms |
| solver P95 | 0.1275 ms | **0.0663 ms** |
| solver P99 | 0.1804 ms | **0.1011 ms** |
| solver max | 9.39 ms（含首次 setup） | 0.4725 ms |
| 完整管线(装配+solve) P99 | 0.9434 ms | **0.1075 ms** |
| iterations | mean 25 / max 25 | mean 25 / max 25 |
| failures | 0 | **0** |

顺带修正：benchmark 增加 **warm-up 一拍**（把一次性 `osqp_setup` 排除出统计），所以 max 从 9.39 ms 降到 0.47 ms。

| 操作 | 未优化 | `-O3` |
|---|---|---|
| DH FK | 15.2 µs | **0.28 µs** |
| DH Jacobian | 8.2 µs | **0.30 µs** |
| `left_T_right` | 43.0 µs | **0.60 µs** |
| `J_rel`(6×12) | 112.6 µs | **1.89 µs** |

**装配零分配**：`DualArmQp` 的临时矩阵改为预分配 scratch（`A_task_/P_/q_cost_/lower_/upper_` + 仅在 k 变化时 resize 的 `A_scratch_`），控制路径不再有堆分配。

## 3. R2 — 时间语义

**问题**：`update()` 丢弃 `period`，QP 恒用 `dt=8ms`。

**修改**：
- 新增 `PeriodMonitor`（ROS-free，4096 窗，零分配）：测**实际**周期，给 mean/P95/P99/max/overrun 统计
- 超期判据：`period > nominal × period_fault_factor`（默认 2.0，即 >16 ms）
- **超期 → 直接进 D7**（两臂 hold），让 scheduler stall 成为健康监控的一部分
- QP 本身仍按 `dt_nominal` 建模（保守：实际更长时速度上界更保守）
- 控制器每 10 s 打一行周期统计（低频，不进 RT 热路径）

**单测** `test_period_monitor.cpp`：标称不报、超期报、混合窗 P50/P95/P99、非有限回退、窗有界。

## 4. R3 — post-solve clamp

**问题**：逐关节 clamp 只对 box 成立；加入一般不等式（CBF）后会破坏 `C·dq ≤ d`。

**修改**：clamp **只在无一般不等式行（k==0）时执行**；k>0 时返回 solver 原值并注明原因（C2.7 需要真正的投影/降级策略）。

**测试** `DualArmQp.GeneralInequalityPreservedWhenClampIsSkipped`：
约束 `dq_0 ≤ −0.01`（注意 d<0，**原点都不可行**，origin-scaling 投影同样会错），
实测 `dq_0 = −0.010000`、收敛、box 仍满足。
