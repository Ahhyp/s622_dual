## 0. 结论先行（五条）

1. **共同可达空间被压缩在中线走廊里，只剩单臂的 36%。**
   左臂球心在 x=+0.35、右臂在 x=−0.35，各自半径约 0.75 m。2 cm 体素统计：
   单臂可达体各 **1.18 m³**，交集 CRW 只有 **0.43 m³（36.4%）**，
   且 3D bbox 被压在 **x ∈ [−0.42, 0.40]**、y ∈ [−0.69, 0.69]、z ∈ [0, 0.82]。
   → **双臂协同/交接在空间上被限制在一条走廊里**，这不是设计选择，是几何必然。

2. **"两只手能同时凑近"的构型极少。** TCP 间距 ≤ 0.35 m 的构型只占 **3.86%**（≤0.25 m 占 1.30%，
   ≤0.45 m 占 8.66%）。交接位不是"随便挑一个共同可达点"，而是共同可达空间里的一个**小测度子集**。

3. **零空间维度在 1e7 样本里恒为 6。** 数值秩 `rank(J_rel)=6`（`dim ker = 6`）在 tol = 1e-4 / 1e-6 / 1e-8
   三档下**都是 100%**，退化样本数 = 0。
   → 精确降秩是**零测度集**，原规划里"C2.6 相对位姿约束降秩耦合"的"降秩区"在采样中抓不到。
   有信息量的是**条件数**，不是秩（见第 4 条）。

4. **真正可用的退化度量是 σ_min(J_rel)，而且它有明确的空间结构**：
   P50 = **0.270**，P5 = 0.155；**越高的地方条件数越好** ——
   z≈0.05 m 时 σ_min 中位数 0.240，z≈0.85 m 时 0.340（**+42%**），`w_rel` 同步从 0.856 涨到 1.324（+55%）。
   但"容易凑近"的比例反向：z<0.1 m 处 6.07% 的构型能满足 ≤0.35 m，z≈0.35–0.5 m 只有 3.5%。

5. **相对可操作度不能由"较弱那条臂"解释**（负面结论，如实记录）：
   `w_rel` 与 `min(w_L,w_R)` 的 Spearman ρ = **0.235**，`σ_min(J_rel)` 与 `min σ_min(J_arm)` 的 ρ = **0.056**。
   也就是说，"两条臂各自都灵活"并不蕴含"相对位姿控制好"。**相对任务必须单独评估。**

## 2. 方法

### 2.1 ★ 实现阶段补上的：地面约束

第一次跑完发现可达空间延伸到 **z = −0.62 m** —— 只过滤了"臂—臂"碰撞，漏了"臂—地"。
而 [dual_arm_world.sdf](../../../src/gz_launch/worlds/dual_arm_world.sdf) 在 **z = 0 有地面**
（注释写明"去掉桌子，板直接放地面"），底座也装在 z = 0，**低于地面的构型物理上不可能**。

不修的话，共同可达空间里 **71.6%** 是穿地的。

约束：所有 DH 坐标系原点（每条臂 7 个）与 TCP 的 z ≥ 0。
**刻意不用 capsule 半径**（0.06 m）——那是"臂—臂"间隙的保守代理，不是真实连杆几何，
用它卡地面会把底座连杆直接判死。

顺带收益：地面过滤放在 FCL 距离之前早退，1e7 样本耗时从 **75.2 s 降到 21.5 s**。

### 2.2 采样与过滤（最终配置）

| 项 | 值 |
|---|---|
| 采样 | Halton（base 2…47），12 维，关节限位内 |
| 评估构型数 | **1e7** |
| 过滤 | ① 关节限位（天然满足）② z ≥ 0 ③ `d_arms ≥ 0.02 m` |
| 线程 | 16 |
| 耗时 | **21.5 s** |

### 2.3 指标定义

| 指标 | 定义 |
|---|---|
| `w_rel` | `√det(J_rel J_relᵀ) = ∏σ_i` —— **帧不变**（`det Ad(T) = det R² = 1`） |
| `σ_min(J_rel)` | `J_rel` 的最小奇异值，**帧相关**，主结果用 **BodyR**（与 C2.3 `relativeError` 同系） |
| `rank(J_rel)` | `σ_i > tol·σ_1` 的个数；**帧不变** |
| 可操作度 | 单臂 `w_L/w_R = ∏σ(J_arm)`，协同取 `min(w_L,w_R)` |

| 指标 | P5 | P50 | P95 |
|---|---|---|---|
| `w_rel` | 0.368 | **0.963** | 2.178 |

**相对距离的影响（主导）**

| \|p_rel\| [m] | 0.0–0.2 | 0.2–0.4 | 0.4–0.6 | 0.6–0.8 | 0.8–1.0 | 1.0–1.2 |
|---|---|---|---|---|---|---|
| `w_rel` P50 | 0.554 | 0.614 | 0.713 | 0.845 | 1.013 | 1.215 |

**相对旋转的影响（几乎无）**：`θ_rel` 从 20° 到 160°，`w_rel` 均值只在 1.06–1.14 之间变化（≈7%），
而 P5–P95 带宽是 0.7–2.2。→ **相对姿态角基本不影响相对可操作度，相对距离影响很大。**

> 附带发现：`θ_rel < 36°` 的构型只占 **1.386%**（`θ_rel` P5/P50/P95 = 56.3°/132.7°/175.6°）。
> 这验证了规划里"固定 `R = I` 姿态切片"的担心 —— 那样每片只有 ~1e2 量级样本。
> 实际实现改成按**相对旋转角**分箱（5 档），每档 2.2万–64万样本。

**与"较弱那条臂"的关系（负面结论）**

| 对比 | Spearman ρ | 中位数比值 |
|---|---|---|
| `w_rel` vs `min(w_L,w_R)` | **0.235** | 455× |
| `σ_min(J_rel)` vs `min σ_min(J_arm)` | **0.056** | 9.38× |

→ **弱相关**：相对位姿控制能力**不是**单臂能力的直接函数，必须单独评估。

## 5. 诚实边界（不可外推的部分）

1. **只做了运动学**。不涉及动力学、力矩、`inertial`；与 C2.9b 的 Gazebo 伺服问题无关（本分析不跑仿真）。
2. **"可达"= TCP 点可达，不是位姿可达**。完整 6D 位姿可达需要 IK + 碰撞，属 C4.2。
3. **碰撞几何是 capsule 简化**（半径 0.06 m，同 C2.7），且只建模了**臂—臂**与**臂—地平面**，
   没有桌子边缘、相机、线缆、环境障碍。
4. **占用/面积不是体积**：关节空间均匀采样 → 任务空间密度 ∝ 1/|det J| 类加权，不均匀。
   图上的"热"不代表"多"，只代表"有样本"。
5. **`σ_min` 必须带帧**。本文所有 `σ_min` 都是 `BodyR`。`w_rel` 才是不带帧也成立的量。
6. **地面按 z=0 平面**。若真机底座有垫高/桌子，改 `--z-floor` 重跑即可，结论方向不变。
7. **结论未在真机验证**（C5）。这是纯几何/运动学的离线结论，真机上还叠加标定残差与伺服误差。

## 6. 给 C4.2 的输入

`analysis/figs/summary.json` 是机器可读的接口，另有：

- **交接位初选区域**：x ∈ [−0.54, 0.54]，y ∈ [−0.67, 0.65]，**z ≈ 0.3–0.7 m**（避开 z<0.2 的低条件数区），
  且以 x≈0 中线为轴；
- **优化目标里应显式含 `σ_min(J_rel)` 的项** —— 因为它与单臂可操作度**弱相关**（ρ=0.06），
  不能靠"两臂各自最优"隐式满足；
- **权衡已知**：低处好凑近但条件数差（z<0.1 m：可交接 6.07%、σ_min 0.240）；
  高处条件数好但可交接样本少（z≈0.6–0.7 m：4.33%、σ_min 0.313）。C4.2 的权重 `w_1..w_4` 要在这条曲线上取值。
