| 指标 | 值 |
|---|---|

ULP 口径：`key(x)` 为单调排序键（负值先映射 `INT64_MIN − i`，再 XOR `2^63`），与 `test_mock_closure.cpp:120-131` 的 `ulpDistance()` 逐行等价。**不能用"XOR 符号位"的朴素做法**——它在跨越零点的两个近零值上报出 ~2^63 ULP，而这正是本例的主导情形（两个任务都在说"不要动"）。

与 `test_ulp_attribution` 在 D1 构建下的实测**完全一致**（该仪器输出：max ULP `8811496414880545534` @ cycle 0 joint 6、max \|Δdq\| 9.024e-14、> 1 ULP = 7656/7656），两条独立读数互相印证。

**结论：原判据 `≤1 ULP` 在现有数值路径下仍为 FAIL，不因 D1 集成而变化。**
