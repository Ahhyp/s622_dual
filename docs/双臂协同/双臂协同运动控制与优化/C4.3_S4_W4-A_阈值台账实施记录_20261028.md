## 2. 结构

字段与分离原则（批次 B 必须按此检查）：

| 字段 | 取值 | 说明 |
|---|---|---|
| `threshold_status` | `APPROVED` / `PENDING_CALIBRATION` / `UNAPPROVED_SOURCE_UNCONFIRMED` | 阈值本身的批准状态 |
| `software_state` | `IMPLEMENTED` / `PARTIAL` / `NOT_IMPLEMENTED` / `OUT_OF_SCOPE` | 软件是否具备 |
| `evidence_state` | `PASS` / `PARTIAL` / `FAIL` / `HOLD` / `UNVERIFIED` / `NOT_RUN` / `MISSING_EVIDENCE` | 证据实际状态 |
| `gate_state` | `CLOSED` / `OPEN` / `HOLD` / `BLOCKED_EXTERNAL_ENV` / `UNAPPROVED` | 门禁状态 |

建议值不与批准阈值混写：规划里"建议 X + `[待标定]`"的条目，`threshold` 填 `"[待标定]"`，建议数字放 `suggested_value`。
