## 检查一:URDF inertial 真伪

### 步骤 1:直接看数值(5 分钟)

翻出 URDF/xacro 里的 `<inertial>` 块,六个连杆逐个看。判据很直接:

| 特征                                | 判定   |
| --------------------------------- | ---- |
| 所有连杆 `mass` 相同(如全是 1.0)           | 假    |
| 惯量矩阵是单位矩阵(`ixx=iyy=izz=1`,非对角全 0) | 假    |
| `origin xyz="0 0 0"`(质心全在关节原点)    | 假    |
| 惯量数值量级整齐(如全是 0.1、0.01)            | 假    |
| 非对角项 `ixy/ixz/iyz` **全部为 0**      | 可疑   |
| mass 有差异、质心偏移各不相同、惯量有非规整小数        | 可能为真 |

最后一条解释一下:真实连杆的主惯量轴一般不与连杆坐标系对齐,所以从 CAD 导出的惯量张量通常**有非零非对角项**。全零意味着要么是简化模型,要么是手填的占位值。少数情况下厂商会把坐标系建在主惯量轴上,所以这条是"可疑"不是"确定假"。

### 步骤 2:物理合理性检查(15 分钟)

即使数值看起来不整齐,也可能是随便填的。用三个物理约束验:

**① 总质量对不对。** 六个 `mass` 相加,和产品手册的整机重量比。S622 这类小臂整机通常十几公斤,减去底座和控制箱部分。差一倍以上就是假的。

**② 惯量张量必须正定,且满足三角不等式。**

$$I_{xx} + I_{yy} \ge I_{zz},\quad I_{yy}+I_{zz}\ge I_{xx},\quad I_{zz}+I_{xx}\ge I_{yy}$$

这是刚体惯量的物理必要条件(源自 (I_{xx}=\int(y^2+z^2)dm) 这类定义)。手填的数值经常违反,尤其是"全填 1" 会恰好满足等号边界,而随手改的数值容易越界。

**③ 回转半径量级。** 用 (r_g = \sqrt{I/m}) 算等效回转半径,应该和连杆的几何尺寸同量级(几厘米到几十厘米)。如果算出来是 1m 或 1mm,明显假。

用 Pinocchio 几行就能跑完:

```python
import pinocchio as pin
import numpy as np

model = pin.buildModelFromUrdf("dual_arm.urdf")
data = model.createData()

print(f"总质量: {sum(model.inertias[i].mass for i in range(1, model.njoints)):.3f} kg\n")

for i in range(1, model.njoints):
    I = model.inertias[i]
    m, c, Ic = I.mass, I.lever, I.inertia
    w = np.linalg.eigvalsh(Ic)            # 主惯量
    ok_pd  = np.all(w > 0)
    ok_tri = (w[0]+w[1] >= w[2]) and (w[1]+w[2] >= w[0]) and (w[0]+w[2] >= w[1])
    rg = np.sqrt(np.trace(Ic)/(2*m)) if m > 0 else 0
    print(f"{model.names[i]:20s} m={m:7.3f}  com={c}  "
          f"正定={ok_pd} 三角={ok_tri}  回转半径={rg*1000:.1f}mm")
    print(f"  非对角: ixy={Ic[0,1]:.2e} ixz={Ic[0,2]:.2e} iyz={Ic[1,2]:.2e}")
```

### 步骤 3:重力力矩合理性(10 分钟)

最实用的一条:用模型算静态重力力矩,看数值是否合理。

```python
q_test = {
    "零位":     np.zeros(model.nq),
    "水平伸展": np.array([0, -np.pi/2, 0, 0, 0, 0]),   # 按你的关节定义调整
    "竖直收起": np.array([0, 0, 0, 0, 0, 0]),
}
for name, q in q_test.items():
    g = pin.computeGeneralizedGravity(model, data, q)
    print(f"{name:10s} tau_g = {np.round(g, 3)}")
```

三个判据:

* **水平伸展时 J2、J3 的重力力矩必须显著大于其他关节**,且和 J1 差一个量级以上
* **J1(绕竖直轴)在任何姿态静止时重力力矩应接近 0** —— 这是几何必然,重力方向与 J1 轴平行,力臂为零(若 J1 是基座旋转轴)
* 量级估算:如果 J2 力矩算出来是 200Nm,而这是一台几公斤负载的小臂,明显不合理;正常应该在几到几十 Nm

第二条特别好用,它是一个不依赖任何参数准确性的**结构性检查**。如果 J1 算出非零重力力矩,说明模型的坐标系或惯量填错了。

### 结论怎么用

| 结果                       | 决策                                 |
| ------------------------ | ---------------------------------- |
| 三步全过                     | inertial 可信,动力学仿真有意义,MuJoCo 力控分析可做 |
| 数值整齐 / 违反三角不等式 / 重力力矩不合理 | **占位符,任何仿真器里的动力学都是虚构**             |

如果是假的,两条路:

* **放弃动力学相关内容**(包括 MuJoCo 力控分析)。这不影响第 23 轮那份规划的主体,阶段 0~4 全部是运动学和控制层面的
* 从 CAD 模型重新导出惯量参数(如果厂商提供 STEP/SolidWorks 文件)。SolidWorks / FreeCAD 都能算质量属性。工作量几小时,但这是唯一能补救的办法

**别硬着头皮用假参数做动力学。** 结论一文不值,而面试时一旦被问到"你的连杆惯量哪来的",没法回答。

## 检查二:20004 的 jt_cur_tor 重力一致性

这一项决定力控归属,核心是判断字段是**原始测量值**还是**已补偿值/指令值**。

### 步骤 0:先确认能读到(30 分钟)

```python
# 调用 SDK 打开实时状态端口
robot.SetRobotRealtimeStateSamplePeriod(4)   # ms,先试最小值
# 周期读取,打印 jt_cur_tor 和 jointDriverTorque 六轴原始值
```

三个初筛判据:

* 六轴**全部为 0** → 固件未实装,到此为止
* 某几轴恒 0 → 部分实装,可用性差
* 有非零值且随姿态变化 → 继续下一步

同时记录:实际上报周期(时间戳间隔的均值和抖动)、数据类型与单位提示。

`jt_cur_tor` 和 `jointDriverTorque` **两个都读**,对比行为差异。名字上 `jointDriverTorque` 更像驱动器原始力矩,`jt_cur_tor` 的 `cur` 可能是 "current"(当前)也可能是 "current"(电流),模糊。让数据说话。

### 步骤 1:多姿态静止测试(★ 生死判据,1 小时)

这是整个检查的核心。用拖动示教把臂摆到若干姿态,每个姿态静止 10 秒,记录均值。

设计至少五个姿态:

| 姿态             | 预期(若为原始测量)                        |
| -------------- | --------------------------------- |
| 竖直收起(重力力臂最小)   | J2/J3 力矩小                         |
| 水平完全伸展(力臂最大)   | **J2/J3 力矩最大**                    |
| 水平伸展,J1 旋转 90° | J2/J3 与上一姿态**基本相同**(J1 旋转不改变重力力臂) |
| J2 抬起 45°      | J2/J3 介于两者之间                      |
| 腕部翻转 180°      | J5/J6 符号反转                        |

判据:

| 观察                                       | 结论                           |
| ---------------------------------------- | ---------------------------- |
| J2/J3 随姿态显著变化,水平伸展时最大,符合 (\cos\theta) 趋势 | ✅ **原始测量值,可用**               |
| J1 在各静止姿态下都接近 0                          | ✅ 符合物理(重力轴平行)                |
| 所有关节在所有姿态下都接近 0                          | ❌ **已做重力补偿,或是指令力矩** → 外力估计失效 |
| 数值随姿态变化但不符合 (\cos\theta) 规律              | ⚠️ 可能是滤波后的量或单位混乱,需进一步排查      |

第二行和第三行的组合是关键:**J1 接近 0 但 J2/J3 大幅变化** 才是正确的原始力矩特征。如果全零,说明控制箱已经内部减掉了 (g(q)),你拿到的是"残差力矩",那它反而**更接近外力**——这种情况下也能用,但要重新验证(见步骤 1b)。

### 步骤 1b:如果全零,别急着放弃

全零有两种可能,要区分:

* **已重力补偿的残差力矩** → 静止无外力时为 0,但**施加外力时会变化**,这其实是好事,省掉了动力学建模
* **指令力矩或未实装** → 施加外力也不变

区分方法:手动推末端,看数值是否响应。有响应就是前者,可用。

### 步骤 2:已知配重加载(1 小时)

末端挂一个已知质量(1kg 砝码或标定过的重物),在几个姿态下对比挂载前后的差值 (\Delta\tau)。

用模型算理论值对比(前提是检查一里 inertial 可信,或者至少几何链长度可信——纯重力力矩只需要连杆长度和负载质量,不需要连杆惯量):

$$\Delta\tau_{theory} = J^T(q)\begin{bmatrix}0\0\-m_{load},g\0\0\0\end{bmatrix}$$

这一步给你三样东西:

* **单位与换算系数**:(\Delta\tau_{meas} / \Delta\tau_{theory}) 的比值。如果接近 1,单位就是 Nm;如果是别的固定比例,那就是换算系数(可能是额定力矩千分比、或电流值)
* **符号约定**:正负方向是否与你的关节定义一致
* **量级可信度**:多个姿态下比值应该**一致**。如果比值散布很大,说明有摩擦或非线性影响,精度会打折

### 步骤 3:噪声与分辨率(30 分钟)

这一步直接决定力控能做到什么程度。

| 测试            | 记录                   | 意义            |
| ------------- | -------------------- | ------------- |
| 静止 60 秒       | 各轴标准差 (\sigma)       | 噪声底噪          |
| 静止 60 秒       | 均值漂移(前 10s vs 后 10s) | 零偏稳定性         |
| 缓慢匀速转动        | 数值波动幅度               | 摩擦扰动          |
| 极低速转动(0.5°/s) | 是否有跳变/爬行             | stick-slip 死区 |

**分辨率下限估算:**

$$F_{\min} \approx \left|\left(J^T\right)^{\dagger}\right| \cdot 3\sigma_\tau$$

这个数字是你后面所有力控内容的精度天花板。经验上,位置控制臂用关节力矩估外力,末端分辨率通常在几 N 到十几 N。如果算出来 <5N,可以做粗柔顺引导;如果 >20N,只能做碰撞检测。

低速爬行那一项很重要:摩擦的 stick-slip 会让力矩读数在零附近跳动,这是位置控制 + 力矩估力的固有问题(第 18 轮提过)。测出来幅度多大,决定你要不要认真做摩擦辨识。

### 步骤 4:带宽与延迟(30 分钟)

快速拍一下末端(阶跃外力),看:

* **响应延迟**:从施力到数值变化的时间
* **上升时间**:判断有无内部低通滤波
* **实际有效带宽**

导纳控制是闭环,延迟直接压缩稳定域。整链延迟(上报周期 + 滤波 + ServoJ 周期 + 控制箱内部位置环)如果超过 30~50ms,实际可用带宽只有几 Hz,只能做很软的柔顺。

### 判定表

| 步骤 1/1b  | 步骤 2  | 步骤 3        | 结论                                   |
| -------- | ----- | ----------- | ------------------------------------ |
| 符合重力规律   | 比值一致  | 3σ 对应 < 10N | ✅ **力控进实机**:外力估计、碰撞检测、柔顺引导、闭链内力监控    |
| 符合重力规律   | 比值散布大 | 3σ 对应 > 20N | ⚠️ 仅做**碰撞检测 / 过载保护**,不做柔顺            |
| 已补偿但响应外力 | —     | —           | ✅ 可用,且省掉动力学建模                        |
| 全零且不响应外力 | —     | —           | ❌ 力控退出实机 → 考虑买力传感器,或 MuJoCo sim-only |

### 一个实用提醒

做步骤 1 和 2 时**用拖动示教摆姿态**最省事,但注意:拖动模式下控制箱在跑力矩环,读到的力矩可能包含补偿输出而非纯负载。**摆好姿态后切回位置保持模式再记录数据**,避免模式串扰。第 13 轮提到的"模式互斥性与切换耗时"在这里会用到。
