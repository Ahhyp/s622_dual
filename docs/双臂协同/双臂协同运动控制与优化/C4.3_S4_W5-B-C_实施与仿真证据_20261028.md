## 4. W5-B 实施与验证

### 4.1 桌面是否属于冻结必需项（B2 核对）

- 冻结依据：`C4.3_S4_W5_Gazebo场景执行规划_v1.1_20261028.md` §2.1「冻结核心交付」第 1 条原文
  **"复用既有桌面模型：`src/gz_launch/models/table`"**，§3.1 文件边界亦列 `models/table/` 为「只读复用」。
  ⇒ **桌面是冻结必需资产**，不是可选项。
- 本会话 W5-A 曾把它记为「REUSE（可选，不引入）」，**该判断与本条冻结要求不符**；W5-B 已按冻结要求纠正，
  并在 world 中实际引用。
- 几何处理（不修改 table 模型，也不为凑场景改其尺寸）：
  `models/table` 的桌面碰撞/视觉盒在模型坐标系 `z=1.0`（厚 0.03 → 顶面 1.015）；沿用
  `worlds/table_world.sdf` 的既有约定 `pose z=-1.015`，使**桌面上表面平齐 world z=0**。
  于是：桌面上表面 0.0 = 支撑底面 0.0（静-静接触，无穿透）；支撑顶面 0.25；样件中心 0.275。
  ⇒ 桌面与支撑/样件**无非预期初始穿模**，且不改变冻结名义坐标。
- 冻结要求与实现之间**无冲突**，不需要暂停任何子项。

### 4.2 world 内容（`c43_s4_world.sdf`）

- `world name="c43_s4_world"`；`<gravity>0 0 -9.8</gravity>`（真实重力，未关闭）。
- `physics max_step_size=0.005`（200 Hz，沿用 `s622_world.sdf`）、`real_time_factor=1.0`。
- 插件：Physics / UserCommands / SceneBroadcaster / Contact（沿用 `s622_world.sdf`）。
- 光照：directional `sun`；地面：内联 `ground_plane`（100×100，静态）。
- 三个 include（模型几何不在此文件重复定义）：
  - `model://table` → 实例名 `c43_table`，pose `0.4 0 -1.015 0 0 0`
  - `model://c43_support` → pose `0 0 0 0 0 0`（底面 0 / 顶面 0.25）
  - `model://c43_sample` → pose `0 0 0.275 0 0 0`（名义中心）
- 未做的事：未关物理、未把样件设 static、未改冻结尺寸/质量、未移除碰撞。

### 4.3 launch 内容（`c43_s4_transport.launch.py`）

> 注：`headless` 判定在首版存在运行时时序缺陷（恒为 server-only），已于 B-11 实测后修复，详见 §4.4。

## 5. W5-C 实施与实测

### 5.1 测试协议

1. 启动 `ign gazebo -s -r -v 3 <c43_s4_world>`（server-only，真实重力、物理运行）。
2. 等待三个模型全部加载；等待 0.5 s 仿真时间令接触稳定。
3. 以 `t_start = sim_time` 为区间起点，连续录制 `/world/c43_s4_world/pose/info`。
4. 轮询 `/world/c43_s4_world/stats`，直到 `sim_time − t_start ≥ 5.0 s`，记录 `t_end`。
5. 停止录制与仿真，按每条消息的 `header.stamp` 解析，取 `[t_start, t_end]` 内 `c43_sample` 位姿序列。
6. 计算漂移/误差/姿态/速度估计并归档原始数据。

约束遵守：未运行机械臂控制、未发 attach/detach、未锁定样件位姿、未关重力、未暂停物理、未改任何阈值。
