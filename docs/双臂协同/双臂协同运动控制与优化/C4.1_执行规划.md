## 0. 一句话目标

采样双臂 12 维构型空间，算出并画出**共同可达空间**、**相对位姿可操作度场**、**零空间维度分布**，
让后续所有双臂任务的关键位置（交接位、待机位、协同区）**有依据地选，而不是示教猜**。

## 1. 回答什么 / 不回答什么

**回答**

1. 两臂 TCP 共同能到哪儿？交接动作在空间上被限制在哪个体积里？
2. 在给定相对位姿 ^L T_R 下，双臂协同的运动能力有多强（可操作度）？哪些相对位姿是"死角"？
3. 相对位姿约束在哪些位置降秩（`dim ker(J_rel) < 6`）？—— 即 C2.6 那个"接近奇异会降秩"的问题，它在空间上长什么样。

- 不做 IK 反解、不做位姿可达性判定（完整 6D 位姿可达需要 IK + 碰撞，属 **C4.2**）；
  本文的"可达"一律指 **TCP 点可达**。
- 不做动力学/力矩层面的可操作度（`inertial` 与整机总质量仍待确认，见 [机械臂参数](../../机械臂参数.md)）。
- 不做时间最优或避障（C3 的事）。

## 2. 关键定义（先写死，否则后面数字会打架）

### 2.1 共同可达空间（Common Reachable Workspace, CRW）

- 采样构型对 `(q_L, q_R)`，各自投影成 TCP 点 `p_L = worldTgrasp(Left).translation()`、`p_R` 同理；
- 左臂可达点集 `A_L`、右臂点集 `A_R`（各自在**无对方**约束下统计）；
- **共同可达空间** `CRW = A_L ∩ A_R`（体素网格上的交）；
- **交接候选区**：在**有效构型对**（两臂距离 ≥ d_min、均不越限）上统计 `‖p_L − p_R‖ ≤ r_handover` 的样本，把 `(p_L+p_R)/2` 投到网格 —— 这才是"两只手能同时伸过去并且靠得够近"的区域，与 `CRW` 是**两个不同集合**，报告里必须分开画。

### 2.2 可操作度（三个都要，别混）

| 名称 | 定义 | 用途 |
|---|---|---|
| 单臂可操作度 | `w_L = √det(J_L J_Lᵀ)`，`w_R` 同理（6×6） | 判断是哪条臂在拖后腿 |
| **相对可操作度** | `w_rel = √det(J_rel J_relᵀ)`（6×12·12×6 → 6×6） | **主指标**：相对位姿保持/协同运动的能力 |
| 协同可操作度 | `min(w_L, w_R)` | 双臂协同受**最弱那条臂**限制，与 `w_rel` 对照 |

补充指标：`σ_min(J_rel)`（对"接近奇异"比 `√det` 更敏感，`√det` 会被大奇异值掩盖）。
`√det` 与 `σ_min` 同时报，是 C2.8 报告里"P99 才是设计指标"那种诚实做法的延续。

### 2.3 零空间维度分布

- `rank(J_rel)` 取 SVD 数值秩：`σ_i > tol · σ_1`，`tol = 1e-6`；
- `dim ker(J_rel) = 12 − rank`，理论满秩时 = **6**（修订版规划 §3 第 8 条已修正：仅在非奇异时成立）；
- 产出：`rank` 直方图 + `rank < 6` 样本在世界系的空间分布（与 CRW 叠加）+ 占比统计。

### 2.4 ★ frame 依赖性：一个必须写进报告的诚实点

`relativeJacobian()` 有三个表达系（`BodyR` / `LeftL` / `WorldSpatial`），关系是
`J_LeftL = Ad(T_rel) · J_BodyR`。开工时先把这条理清（**已在 S1 用数值验证，见下**）：

| 量 | 表达系无关？ | 原因 |
|---|---|---|
| `rank(J_rel)` / `dim ker(J_rel)` | ✅ 无关 | 左乘可逆阵不改变秩 |
| **`w_rel = √det(J_rel J_relᵀ) = ∏σ_i`** | ✅ **无关** | `J' = Ad·J` → `det(J'J'ᵀ) = det(Ad)²·det(JJᵀ)`，而 `det(Ad(T)) = det(R)² = 1` |
| **`σ_i(J_rel)`（含 `σ_min`、条件数）** | ❌ **有关** | `Ad` 在平移部分非零时**不是正交阵**，会各向异性拉伸 |

数值验证（200 组随机构型，`BodyR` vs `LeftL` vs `WorldSpatial`）：

```
∏σ 的最大帧间相对差      = 1.553e-14   （机器精度）
σ_min 的最大帧间相对差   = 1.102e-03
σ_min 有差异的样本       = 200/200
```

**结论（比原设想更精确）**：

- `w_rel` 是**天然可比的**，可以放心跨场景引用，不必注明系；
- 但 **`σ_min` 必须永远带着系一起报** —— 它是帧相关的，脱离系的 `σ_min` 没有意义；
- 两者都已固化成单元测试（`RelativeManipulabilityIsFrameInvariant` /
  `RelativeSminIsFrameDependent`），防止后人"顺手修好"这个差异。

主结果仍固定用 **`BodyR`**（物理含义 = "右臂看到的相对位姿误差"，与 C2.3 的 `relativeError` 同系）。

## 3. 方法

```
Halton 低差异采样 q_L, q_R ∈ 关节限位
        │
        ├─ 过滤 1：关节限位（采样时天然满足）
        ├─ 过滤 2：地面/工作平面 —— 所有 DH 坐标系原点与 TCP 的 z ≥ z_floor
        │          ← dual_arm_world.sdf 在 z=0 有地面（桌子已去掉），★ 见 §3.1
        ├─ 过滤 3：双臂距离 d(q12) ≥ d_min     ← DualArmCollisionModel::distance()
        │
        ├─ FK：worldTgrasp(L/R) → 点云、^L T_R
        ├─ 单臂：J_L, J_R → w_L, w_R, min
        ├─ 相对：J_rel(BodyR) → w_rel, σ_i, rank
        │
        └─ 写 CSV（每行一个有效样本）
                 │
                 └─ Python（conda yolov8）读 CSV → 分箱 → 出图 + 汇总数字
```

**为什么关节空间采样而不是任务空间**：任务空间采样必须逐个做 IK，成本高、成功率还受 IK 求解器影响，
会把"可达性"和"IK 好不好"两个问题搅在一起。关节空间采样是**无偏的构型空间统计**，投影到任务空间即可。
IK 反解留到 C4.2（那时才需要"给定目标位姿求关节"）。

### 3.1 ★ 地面约束（实现阶段补上的，原规划漏了）

第一次跑完发现可达空间一直延伸到 **z = −0.62 m** —— 因为只过滤了"臂—臂"碰撞，
没有过滤"臂—地"。而 [dual_arm_world.sdf](../../../src/gz_launch/worlds/dual_arm_world.sdf) 在 **z = 0 有地面**
（注释写明"去掉桌子，板直接放地面"），机械臂底座也装在 z = 0，所以**低于地面的构型物理上不可能**。

不修的话，"共同可达空间"里有 71.6% 是穿地的，拿它去选交接位毫无意义。

**约束形式**：所有 DH 坐标系原点（每条臂 7 个）与 TCP 的 z ≥ `z_floor`（默认 0.0）。

- **不用** capsule 半径：那个 0.06 m 是"臂—臂"间隙的保守代理，不是真实连杆几何；
  用它去卡地面会把底座连杆直接判死。
- 影响量化（1e7 样本）：**拒绝 71.6%**，有效样本 27.8%；
  关掉地面约束则有效率 98.5%（即 71.6% 的原始采样穿地）。
- 顺带收益：这个过滤放在 FCL 距离之前早退，1e7 样本耗时从 **75 s 降到 21.5 s**。

**为什么用 Halton 而不是均匀随机**：关节 2、4 的区间（[-4.6251, 1.4835]，跨度 6.1 rad）比其它关节大得多，
纯随机在高维下会出现空洞与聚集。Halton（base 2…47）在同样样本量下覆盖更均匀，且**无需新依赖**（自己写 20 行）。

## 8. 风险与坑

| 风险 | 对策 |
|---|---|
| **frame 依赖被忽略**：报了个 `w_rel` 不说系，数字无法复现 | §2.4 写死：主结果 `BodyR` + 三 frame 对比表 |

| 关节采样在 J2/J4 大区间上出现空洞 | 用 Halton；S1 里做均匀性单测（分位数检验） |

| **只过滤臂—臂碰撞、忘了臂—地** | §3.1 地面约束 + 开关对照，量化被拒比例 |
| `σ_min` 与 `w_rel` 的帧依赖被混为一谈 | §2.4 + 两个固化单测 |
| FCL capsule 是简化几何，`d_min` 判定偏乐观 | 报告注明；`d_min` 做 0.02/0.05 敏感性对照 |

| 退化区看起来"很多"被误读为系统有病 | 明确 `rank<6` 的**测度占比**与它对 C2.6 的实际影响（C2.6 已证明连续退化机制可用） |

### 10.1 输出格式的补充决定（实现时定的）

原计划的 CSV 在 1e7 样本下**体积失控**：37 个字段 × 1e7 行 ≈ 7 GB ASCII。
改为：

- 主产物 **二进制 float32 记录** `<prefix>.bin`，**37 字段 × 4 B = 148 B/样本** → 1e7 约 1.5 GB（磁盘余量 926 GB，无压力）；
- `<prefix>.json` 记录 schema + 全部参数 + 统计；
- `<prefix>_preview.csv` 只写前 1000 行，供人工查看；
- Python 侧用 `np.memmap` **分块**读取（本机 RAM 仅 7 GB，不可整体载入）。

记录字段（固定顺序，Python 按此解析）：

```
q12(12) | p_left(3) p_right(3) p_object(3) p_rel(3) | rel_rotvec(3)
d_arms | w_left w_right | smin_left smin_right
w_rel_body smin_rel_body | w_rel_left w_rel_world | rank_rel
```

> `rank_rel` 与表达系无关（§2.4），只存一份；`rel_rotvec = logSO3(R_rel)` 用于 fig2 的姿态切片。
