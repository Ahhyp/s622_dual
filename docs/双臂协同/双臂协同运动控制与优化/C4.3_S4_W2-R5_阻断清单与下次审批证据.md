## 2. 本轮新增/更新的确定结论

1. **R3 的 4501 次未归属 = 未取栈的 `calloc` 路径**（4502 次，±1），**不是**第三方。
2. **R4 的 95 次差额 = 漏计 `libstdcxx 27 + libc 3` + 口径漂移 `16 + 49`**，算术闭合。
3. **类型化账本 UNKNOWN = 0**，两种独立实现相差 1/27606（0.004%）。
4. **B′ 原型数值逐位相同**（7656 个 `dq` 值 md5 一致），消除 1.00 次/solve 与 192 B/solve。
5. **OSQP 动态链接、入口全可拦、Eigen 走普通 `malloc`** ⇒ 此前的"可能走 `posix_memalign`"担忧不成立。
