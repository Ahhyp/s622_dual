## 2. 一个会让证据失效的陷阱（本轮实测踩到）

第一次在 `/tmp/w2r4_on` 跑 CTest 时，脚本里写的库路径是 `/tmp/w2r4_on/install/lib`（merge 布局），
而实际装到了 `/tmp/w2r4_on/install/dual_arm_qp_controller/lib`。
结果：**`LD_LIBRARY_PATH` 指了个空目录，测试悄悄加载了主安装的 OFF 库**，8/8 全绿但**与 ON 无关**。

识别方法（建议写入规范）：

```bash
ldd /tmp/w2r4_on/build/dual_arm_qp_controller/test_transport_latches | grep qp_controller.so
# 必须打印 /tmp/w2r4_on/... 而不是 /home/yep/my_S622/install/...
```

修正后重跑，`ldd` 确认加载 `…/w2r4_on/install/dual_arm_qp_controller/lib/libdual_arm_qp_controller.so`。
