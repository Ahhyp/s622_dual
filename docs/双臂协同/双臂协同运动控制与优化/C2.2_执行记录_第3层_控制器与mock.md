## 1. 三层结构落地（D2）

```
dual_arm_kinematics         (Step 0，纯 C++)
        ↓
dual_arm_qp_core            (C2.2 二，纯 C++，OSQP/ADMM)
        ↓
dual_arm_qp_controller      (C2.2 三，ros2_control 插件)   ← 本文
```

- **数学层**求 `d q`；**控制器层**积分成 `q_cmd` 并写 **position command interface**。
- 与现有 velocity JTC profile **完全分离**：
  - 旧 profile：`dual_arm_controllers.yaml`（臂 = velocity，JTC）
  - 新 profile：`dual_arm_qp_controllers.yaml`（臂 = position，QP 控制器）
  - 二者**不得同时 claim 同一组关节**。

## 2. 接口契约（实测确认）

`ros2 service call /controller_manager/list_controllers` 返回：

| 项 | 值 |
|---|---|
| name | `dual_arm_qp_controller`，state = **active** |
| claimed command | `left_j1..6/position` + `right_j1..6/position`（12 个） |
| required state | 同名 12 个 position |
| 手指关节 | **不 claim**（交由其它控制器） |

## 3. 控制行为

- `on_activate`：读当前 12 关节角 → 记录相对位姿目标 `^L T_R`（C2.3"相对位姿保持"）→ `q_cmd = q_state`。
- `update`（125Hz）：
  1. 读 12 个 position；
  2. **D7 健康检查**；
  3. `DualArmQp::solve`（OSQP + warm start）；
  4. 未收敛 → 不积分、保持；
  5. 收敛 → `q_cmd += dq` → 限位钳制 → 写 12 个 position command。
- 测试用刺激：`test_sweep_amp_m` 让相对目标做正弦漂移，使 D7 hold 在仿真里**可观测**。

## 4. D7 双臂联动 hold（本次核心验证）

规则：**任意一臂 stream 不健康 → 两臂一起冻结**。
健康判据：状态/命令非有限、注入 stall、per-arm 跟踪误差超限（可选）、连续求解失败超限。

### 实测（mock，参数 `stall_inject_arm=1`、`start=5.0s`、`duration=1.5s`）

控制器日志：

```
activated: relative target captured      @ 1791392185.0637
D7 HOLD enter @ t=5.006s: injected stream stall (arm=1)   @ 1791392190.0697
D7 HOLD exit  @ t=6.502s                                   @ 1791392191.5658
```

`/joint_states` 每 0.25s 最大增量（`left_j2 / right_j2`）：

| 窗口 | left_j2 | right_j2 | 说明 |
|---|---|---|---|
| 激活+4.60s | 0.00024 | 0.00020 | 正常跟随 sweep |
| **+4.86s** | **0.00000** | **0.00000** | ← HOLD 窗口开始 |
| +5.12 / +5.37 / +5.63 / +5.88s | **0.00000** | **0.00000** | **两臂完全冻结** |
| +6.14s | 0.00556 | 0.00449 | HOLD exit，释放瞬间追赶 |
| +6.65s 起 | ≈0.0005 | ≈0.0004 | 恢复正常跟随 |

→ **单臂 stall 时，健康的那一侧也没有继续运动**，且 hold 起止时刻与配置窗口精确一致（5.006 / 6.502 s）。

## 5. 控制频率

`/joint_states` 实测 **125.0 Hz**（501 msgs / 4.000 s），与 `controller_manager.update_rate=125`、QP `dt=0.008` 一致。
