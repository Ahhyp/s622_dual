## 6. 已知坑（都踩过）

- 直接跑 gtest 要 `source install/setup.bash` **且** `export LD_LIBRARY_PATH=$PWD/install/lib:$LD_LIBRARY_PATH`（**不能覆盖**，否则缺 `libfairino_planning_core.so`）。
- `pkill -f "c43_s4…"` 会匹配到自己的 shell 并自杀；用 `kill -TERM $(pgrep -f "^ign gazebo" | head -1)`。
- Gazebo 插件日志默认被吞，launch 里要 `-v 4`；`ros_gz_sim create -J` 对关节初值**无效**（B-4）。
- URDF→SDF 会把 `left_grasp_frame` 这类固定关节**合并掉**，插件 `parent_link` 只能填 `left_wrist3_link`；
  `child_link` 必须写模型内名 `base_link`（不能写 `c43_sample::base_link`）。
- YAML 里给 `ros__parameters` 追加键必须缩进 4 空格，否则执行器直接 `Failed to parse params file`。
- `/tmp` 会被清、机器重启会丢：**证据要落仓库**（本轮已有两次教训）。
- 构建内存：单 TU 1.2 GB，别开满并发。

## 7. DSH 迁到服务器

按「私有前缀安装」，**不要** `npm i -g`：

```bash
PREFIX="$HOME/.dsh-remote/dsh"; mkdir -p "$PREFIX"
printf '%s\n' '{"name":"dsh-remote-install","private":true,"version":"0.0.0"}' > "$PREFIX/package.json"
cd "$PREFIX" && npm install --prefix "$PREFIX" --no-audit --no-fund '@deepseek-ai/dsh@0.1.5-rc.2'
"$PREFIX/node_modules/.bin/dsh" --version
```

三条校验（缺一条不算装好）：

```bash
BIN="$PREFIX/node_modules/.bin/dsh"
ls "$PREFIX/node_modules/node-pty/prebuilds/"      # 必须有 linux-x64（0.1.0-rc.6 没有，Linux 起不来）
"$BIN" web --help | grep -q -- '--port'
DSH_HOME=/tmp/dshweb-check setsid nohup "$BIN" --profile web --port 0 --no-open \
  >/tmp/dshweb-check.log 2>&1 </dev/null &
sleep 8; grep -m1 'dsh web:' /tmp/dshweb-check.log   # 打印 http://127.0.0.1:<port>/?token=…
```

坑：`node-pty` 缺 `linux-x64` → `Failed to load native module: pty.node`；老版本不认 `--no-open`；
`.bin/dsh` 是符号链接，判断依赖要向上找第一个含 `node_modules` 的祖先，别用 `dirname(dirname())`。
需要从外部访问时用 `--port <port>` + 反向代理/隧道，**不要**默认监听 `0.0.0.0`。
