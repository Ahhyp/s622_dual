## 8. W4 不能代表 S4.1 整体 Gate PASS 的理由（C2-8）

1. **W4 只覆盖"阈值台账 + 检查器"**，冻结 §7 的测试执行本身属 W5–W9 与外部环境；台账 26 个指标中仅 3 个 `PASS`。
2. **`[待标定]` 12 项未标定**：没有阈值就没有判定，谈不上通过。
3. **外部环境阻断未解除**：C6 / S4-T2 / S4-T17 需原生 Linux RT（`ENV_REFUSED`），9 个测试需 Gazebo 真机流程；WSL2 数据不得替代。
4. **历史 FAIL 仍在**：`W2-C3/legacy-1ulp` 7656/7656 保留为 `LEGACY_...`，D2-B 只替代跨版本回归用途。
5. **未批准事项未变**：D4 失败码登记、P1-4 安全权责、C3-V1 提案均未获批准；B-4 仍 P0 OPEN。
6. **检查器语义**：退出码只表示"台账软件检查结果"，`LEDGER_OK` 不等于验收通过（脚本每次输出都带该声明）。

因此本记录**不得**被解释为：`W3 GATE PASS`、`S4.1 FULL GATE PASS`、`C6 / S4-T2 / S4-T17 RT PASS`、`B-4 CLOSED`、`D3 / D4 / D5 APPROVED`、`REAL HARDWARE ACCEPTED`。
