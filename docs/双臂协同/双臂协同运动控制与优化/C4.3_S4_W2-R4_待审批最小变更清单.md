## C1 —— `QpSolution::x` 改有界动态向量（推荐）

```cpp
// src/dual_arm_qp_core/include/dual_arm_qp_core/qp_types.hpp
inline constexpr int kMaxVars = 24;                     // 决策变量上限（12 与 24 都在内）
using QpVec = Eigen::Matrix<double, Eigen::Dynamic, 1, 0, kMaxVars, 1>;
struct QpSolution { QpVec x; /* 其余字段不变 */ };
```

- **为什么**：实测每次 solve 有 3.04 次自有分配（`osqp_solver.cpp:210` + 返回侧），全部来自这个字段；
  改后容量内 `resize` **零分配**（已由 `EIGEN_RUNTIME_NO_MALLOC` 实测，退出码 0 vs 134）。
- **影响文件**：`qp_types.hpp`（主要）；`osqp_solver.cpp:210`、`admm_solver.cpp:114`、`dual_arm_qp.cpp:350-355` **无需改动**；
  全部消费方重编（无源码变化）。
- **验收判据**：① `EIGEN_RUNTIME_NO_MALLOC` 下整段 `qp.solve()` 不触发断言；② `n=12` 与 `n=24` 两条路径 size/内容正确；
  ③ `test_legacy_golden_c43s3` **逐位不变**；④ `ctest` 全绿。
- **风险**：ABI 破坏（工作区内可接受，外部消费者须重编）；`kMaxVars` 将来需同步，建议 `static_assert`。
- **与方案 A 的关系**：若评审坚持“ABI 也不能动”，则改走 A（输出参数重载），代价是首拍分配 + 调用方必须复用缓冲。

## C2 —— 分配探针类型化

- **为什么**：4501 次（13.8%）未归属；且 Eigen 可能走 `posix_memalign`，只拦 `malloc` 不足。
- **做法**：拦截 `malloc/calloc/realloc/reallocarray/posix_memalign/aligned_alloc/memalign/valloc/strdup/operator new`，
  每条记录带 `kind` 与 5 帧栈；闭合判据 `sum(entries) == total`（≤0.1%）。
- **验收**：闭合误差 ≤0.1%；正/负控制各一（已知分配的合成程序 / 空程序）。
- **风险**：无生产影响；工具自身可能引入 ~5% 观测开销（只用于离线）。

## C3 —— ULP 判据 V1 生效 + 近零分层

- **为什么**：原“逐周期 `dq` ≤1 ULP”在近零区数学上不可用（实测最大 2.08e5 ULP），
  且两条独立机理（时钟表达式 + 取整方向）都已定位。
- **条款**：`max|Δdq| ≤ 1e-6 rad`（累积 ≤1 mm 的 3.6%）、`max|Δt| ≤ 1e-6 s`（2.1%）、
  决策零不一致、末端 ≤1 mm（沿用 S3 A1）；**近零分层**：`|dq| < 1e-9` 只记录不判定。
- **必须同时**：原条款保留为历史记录（FAIL 不得改写成 PASS）。
- **验收**：638 周期全量统计；近零样本单列。
- **风险**：“1e-6”是本文推导的工程值，非标准原文，需明确标注来源。

## C4 —— ON 构建纳入 CI

- **为什么**：钩子隔离已做实（`hook_refs=0/1`），但只在人工 A/B 中验证；
  长期防止“某次改动让钩子漏进正式构建”。
- **验收**：CI 对 OFF 与 ON 各跑一次全量 `ctest`，两者都绿。

## C5 —— E8 真实心跳停 → HOLD 注入

- **为什么**：目前只注入了 deadline（E4）；W1 遗留项“E8 真实心跳超时 HOLD 未注入验证”。
- **做法**：台架停发 `~/heartbeat`，测 `executor_lost` 的触发与 `~/resume` 恢复；
  测“从未收到心跳”的 `seen=false` 分支。
- **验收**：三例（正常 / 超时 / 从未收到）+ 恢复后锁存行为。

## C6 —— S4-T17 原生 Linux 环境（非代码）

- **为什么**：WSL2 无 `SCHED_FIFO`、无 `isolcpus`，四组实测最大间隔 15.7–21.3 ms > 12 ms。
- **需要**：原生 Linux + `isolcpus` + `rtprio` + 空载；步骤见 `C4.3_S4_W2-R3_综合验收矩阵.md` §7。
- **验收**：6380 周期，`interval_max ≤ 12 ms`、P99 ≤ 6.4 ms、RSS ≤ 1 MB、fd 不增长。
