## 一、这个阶段在做什么

C4.1 回答了"**两只手能够到哪**"（共同可达空间 53,606 体素 ≈ 0.429 m³），
但没有回答"**够得到不等于能以正确姿态抓**"。

C4.2 把"够得到"逐层收紧成一个**可报数字的梯子**，然后在梯子顶端做**多目标寻优**，
给出一个**比 M4 原始交接位更好的交接位姿**。

```
S0 点可达  →  S1 单臂姿态可达  →  S2 双臂姿态可达  →  S3 抓握约束  →  S4 无碰撞
                                                                      ↓
                                                        V0/V1 局部精化 → Pareto → 推荐点
```

**分层集合定义（S0–S4 见 S3 记录 §5；下面只列结论）**

| 层 | 含义 | 结果（23.3 万候选） |
|---|---|---|
| S0 | 两个诱导 TCP 都是点可达的 | 98,458 |
| S1_L / S1_R | 单臂有通过硬过滤的 IK 解 | 38,601 / 67,157 |
| S2 | 双臂同时 | **28,841（S0 的 29.3%）** |
| S3 | ∧ 抓握约束 | 28,841（**100%**，见"结构性恒等"） |
| S4 | ∧ 无碰撞 | **28,192（S3 的 97.7%）** |

## 五、★ 本阶段发现并修掉的问题（按重要性）

1. **S1：跨臂口径泄漏**。按名字前缀定义"跨臂"漏掉了挂在右腕上的 `wrist_camera_link`
   （没有 `right_` 前缀），导致 `arm_arm == whole_robot == 0.01312 m`。
   → 改成按左右连杆集合的**成对隶属**构造 ACM，修正为 0.01952 / 0.03396 m。
2. **S2：ACM 豁免没生效**。`addRodToScene` 往 ACM 的**副本**上加豁免并返回，
   而 `isStateColliding` 用的是场景自己的 ACM，导致手指-杆接触被误报为碰撞。
   → 改用 `getAllowedCollisionMatrixNonConst()` 就地写。
3. **S3/S5：嵌套自检是计数比较，不是逐候选蕴含**。
   原检查 `s4<=s3<=s2<=s0` 是**总数比较**，不等价于 `S4⊆S3⊆S2⊆S1`。
   S5 检查候选表时发现 `S4 但非 S0` 有 171 个才暴露。
   → 改成逐候选检查，实测 **0 违反 / 233,288**；`S4∖S0` 的 0.6% 作为
   **C4.1 采样覆盖缺口**单独报告。
4. **S4/S6：净空目标被几何锁死**。刚性抓握固定 `T_rel` ⇒ 两条臂**整条远端链**
   刚性同步 ⇒ 所有"远端–远端"距离是常数（`arm_arm` 在 97.7% 的 S4 解上恒为 33.7 mm，
   std 1.9 mm）。中途"只排除夹爪"的版本**也失败**（wrist3↔wrist3 = 35.1 mm）。
   → 新增 `arm_proximal`（≥1 端是近端杆）口径，std **50.6 mm（26×）**。
   **这一条是实测钉下来的，只靠推断会做错。**
5. **S6：J8 被自己的归一化尺度废掉**。`arm_proximal` 用 0.05 m 参考值归一化后，
   **94.8% 的候选被截断到 1.0**，完全丧失区分能力 —— 即第 4 条辛苦找回来的梯度又被丢了。
   J5（0.5 rad）同样被截断 58.7%。
   → 改用候选池 P95；推荐点移动 **0.233 m**，关节余量从 −35.3% 变 **+47.4%**。
6. **S5/S7：协同区"单连通"是过度声称**。只在 2 cm/26 邻接下成立；
   1 cm 下有 524 个分量（最大占 93.8%）。→ 已在 S5 记录更正为"**一个主导连通区**"。
7. **文档出处错误**：`grasp_long_offset_handover_mm` / `_regrasp_mm` 在 `m5_task.yaml`，
   **不在** `m4_handover.yaml`。§2.2 表已更正。
8. **建模陷阱（主动规避）**：右爪目标从"固定 `receive_quat` + 世界轴偏移"（模型 A，
   只在标称姿态成立）改为**刚性抓握** `T_R = T_L·T_rel^B`（模型 B）。
   两者在标称与 V0 下完全一致，但模型 A 在姿态扰动时会**静默破坏刚性抓握**。

## 六、必须随结论一起说的边界

1. **S3 是结构性恒等**。刚性抓握下 `T_R = T_L·T_rel^B`，H4 残差只剩 IK 误差，
   所以 `|S3|/|S2| ≡ 100%`。这是**结构性事实**，不是发现；已固化成单测。
   S3 真正开始咬人要等 V1/V2（姿态扰动或放开抓握点）。
2. **S4 是静态可行，不是"可到达"**。没有做运动规划，未宣称路径存在。
3. **"关节空间线段可行性率"是代理，不是规划成功率**。`isSegmentValid` 只是
   关节空间直线采样（与真规划器共享同一个离散碰撞原语，因此**同样有假阳风险**）。
   已做采样密度敏感性（N=8/16/32/64 结论不变）；**`padding` 对照未做**。
4. **有效目标集只有 {J3, J5, J6}**。8 个目标里 5 个对选择无影响（消融移动 0.0000 m）。
   **不得宣称"8 目标优化"**。
5. **Q1–Q4 未确认**（`m4_handover.yaml` 内部矛盾），物体是**参数化盒**而非真实杆，
   Baseline B 标为 `provisional_rebuilt`。**结论不得宣称适用于真实 M4 杆。**
6. **Baseline A 只作静态史料**，不参与任何对照。
7. **协同区是 V0 分层下的**（姿态固定 = M4 姿态）；V1 的协同区未单独重新体素化。
8. **局部精化增益很小**（相对 S4 池内最优：V0 +0.0006、V1 +0.0044）——
   **候选池本身贡献了主要优化效果**，不把"网格够密"包装成"优化器很强"。
9. **`p_opt` 的口径**是"落到同一盆地的比例"，**不是"找到全局最优的概率"**。
