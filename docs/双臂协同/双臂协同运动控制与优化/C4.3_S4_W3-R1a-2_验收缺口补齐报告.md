**P-2 四条规则（实现位置 `src/hold_requester.cpp`）**

1. **联合判定**：`state=="HOLD" && hold_origin=="executor" && seqAtOrAfter(ack_seq, seq)` 才算 L3/L4 成立；**不看 `result` 单独下结论**。
2. **`result==2` 不解释为"未冻结"**：若同时 origin 是 executor ⇒ 判 Done（`frozen_by_executor_request`）；若 origin 是 controller ⇒ **Abort**（`hold_owned_by_controller`），绝不冒领安全归因。
3. **超时不是成功**：`now - last_send > ack_timeout` ⇒ 同 seq 重发，耗尽 `max_attempts` ⇒ `Abort("hold_ack_timeout")`。
4. **陈旧状态不构成证据**：`status_age_s > status_stale_s` 的样本一律不参与判定。

节点侧（`executor_node.cpp::driveHoldRequest`）只搬运消息：状态机进入 `Hold` ⇒ `beginHoldRequest`；`Done` ⇒ 记日志；`Abort` ⇒ `sm_->abortTransport("hold_not_confirmed:" + reason)`。
