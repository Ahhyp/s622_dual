## 1. QP 形式（决策变量 18 → 24）

```
z = [dq(12); s_rel(6); s_obj(6)]
min w_rel ‖J_rel dq − α_rel e_rel − s_rel‖²
  + w_obj ‖J_obj dq − α_obj e_obj − s_obj‖²
  + w_slack‖s_rel‖² + w_slack_obj‖s_obj‖² + w_center‖dq−dq_c‖² + w_reg‖dq‖²
s.t. dq ∈ [max(−v dt, q−q), min(v dt, q−q)]        （硬约束）
```

结构恒为 24 维（`w_obj=0` 即关闭 object 任务），因此 **OSQP workspace 仍只 setup 一次**。
新增 **object 前馈** `solve(q, rel_t, obj_t, v_ff)`：`bias = −(α e + dt·v_ff)`。

## 2. 三个被实验逼出来的结论

### ① 纯比例跟踪有 `v/kp` 滞后 → 必须加前馈
平移轨迹：无前馈 obj RMS **7.35 mm** → 加前馈 **3.33 mm**。

### ② 构型条件数决定一切；`|ξ|≈π` 是禁区
- mock home 位姿：左右爪相对旋转 `|ξ| = 3.142 rad ≈ π`（正好是 `logSO3` 分支点），
  闭环直接发散（obj RMS 116–186 mm）。
- 测试改为**良态构型搜索**（2000 随机样本，取 `|ξ|<1.0` 且 `cond(J_stack)` 最小者）：
  选中 `cond=28.5, |ξ|=0.555 rad`。

> 这直接说明 **C2.6（奇异点/病态处理）不是可选项**。

### ③ 关节速度上限是硬物理约束
原始 3D 曲线（幅值 0.05 m / 0.3 rad，最高 3ω）**248/500 步把 |dq| 顶到 0.02 上限**，
obj RMS 39.5 mm。这不是控制器缺陷，而是 `v_max=2.5 rad/s` 的物理上限。
把该轨迹幅值减半后回到 0 饱和，obj RMS **5.49 mm**。
