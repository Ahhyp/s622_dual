### 2.1 闸门本身的两处修正（本轮发现并修）

1. **原来会"缺失输入即通过"**：候选版在没有 `--admm`、没有 provenance 绑定、文件缺失时仍可能给出 PASS。正式版改为 **fail-closed**：`--admm` 必填、`--provenance`+`--lib` 校验「基线是由被测库构建的」、缺文件/改 schema/截断/k 不连续一律 `INPUT_ERROR`（exit 2）。
2. **ctest 曾因"graded 错库"失败**：`$<TARGET_FILE:…>` 指向 build 树 `.so`（sha256 `15add58d…`，rpath 不同），与基线 PROVENANCE 记录的 install 库 `ff95750a…` 不符 → 闸门正确报 provenance mismatch。修正为**统一评估 install/lib 的库**（基线就是它构建的）。这不是放宽，而是把"评估对象"钉死。
