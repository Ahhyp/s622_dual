## 5. S1 期间抓到的错误与缺陷

### C-S1-1 ★ 对我自己 S0 结论的更正：`-Ad(G_L)` 是错的

`C4.3_S0_审计报告.md` §A14.2b(d) 手推为 `J_{O,L} = -Ad(G_L)·J_L`，并断言
"`-Ad(G_L)` 只是零残差附近的形式，必须再左乘 `Ad((T̂_{O,L})⁻¹T_WO,d)` 才是全局精确式"。

**两条都更正**：
1. 映射是 **`+Ad(G_X)`**（当时把"残差的符号"错误带进了"位姿的映射"）；
2. **不需要**额外修正项 —— 解耦误差形式 `A = [[R_dᵀR̂, 0],[0, J_r⁻¹(log(R_dᵀR̂))]]`
   已经把该修正吸收，且 `J_r⁻¹` 的**奇异在 2π 不在 π**，故 `J_{O,X} = A·Ad(G_X)·J_X`
   是**全局精确**的（大残差实测 `2.6e-7`）。

这正是 §A14.2b(d) 自己要求的"**符号约定在 S1 内用有限差分确认，不靠推导结论直接采信**"。
落点：契约表 §5.2/§5.3。

### C-S1-2 实现 bug：闭环误差雅可比的符号

`closureErrorJacobian` 初版把旋转块写成 `-J_r⁻¹·R_c`，正确为 `-J_l⁻¹`（由 `SO(3)` 恒等式
`R_c·J_r(φ) = J_l(φ)` 定）。**由 `ErrorJacobianMatchesFiniteDifference` 抓出**（初版差 `1e-1` 量级，
修正后 `2.6e-7`）。这是"独立有限差分对拍"作为硬性要求的直接价值。

### F-S1-1 ★ 新发现的缺陷（**未修改，用户已裁定单独立项**）

`src/dual_arm_kinematics/include/dual_arm_kinematics/se3.hpp:57` 的近 π 分支
（**更正**：本记录初版误写为 `fairino_planning_core`，该文件实际属 `dual_arm_kinematics`；
它是**头文件**，`dual_arm_kinematics.hpp` 会把它带给所有下游包）：

```cpp
Vec3 axis = A.col(best) / sqrt(std::max(1e-12, A(best, best)));   // A = (R + I)/2
// 符号 = sign(axis[best])，与紧邻的通用分支可能相反
```

**症状**：在 `π − θ < 1e-6` 的带内，`logSO3` 可返回**被取反**的轴。
实测（轴最大分量为负时）：`|logSO3 − 真值| = 6.283185 rad`（**恰好 2π**），方向点积 `−1.0000`。

**几何机理**：`A = (R+I)/2 = s·[axis] + c·axis·axisᵀ`（`c = sin²(θ/2)`，`s = sin θ/2`）。故
`A.col(best)/sqrt(A(best,best))` 化简为 `axis·sign(axis[best])` —— 该分支**总是**把轴定向为
"最大对角分量取正"；而通用分支（第 67 行）的符号来自反对称部分 `R − Rᵀ`，即来自 `R` 自身。
两者约定不同，故可相差 2π。

**传播**：`logSE3`（第 116–122 行）把 `logSO3` 的结果喂给 `leftJacobianInverseSO3(w)`，
其奇次项 `−0.5[w]` 在 `w` 取反时**翻转**，故缺陷会传入 `logSE3` 的平移块。

**影响与待办**：见 §8 与 `C4.3_S2_实施方案.md` 的 F-S1-1 调用链核查。
**用户已裁定（m01856）：单独立项、优先处理；必须区分"数学上的分支不连续"与"实现自身的数值不稳定"；
修复需验证 Exp/Log 重构精度、数值有限性、分支一致性；不得只按旋转向量符号判对错；
因被 C2/C4.2 共用，改生产代码前必须先交最小方案供审查并跑受影响模块全部回归。**
**S1 按纪律未改**，仅单独立测特征化
（`LogSO3SignIsUnstableAtTheNearPiBranchThreshold`）。

### 方法学教训：近 π 处**不能用中心差分**做预言机

`logSO3` 的 `acos(0.5(tr R − 1))` 在 `θ → π` 时条件数按 `1/sin θ` 恶化，
而中心差分要**除以 `2h`**，把该噪声放大。实测在 `θ = π − 1e-3` 处中心差分给出 `2.28e-4`
的**假失配**（解析映射本身没问题）。
**改用前向一致性** `e(q+h·dq) ≈ e(q) + h·J·dq`（**不除以 h**），并验证残差按 `h²` 缩放
（实测比值 **4.00**），既避开预言机病态又证明解析映射是一阶正确项。
