### 1.4 独立审查（结论：`GAP_FOUND`，4 个 P1、0 个 P0）

由独立审查代理（非实现者）只读复核 seq 重放、readState 回执、已 HOLD 请求、同拍竞争、假成功、测试强度与契约一致性。**结论不是"通过"，而是发现 4 个 P1**——这是本轮最有价值的产出：

| 编号 | 发现 | 证据 |
|---|---|---|
| P1-1 | 同拍 safety 覆盖 `hold_origin`：drain 先回 `applied`（origin=executor），同拍 collision/D7/E8/E1 再 `hold()` 把 origin 改成 controller；执行器要求 `result==1 && origin==executor`，否则 `Wait; return`，**该 return 绕过 ack 超时路径** ⇒ 机器人确实冻结，执行器却永久等待 | `dual_arm_qp_controller.cpp:784-809, 848-935`；`hold_requester.cpp:74-86`；`transport_task.cpp:260-264` |
| P1-2 | replay 判据用 `!running()`，而 **COMPLETE 满足 `!running()`** 且 `step()` 在 COMPLETE 仍继续解算/提交 ⇒ 回执 `applied` 时 `q_cmd` 仍在推进（假成功） | `dual_arm_qp_controller.cpp:796`；`transport_task.cpp:209-213, 234-247`；`transport_task.hpp:196-198` |
| P1-3 | 冻结快照在进入 HOLD 的瞬间取 `last_status_`，而 status 是 10 Hz、冻结发生在控制拍 ⇒ 晚一拍 drain 会把真实冻结误报成 `hold_invariant_violated → FAULT` | `state_machine.cpp:232-235` vs `555-571` |
| P1-4 | 执行器 Abort 只写本地状态机，全仓无 `AbortTransport` 客户端 ⇒ 执行器报 ABORT 时控制器可能仍 RUNNING | `executor_node.cpp:259-266` |

审查同时确认：readState 失败只回 refused 且不冻结（安全方向正确）；单拍内不会有"applied 且 `running()`"；T_H18/T_H19/T_H20 强度足够，而 **T_H21 偏弱**（只断言状态，不断言冻结快照，两个 P1 实现都能通过它）。

## 3. W2 最终处理

### 3.1 C1（`QpSolution` 每 solve 一次分配）

- **结论：BLOCKED（保留）**。不存在"不改 ABI 且不改 G-14 基线"的修复。
- 实测机理：返回的 `Eigen::VectorXd x` 是空向量，任何赋值/拷贝都要分配；move 只把分配推后；该 192 B 走 `malloc`（不是 `operator new`），进程级 new 池拦不到。生产库归因：**655 次 / 638 solve = 1.03/solve**，其中 638 次即 `osqp_solver.cpp:210 solution.x.resize(24)`。
- 候选（**原型验证，未实施**）：新增 `virtual QpSolution solveInto(const QpProblem&, QpSolution&)`，调用方预留 sink ⇒ **17 次 / 638 = 0.0016/solve**。
  - ABI：`sizeof(QpSolution)=48` 不变；`solveInto` 追加在虚表末尾 ⇒ 0 个删除符号、10 个新增符号（不影响既有 vtable 槽）。
  - G-14：**必然使 `libdual_arm_qp_core.so` md5 改变**（新增导出符号），因此与 G-14"md5 未变"直接冲突。
  - 数值回归：三种构建（prod/ctrl/bprime）对比 638 周期 7656 个 `dq`，md5 全为 `c21118176f03a70df34c8be5a84b0c20`，**逐位相同**。
- **唯一最小审批问题**：是否授权在 `src/dual_arm_qp_core/include/dual_arm_qp_core/qp_types.hpp` 追加 `solveInto` 虚函数（尾部追加，ABI 向后兼容但 `.so` 变更），并**重新基线化 G-14 的 md5**？否则 C1 保持 BLOCKED、1.03/solve 继续作为 W2 阻断事实。

### 3.2 C3（≤1 ULP 判据）

- **结论：FAIL（维持）**。原判据按原定义不通过，本轮用独立测试真实复现。
