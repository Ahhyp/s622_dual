## 1. 定义

object/coordination frame = 两个 grasp frame 的 **SE(3) 中点**（世界系）：

```
p_O = (p_L + p_R) / 2
R_O = R_L · exp( 0.5 · log(R_Lᵀ R_R) )
```

## 2. 解析 Jacobian（精确，不是平均近似）

```
v_O = 0.5 (v_L + v_R)                         （精确）
w_O = (I − G) w_L + G w_R                     （精确）
G   = R_L · J_l(ξ/2) · 0.5 · J_l(ξ)⁻¹ · R_Lᵀ,  ξ = log(R_Lᵀ R_R)
```

推导要点：`[ω_O] = [ω_L] + R_L (Ė Eᵀ) R_Lᵀ`，`E = exp(ξ/2)`，`Ė Eᵀ = J_l(ξ/2)(ξ̇/2)`，
`ξ̇ = J_l(ξ)⁻¹ · R_Lᵀ(ω_R − ω_L)`。

**为什么不用 `0.5(ω_L+ω_R)`**：实测两者最大差 **0.485 rad/s**（随机构型，`|ξ|` 最大 3.14 rad）。
只有当相对旋转很小时才近似相等，不能当一般公式。

## 3. 🚨 有限差分验证抓到一个真 bug：SE(3) 逆雅可比写反

写 object-frame FD 测试时，角速度项对不上（误差 1.8，完全错），排查发现
`src/dual_arm_kinematics/include/dual_arm_kinematics/se3.hpp` 里：

| 函数 | 我原来写的 | 正确 |
|---|---|---|
| `leftJacobianInverseSO3(w)` | `I + 0.5[w] + c[w]²`（其实是 J_r⁻¹） | `I − 0.5[w] + c[w]²` |
| `rightJacobianInverseSO3(w)` | `I − 0.5[w] + c[w]²`（其实是 J_l⁻¹） | `I + 0.5[w] + c[w]²` |

**两者被互换了。** 后果：`logSE3(T)` 的平移部分用了 `J_r⁻¹` 而不是 `J_l⁻¹`，
对**大位移/大相对位姿**的 `relativeError` 是错的（C2.3 与 QP 都在用）。

**为什么 Step 0 没抓到**：FD 测试里相对变换是小量（`T₀⁻¹T(q+h·dq)`，旋转 O(h)），
`J_l⁻¹` 与 `J_r⁻¹` 的差是 O(h²)，被有限差分再除以 2h 后只剩 O(h) → 极限下消失。
**只有在大相对位姿下才暴露。**

**修复后**：
- object frame 全部 FD 通过（见下表）
- 新增 `expSE3/logSE3` round-trip 测试（大旋转+大平移）：**max err 1.33e-14**
- C2.3 的 error-rate Jacobian 小偏置偏差从 9.565e-05 → **6.537e-05**（log 精确化带来的改善）
