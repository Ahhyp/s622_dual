# C4.3 S4.1 W2 —— ULP 判据正式变更申请（SPEC_CHANGE，未批准）

- 文档编号：C4.3-S4-W2-DECISION-C
- 类型：**正式标准变更申请（SPEC_CHANGE）**。**未获批准前，原条款维持 FAIL，本文件中的候选条款一律不得标记为 PASS。**
- 边界声明的核心：**S4-T3 的 `== 0` 不修改、不豁免、不降低优先级**；本申请只针对 W2 的“跨实现一致性”判据。

## 1. 两条条款的边界（本申请的前提）

| 条款 | 出处 | 比较对象 | 数值路径 | 通过标准 | 本轮状态 |
| --- | --- | --- | --- | --- | --- |
| **S4-T3** | 规划 `:637` | 同一实现的两次计算 | **同一路径**（同 `q0`、同 `t_traj`、同轨迹、同 `DualArmQpParams`，无物理无并发） | `max\|Δrow.J\|`、`max\|Δrow.e\|`、`max\|Δdq\|` **全部 == 0** | **PASS（本轮复跑仍成立）** |
| **W2 完成判据** | 规划 `:533` | S3 mock 的 `dq` ↔ 控制器装配的 `dq` | **不同路径**（S3：离线 `t = k·dt`；控制器：`t_traj` 累加 + 服务化装配） | “逐周期比 `dq` 位相同（≤1 ULP）” | **FAIL** |

- `已证明事实`：S4-T3 的 `== 0` 在本轮（同一构建、同一输入、连续多次运行）仍然成立，**不因 W2 的 FAIL 而失效**。
- `已证明事实`：W2 的差异**不是**求解器误差，而是**采样时刻不同**（见 §3 证据 2）。
- 因此本申请**只**处理“两个不同数值路径之间允许多大差异”，不触碰“同一路径必须逐位相同”。

## 2. 原始标准（原文，不得改动）

> 规划 `:533`（§5 W2 行，完成判据）：
> “与 S3 `ff_1` 逐周期比 `dq` 位相同（≤1 ULP）；终点误差 ≤ S3 同量级。”

`技术推断`：原文同时给了两个不可分离的要求——“≤1 ULP”（极强，等于要求同一浮点运算序列）与“终点误差同量级”（物理量级）。前者与后者的严格程度相差约 5 个数量级，**条文内部不自洽**，这是需要正式变更而非解释的根因。

## 3. 已证明事实（三条独立证据）

### 证据 1：冻结件自身满足 `t == k·dt`（位级）

用 S3 的 `t = k·dt` 规则复算 638 周期，与 `test/fixtures/s3_ff_1_dq.csv` 的 `dq` 列**逐位相同**（`max|Δdq| == 0`，`decision_mismatches == 0`）。⇒ 冻结件是合法的参考基线。

### 证据 2：差异来源是采样时钟，不是求解器

- 控制器用“累加式”时钟：`t_traj_{k+1} = t_traj_k + dt`。累加 638 次后的相对漂移实测 **3.553e-15**（`max|Δt_traj|`）。
- 该漂移使 `T_d` 与 `v_ff` 相对冻结件出现 ~1e-15 级差异 ⇒ `dq` 出现同量级差异。
- 决定性实验（`test_ulp_semantics.cpp::UlpMetric.S4T2_DifferenceIsTheTrajectoryClockNotTheSolver`）：改用 `t = k·dt` 后差异**归零**；改回累加式后差异**重现**。⇒ **差异完全由时钟口径决定，与求解器无关。**

### 证据 3：ULP 度量在近零处没有物理意义

同一 638 周期对拍，按 `dq` 绝对值分层统计（`ulpDistance` 为单调位型映射）：

| 层 | `\|dq\|` 范围 | `max\|Δdq\|` | ULP 距离 |
| --- | --- | --- | --- |
| 大 | 1e-1 … | 9.0e-14 | 2.08e5 |
| 小 | < 1e-14 | 4.6e-15 | 4.69e20 |

- 7656 个 (周期, 关节) 对中，**绝对差从未超过 9.0e-14 rad**。
- `ulpDistance(+0, −0) = 1 << 63`（实测）：跨零不同号的一对值被映射到符号位两侧，ULP 距离爆炸。这不是数值误差，是度量的定义域问题。
- `技术推断`：对 `dq ≈ 1e-14 rad` 的量要求 ≤1 ULP，等于要求“两次不同浮点运算序列在最低位完全一致”，这在物理上无对应意义（1e-14 rad ≈ 5.7e-13 度）。

## 4. 未验证事项

1. 原生 Linux + 不同编译器（clang / 不同 `-march`）下 `max|Δdq|` 的量级（当前只测了 GCC 11.4、固定编译参数）。
2. 轨迹换成非均匀时间缩放后，累加漂移是否仍为 1e-15 量级。
3. `AdmmSolver` 路径下的差异分布（属 A3 研究，未做）。

## 5. 候选新条款（待批准，不得视为 PASS）

### 5.1 建议条款文字

> **W2 跨实现一致性判据（候选 V1）**
> 对同一起点、同一轨迹、同一 `DualArmQpParams`，逐周期比较 S3 冻结件与控制器装配结果：
> 1. **决策一致**：`committed` 逐周期相同，`decision_mismatches == 0`；
> 2. **关节增量**：`max|Δdq| ≤ 1e-6 rad`，且不得出现非有限值；
> 3. **轨迹时刻**：`max|Δt_traj| ≤ 1e-6 s`；
> 4. **终点**：`‖e_O‖_pos ≤ 1e-3 m` 且与 S3 的比值 ∈ [0.5, 2.0]；
> 5. **安全行为**：`active_limit_count`、`sigma_min_stack` 的逐周期符号与阈值判定一致（不比较浮点值）。

### 5.2 每个阈值的来源（禁止反向选择）

| 阈值 | 来源 | 与实测的关系 |
| --- | --- | --- |
| `1e-6 rad` | **物理相关性下限**：1e-6 rad = 5.7e-5°；典型关节编码器分辨率 ≥1e-4 rad，故 1e-6 rad 比最小可分辨动作小 2 个数量级 | 实测 9.0e-14，余量 1.1e7 倍。**阈值不是由实测推出来的** |
| `1e-6 s` | 控制周期 8 ms 的 1.25e-4；远小于任何轨迹插值的可分辨时间 | 实测 3.553e-15，余量 2.8e8 倍 |
| `1e-3 m`（终点） | 沿用 S3 已承诺的 1 mm 搬运精度（S3 验收 A1–A15 的同一数字） | 实测 2.97e-8，余量 3e4 倍 |
| 比值 `[0.5, 2.0]` | “同量级”的可机检化：2 倍以内即同一量级 | 实测比值 ≈1 |

- 原方案的 `1e-12 rad`：**`THRESHOLD_UNJUSTIFIED`** —— 它是 9.0e-14 的约 11 倍，属于“按实测结果反推刚好能通过”的阈值，本申请**主动撤销**它，不作为正式建议。

### 5.3 近零、符号变化、异常值规则

| 情形 | 规则 |
| --- | --- |
| `\|dq_ref\| < 1e-6 rad` | 走**绝对**判据 `\|Δdq\| ≤ 1e-6`，`dq ≈ 0` 一侧不再有放大效应 |
| 跨零（参考值正、实测值负） | 同绝对判据，不引入符号特判 |
| `+0` / `−0` | 视为相等（差值 0），不参与 ULP 度量 |
| NaN / Inf（任一侧） | **直接 FAIL**，不进入统计 |
| 离群点 | **不得裁剪**；必须报告 `max`、P99.9、以及“超阈值个数” |

### 5.4 比较对象、单位、样本范围、统计方式

- 对象：`dq`（12 维，单位 rad，逐步增量）与 `t_traj`（单位 s）。
- 样本：S4 `ff_1` 规格全 638 周期 × 12 关节 = 7656 对；**全部参与**，不抽样。
- 统计：`max` 绝对值、P99.9、超阈值计数、按 `|dq|` 分层的 ULP 分布（仅作诊断输出，**不再作为判据**）。

### 5.5 新旧条款的适用范围

| 条款 | 适用 | 不适用 |
| --- | --- | --- |
| S4-T3（`== 0`） | 同一构建、同一输入、同一路径、无物理无并发 | 跨实现、跨时钟口径、Gazebo 物理闭环 |
| W2 候选 V1 | 仅 S3↔控制器的跨实现一致性 | 不得用于 S4-T3；不得用于 Gazebo（那需数值容差 + 独立确定性检查，见规划 §7 S4-T3 的适用范围注记） |

## 6. 批准后的必要重新测试

1. 用候选 V1 重跑 W2 对拍，输出 §5.4 的全部统计量（含分层 ULP 诊断，仅展示）。
2. 在**冻结件不变的**前提下，连续 3 次运行，验证 V1 的确定性（三次结果完全一致）。
3. 复跑 S4-T3 的 `== 0`，证明本次变更**没有**连带放宽同路径判据。
4. 回归：`test_mock_closure`、`test_frozen_baseline_compat`、W0 的 208 行对拍。
5. 若候选 V1 之外的任何阈值调整，须重新提交申请。

## 7. 风险与代价

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 弱化到失去判别力 | 1e-6 rad 比原条款松 1e7 倍，可能掩盖真实的实现分歧 | 保留 `decision_mismatches == 0` 与终点/安全行为判据；分层 ULP 统计继续输出 |
