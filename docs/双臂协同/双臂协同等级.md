| 层次              | 定义                   | 例子                                 |
| ----------------- | ---------------------- | ------------------------------------ |
| **L1 时间并发**   | 两臂同时在动，动作独立 | 左臂拧螺丝，右臂同时在另一处贴标签   |
| **L2 空间协调**   | 共享工作区，需避免碰撞 | 左右臂轮流进入 handover 区           |
| **L3 运动学耦合** | 两臂末端有几何约束     | 两臂共同搬一个大箱子（末端距离恒定） |
| **L4 动力学协同** | 力/位置闭环耦合        | 一手扶零件、一手装配，需力反馈       |
