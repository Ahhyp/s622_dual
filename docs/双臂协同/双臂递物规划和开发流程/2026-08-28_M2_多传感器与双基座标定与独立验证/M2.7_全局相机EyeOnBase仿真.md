## 1. 目标与坐标约定

- 用同一台固定全局相机，分别对左/右臂做 **Eye-on-Base** 标定：相机固定 `world`、
  ArUco 标定板（板 240mm / marker 黑框 200mm，DICT_5X5_250 id=1）固定在臂 `grasp_frame`。
- 每臂求解 `base_T_camera`（记 `T_LC`、`T_RC`），再组合
  `T_LR_cam = T_LC · inv(T_RC)`（= `B_L_T_B_R`，经相机推导的左→右基座变换）。
- EOB 恒定帧原理：对每样本 `ee_T_base · base_T_cam · cam_T_marker = ee_T_marker` 恒定，
  `ee_T_marker` 由 solve 集单独建立、hold-out 不参与。
- URDF GT：`left_base @ (0.35,0,0) yaw=π`，`right_base @ (-0.35,0,0)` →
  `T_LR_GT = Rz(180°) + t=(0.7,0,0)`（`dual_arm_calibration.monte_carlo.dual_base_ground_truth()`）。

## 2. 仿真环境

- gz-sim Fortress + ROS2 Humble；全局相机 960×540、camera_info fx=548.3/fy=547.5/cx=480/cy=270；
- marker 实物物理 200mm；**仿真 PnP 用 `marker_size_m=0.1988`（仅 Gazebo 渲染补偿值，
  真机必须恢复 0.200，见 §12）**；
- 相机真值（TF 全精度捕获，与 3 轮 calib 解-误差互推一致 <0.005mm）：

```
right base_T_cam GT = t(0.382500,  0.483782, 0.897635)  q(0, 0.961262, -0.275637, 0)
left  base_T_cam GT = t(0.317500, -0.483782, 0.897635)  q(0.961262, 0, 0, -0.275637)
```

## 3. 验收标准（GPT 规划 §建议验收线）

① 每臂 marker ≥20 有效姿态；② 求解 `solver_valid=True`；
③ 每臂 hold-out：位置 RMS≤3mm、MAX≤5mm、旋转 RMS≤1°；
④ 每臂 `base_T_camera` vs GT：平移≤3mm、旋转≤1°；
⑤ `T_LR_cam` vs GT：平移≤3mm、旋转≤1°；⑥ 三次独立运行离散度记录后冻结门限。

## 4. 实现与关键修复（三类 bug）

1. `launch arm:=left|right` 从未生效（模块导入期才读 env）→ 标定板挂错臂、相机看到"冻结"
   的板。修复：`OpaqueFunction` 在 include 前写 `M2_MODE`/`M2_ARM`（`s622_global_handeye_sim.launch.py`）。
2. 自动采集脚本 `_move_right` 硬编码只动右臂 → 左臂采集时右臂乱动挡视野。修复：`_move_arm`
   按 `--arm` 决定移动哪只臂（`auto_collect_eye_on_base.py`）；另修 Client 覆盖方法的
   `TypeError` 与助手三服务状态同步（/status、/remove_latest、/validate_latest）。
3. camera/PnP 深度尺度偏差：gz 渲染跟随 `<lens>` fx（render≈0.9957×lens），改 lens 自抵消；
   正确杠杆 = `marker_size_m` 0.20→**0.1988**（只改 PnP 假设、不动渲染）。

## 5. 采样质量门与 20/20 策略

- 质量门：marker 角点边缘裕量 ≥60px、边长 ≥90px、静止窗口、姿态覆盖（平移跨度≥40mm、
  旋转跨度≥20°）、20 组目标（15 求解 + 5 留出）。
- 20/20 补采策略（doc 章十一）：auto 采集后对贴边丢组做"探测-补采"——候选修正位姿
  （减倾角/加 j2/j3 位移）实测角点裕量 ≥60px 后逐一 `/validate_latest` 补足。
  丢组模式：右臂 j5=-28°（裕量 55px<60）；左臂正向大倾角 4 组（镜像）。
- 运行可复现性（doc 章十一.1）：软件渲染下 sim 实速 ~0.1-0.2x；杀 launch 链 obb_node/rviz2
  提速；杀 gz GUI 会拆整树；渲染异常需干净重启；ROS_HOME 指工作区（沙箱）。

## 9. 机理实验与误差分解（2026-09-04）

### 9.1 marker_size 双尺度扫描证伪（doc 章十.2）

`camera_T_marker` 平移 ×k ≡ `marker_size = 0.1988·k`（不动渲染）重解 6 轮 + 联合扫描
(k_L,k_R)：单臂 k 最优均在 1.0 附近（0.1988 已居中）；**不存在任何 (k_L,k_R) 使 9/9
组合 ≤3mm**（最优仅 3/9，均值地板 3.70mm）→ 5mm 级组合偏差**不是**均匀深度尺度误差，
"继续调 marker_size"支线终止。

### 9.2 root 敏感性（doc 章七/九）

root 构型显著改变左臂求解收敛（同质量数据可 4.3mm 或 0.4mm）与丢组模式 → 优化盆地/
可观测性差异，非数据噪声。

### 9.3 误差分解（GPT 评审 P1，doc 章十二）—— 旋转 × 1m 杠杆臂主导

对 4 左 × 4 右 = 16 对（含两个 20/20 轮），用 TF 全精度 GT 分解 `T_LR` 误差
（|t 误差| vs (0.7,0,0)）：

| 分解 | 含义 | mean | max |
| --- | --- | --- | --- |
| full | 完整估计 | 5.52mm | 7.92mm |
| **rot_only** | 保留估计旋转 + GT 平移 | **5.76mm** | 9.51mm |
| trans_only | 保留估计平移 + GT 旋转 | **2.37mm** | 4.73mm |
| left_only | 左估计 + 右 GT | 3.07mm | 3.74mm |
| right_only | 左 GT + 右估计 | 3.56mm | 4.44mm |

**结论：组合 5-7mm 由每臂 ~0.3-0.5° 旋转残差经 ~1m 相机位置向量杠杆放大主导**
（rot_only ≥ full；trans_only 均值 2.37mm < 3mm 门——平移残差单独本可过⑤）。
0.3° ≈ 5.2 mrad × 1m ≈ 5.2mm，与观测一致。

**验收设计洞见**：单臂④旋转门 ≤1° 对组合⑤（≤3mm @ ~1m 杠杆）**过松**——组合达标
需每臂旋转误差 ≲0.15-0.2°（且方向有利）。单臂平移精度（1-2.5mm）不是组合瓶颈。

## 10. 已确认事实 / 尚未完全确认假设

**已确认（证据充分）**：
- gz 分离 camera 渲染跟随 `<lens>` fx（render≈0.9957×lens）→ focal_scale 无效杠杆；
- 偏差 ≈ ~1px 角点内缩（深度相关，斜率随臂/轮次不同）+ ~0.5% 常量 → marker_size 0.1988
  是唯一独立杠杆（离线 6 轮扫描证实）；
- ⑤ 非均匀尺度、不可按臂 marker_size 补偿；样本数量不是主瓶颈（20/20 对 7.27mm）；
- 组合误差主因 = 旋转残差 × ~1m 杠杆（9.3 分解）；
- GT 平移绝对值精确（TF 捕获 + 3 轮互推一致）。

**高概率但未单独隔离验证（仿真渲染侧遗留，不再追）**：
- ArUco 亚像素角点的姿态相关偏差（抗锯齿/斜视/像素尺寸变化 → 非等比例内缩）；
- 平面 PnP/IPPE 姿态相关偏差；主点 (cx,cy) 亚像素偏差、fx/fy 各向异性；
- 两臂深度/倾角/画面位置分布不同 → 共享渲染产生**姿态相关**偏差，但左右残差不是同一
  公共右乘变换，故组合中不抵消（若真共享同一 E：T̂_LC=T_LC·E、T̂_RC=T_RC·E，则 E 会在
  T_LR 中抵消——因此"共享相机误差→同向累加"的说法不成立，已修正为本表述）；
- 图像与 TF 时间同步：采样静止门控已压低（遗留项注明，未量化）。

## 12. 真机迁移要求

1. `marker_size_m` **恢复 0.200**（0.1988 仅为 Gazebo 渲染补偿，真机 D435 无此偏差）；
2. 全局相机换成真实相机话题/内参（realsense-ros），重新设计安全采样位姿并重新采样；
3. 重新执行 ③④⑤ 验收；**禁止直接沿用 Gazebo 补偿值或仿真验收结论**；
4. ⑤ 必须真机实测——**不预先承诺"预期 ~1mm 可过"**（现阶段无真机数据支持该精度预测；
   真机无已确认的 Gazebo 渲染偏差，但能否 ≤3mm 需实测）。

## 14. 结论（一句话）

**M2.7 算法链与独立验证链已闭环：①③④ 通过（正式 20/20：右 1.956 / 左 1.375mm，
hold-out RMS ≤1.1mm）；⑤ 组合受"姿态相关残差 + 旋转×1m 杠杆"影响，仿真重复精度
~5mm、未稳定 ≤3mm（best-case 2.73mm 为事后最小，不作验收通过证据）；以约 5mm 精度
地板记录成因，⑤ 留待真机重新验收。**
