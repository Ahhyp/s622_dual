# 真机单臂验证操作手册（58.3，只读验证，不驱动运动）

日期：2026-08-27
适用：`s622_real_arm.launch.py` 首次真机验证（机器：58.3 单臂）
原则：**先只读验证，不主动下发任何运动指令**

---

## 0. 安全前置检查（每一步都重要）

- [ ] 机械臂已上电、控制箱正常、无报警
- [ ] **急停按钮位置确认**，手指随时可及
- [ ] 机械臂周围 1m 无人员/障碍物，工作区清空
- [ ] 手动模式下确认机械臂当前姿态正常（无异常扭曲）
- [ ] 夹爪气源已接（若不接气源，SetDO 无动作，更安全）

## 1. 网络准备

```bash
ping 192.168.58.3 -c 3
```
- 能通（有回包）→ 继续
- 不通 → 先解决 WSL2 → 机械臂局域网连通（镜像网络/桥接），**不要继续**

## 2. 环境

```bash
source /opt/ros/humble/setup.bash
eval "$(conda shell.bash hook)" && conda activate yolov8
source ~/my_S622/install/setup.bash
export ROS_LOG_DIR=/tmp/ros_log   # 可选：日志放 /tmp 避免权限问题
```

## 3. 启动真机 launch

```bash
ros2 launch s622_moveit_config s622_real_arm.launch.py ip:=192.168.58.3
```

**预期日志（看到这些 = 正常）：**

| 日志 | 含义 |
|---|---|
| `Loading hardware 'RealSystem'` → `Successful initialization` | 插件 on_init 成功（joint/参数检查过） |
| `'activate' hardware 'RealSystem'` | 开始激活 |
| `机械臂SDK连接成功！ip=192.168.58.3` | ✅ RPC 连上控制器 |
| `初始指令位置: ...`（6 个数） | 读到真实关节角 |
| `机械臂硬件启动成功!` | ✅ 激活完成 |

⚠️ 激活瞬间插件会 `SetDO(0, 关闭电平)`：**气动夹爪可能"咔"一声闭合一下**，这是设计行为（上电置已知状态），不是故障、不是运动。若担心可先不接气源。

**异常（机器未接通时的表现，接通后不应出现）：**
- `机械臂SDK连接失败！ip=192.168.58.3` → 网络/控制箱问题
- `ros2_control_node terminate` → 激活失败导致（接通后不出现）

## 4. 只读验证（不驱动运动）

新开终端（同样 source 环境）：

```bash
# 4a. 关节状态（只读）——连续看 10 秒，数值应稳定
ros2 topic echo /joint_states --once
ros2 topic echo /joint_states
# Ctrl+C 退出

# 4b. 控制器状态
ros2 control list_controllers
# 预期: robot_arm_controller / joint_state_broadcaster / hand_controller 均 active

# 4c. 节点栈
ros2 node list
# 预期: /move_group_fairino /robot_state_publisher /controller_manager /retime_server 等

# 4d. TF 检查
ros2 run tf2_ros tf2_echo base_link wrist3_link
# 预期输出一组固定变换（机器人没动就不变）
```

**"没在动"判据：**
- `/joint_states` 的 6 个位置值保持稳定（小数点后变化 < 0.001 rad 级别）
- 机械臂本体完全静止、无声音
- 只要有一项异常（突然跳动/持续变化），**立即按急停**并检查

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| SDK 连接失败 | ping 不通 → 网络；ping 通 → 控制箱是否上电/远程模式 |
| joint_states 无数据 | 检查 `ros2 control list_controllers` 是否 active |
| move_group 起不来 | 看日志有无 SRDF/URDF 报错，贴给我 |
| 数值缓慢漂移 | 机械臂在"维持位置"的伺服响应，正常；漂移大才异常 |
