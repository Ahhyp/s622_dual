# S622 机械臂参数

来源：URDF (`s622_moveit_descriptions.urdf`) 和原项目 `fairino_planning_core/types.h`。

---

## DH 参数（标准 DH 约定）

| 关节 i | d (m)   | a (m)   | α (rad)        | theta_offset |
|--------|---------|---------|----------------|--------------|
| 1      | 0.140   | 0       | π/2            | 0            |
| 2      | 0       | -0.280  | 0              | 0            |
| 3      | 0       | -0.240  | 0              | 0            |
| 4      | 0.102   | 0       | π/2            | 0            |
| 5      | 0.102   | 0       | -π/2           | 0            |
| 6      | 0.100   | 0       | 0              | 0            |

C++ 数组形式：

```cpp
std::array<double, 6> d     = {0.140, 0,     0,     0.102, 0.102, 0.100};
std::array<double, 6> a     = {0,    -0.280, -0.240, 0,     0,     0};
std::array<double, 6> alpha = {M_PI/2, 0,     0,    M_PI/2,-M_PI/2,0};
```

## IK 用命名常量（原项目 `fairino_ik.h`）

| 符号 | 值     | 含义               |
|------|--------|--------------------|
| d1   | 0.140  | 基座高度偏移       |
| a2   | -0.280 | 上臂连杆长度(x)    |
| a3   | -0.240 | 前臂连杆长度(x)    |
| d4   | 0.102  | 腕横移             |
| d5   | 0.102  | 腕轴距             |
| d6   | 0.100  | 末端到法兰距离     |
| L2   | 0.280  | \|a2\|，三角形法用 |
| L3   | 0.240  | \|a3\|，三角形法用 |
