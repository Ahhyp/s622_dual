# 桌面平面法替代深度传感器估算目标位置

## 问题背景

BT 单臂 Pick-Place 测试中，XY 视觉对齐偏差过大（数厘米级），导致 descend 时夹爪撞到方块侧面，抓取失败。

## 根因：深度传感器在小目标上穿透

### 现象

YOLO 检测到方块中心像素 `(u,v) = (457.6, 301.6)`，深度传感器在该像素读数 `z_cam = 0.976m`。

但方块实际离相机约 **0.5m**。深度读数是方块**后方背景**的距离。

### 为什么穿透？

```
相机 ──────────── 方块 (4cm) ──────────── 背景（远处）
                   ↑ 仅占 ~20×20 像素
```

1. **方块太小**：4cm 方块在 960×540 图像中仅占约 20×20 像素
2. **RGB-D 对齐误差**：gz-sim 中 RGB 和深度传感器的像素坐标存在亚像素级偏差
3. **中值滤波**：`samplePixelDepth` 在 5×5 核心里取中值。25 个像素中，方块表面可能只覆盖 10~12 个，其余是背景。中值 = 背景深度

### 后果链

```
z_cam 错误（0.976 而非 ~0.5）
  → obj_x = (u-cx) * z_cam / fx  被放大 ~2x
  → obj_y = (v-cy) * z_cam / fy  被放大 ~2x
  → grasp_pose XY 偏了数厘米
  → XY 对齐收敛到错误位置
  → descend 夹爪撞方块侧面
```

## 解决方案：桌面平面交线法

### 核心思想

**不用深度传感器**。已知桌面高度、相机位姿、像素射线方向，用几何求交直接算目标 XY。

### 所需信息

| 信息 | 来源 | 精度 |
|------|------|------|
| 相机位姿 `T_cam_base` | TF (`base_link` → `camera_color_optical_frame`) | 高（URDF + FK） |
| 桌面高度 `table_z` | 参数（已知常量 0.0m） | 精确 |
| 方块高度（顶面） | `table_z + grasp_dz`（0.03m） | 近似，可以接受 |
| 像素 `(u,v)` | YOLO OBB 检测 | 准确 |
| 内参 `(fx,fy,cx,cy)` | `camera_info` | 已知 |

### 数学推导

```
已知:
  - 相机光心在 base 系: P_cam = (cam_x, cam_y, cam_z)
  - 像素 (u,v) 对应射线方向（光轴系）:
      d_cam = ((u-cx)/fx, (v-cy)/fy, 1.0)
  - 光轴系 → base 系旋转矩阵: R
  - 射线方向（base 系）: d_base = R · d_cam
  - 目标平面: z = table_z + grasp_dz

射线方程:  P(t) = P_cam + t · d_base

求交:     P_cam.z + t · d_base.z = table_z + grasp_dz
       →  t = (table_z + grasp_dz - P_cam.z) / d_base.z
       →  obj_x = P_cam.x + t · d_base.x
       →  obj_y = P_cam.y + t · d_base.y
```

### 优势

1. **不依赖深度传感器**——彻底消除小目标穿透问题
2. **只依赖已知几何**——TF、桌面高度、内参都是精确或可接受的近似
3. **计算量极小**——几行线性代数

### 局限性

1. 要求桌面是水平平面（z = const）。倾斜桌面不适用
2. 方块高度（`grasp_dz`）是近似值，但 XY 对 Z 误差不敏感（远距离时有微小放大）
3. 相机 TF 必须可用（仿真中用 URDF，真机中用 `robot_state_publisher`）

## 代码改动

**文件**: `src/s622_bt_manager/src/grasp_nodes.cpp` → `GenerateGraspCandidate::tick()`

改动前（深度传感器路径）：
```
depth pixel → samplePixelDepth(u,v) → z_cam
  → x_cam = (u-cx) * z_cam / fx
  → y_cam = (v-cy) * z_cam / fy
  → TF: camera → base → (obj_x, obj_y)
```

改动后（桌面平面法，优先使用）：
```
1. TF: 读相机位姿 (P_cam, R)
2. 像素射线 d_cam → d_base = R · d_cam
3. 射线与 z = table_z + grasp_dz 求交 → (obj_x, obj_y)
4. 无法求交时回退深度传感器（goto use_depth）
```

日志输出：成功时打印 `Grasp(plane):`，回退时打印 `Using depth sensor fallback:`。

## 验证

编译通过。预期效果：
- `Grasp(plane):` 日志中 `obj_x, obj_y` 与实际方块位置偏差 < 1cm
- XY 对齐收敛后 descend 夹爪正中方块顶部
- 抓取成功率显著提升
