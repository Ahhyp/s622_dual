**PD控制器**（比例-微分控制器）是PID控制器的简化形式，去掉积分项(I)，只保留比例(P)和微分(D)。它通过**当前误差**决定纠正力度，通过**误差变化率**预测趋势并抑制震荡，非常适合需要**快速响应但避免积分饱和**的场景（如视觉伺服、无人机姿态控制）。

---

## 1. PD控制器的数学形式

```python
# 离散时间实现（每隔 Δt 执行一次）
error = target - current_position          # 当前误差
derivative = (error - last_error) / Δt      # 误差变化率（速度项）
output = Kp * error + Kd * derivative       # 控制输出
last_error = error                          # 保存用于下一帧
```

- **Kp**（比例增益）：决定系统对当前误差的敏感度。Kp越大，响应越快，但过大易引发震荡。
- **Kd**（微分增益）：相当于一个“阻尼器”，预测误差的变化趋势，产生相反的力来抑制超调和震荡。

如果采用**位置式PID**标准形式，常写作：
```
u(t) = Kp * e(t) + Kd * de(t)/dt
```
其中 `de(t)/dt` 是误差对时间的导数（速度）。

## 2. 直观比喻：推购物车对准地上的标记

| 情景         | 纯P控制              | PD控制                              |
| ------------ | -------------------- | ----------------------------------- |
| 偏离标记10cm | 用力推（大P）        | 同样用力推，但手会感知车滑行的速度  |
| 快接近标记时 | 仍可能因惯性冲过头   | 手提前“刹车”（D项），稳稳停在标记上 |
| 反复震荡     | 常见（像弹簧来回晃） | 几乎无震荡，一次到位                |

- **P**：根据距离标记还有多远决定推力（误差越大，推力越大）。
- **D**：根据当前滑行速度决定是否提前“捏闸”（速度越快，反向阻力越大）。

---

## 3. PD vs PID：为什么有时不要 I（积分）？

| 控制器  | 特性           | 优点           | 缺点                       | 典型场景                           |
| ------- | -------------- | -------------- | -------------------------- | ---------------------------------- |
| **P**   | 仅比例         | 简单           | 有稳态误差                 | 不要求绝对精度的场合               |
| **PD**  | 比例+微分      | 无震荡，响应快 | 仍有稳态误差（有静差）     | 视觉伺服、角度控制（允许微小误差） |
| **PID** | 比例+积分+微分 | 消除稳态误差   | 积分饱和、参数难调、易震荡 | 温度控制、位置精准调节             |

**为什么视觉伺服常用PD而不是PID？**
- 视觉反馈更新频率高（如50Hz），误差通常不会持续存在（目标移动或相机动态变化），积分项容易累积误差导致**积分饱和**（windup），引起过冲和抖动。
- 机械臂抓取允许毫米级的稳态误差（目标有一定容差），不需要绝对消除静差。
- PD提供更平滑、稳定的跟踪，适合**动态目标跟随**。

## 4. PD控制器的参数整定（Kp、Kd的调节）

**手动调节步骤（Ziegler-Nichols启发式）：**
1. 先设 `Kd=0`，增加 `Kp` 直到系统开始等幅振荡（临界振荡）。
2. 记录振荡周期 `T`。
3. 对于PD控制器：`Kp = 0.5 * Kp_crit`，`Kd = Kp * T / 8`。
4. 微调：增大 `Kd` 可抑制震荡，但过大会导致噪声敏感（微分项放大传感器噪声）。

**常用技巧：**
- 对测量值进行**低通滤波**（尤其是微分项），避免高频噪声放大。
- 在代码中常使用 `derivative = (error - last_error)`（省略Δt，等价于将Kd合并了Δt因子）。

## 5. 代码中的实际例子（与你之前的抓取节点关联）

在你之前的 `PoseEstimator` 或控制器中，如果实现视觉伺服（直接控制相机速度），PD控制可能这样写：

```python
class VisualServo:
    def __init__(self, Kp=0.5, Kd=0.1):
        self.Kp = Kp
        self.Kd = Kd
        self.last_error = 0.0

    def compute_control(self, target_pixel, current_pixel):
        error = target_pixel - current_pixel
        derivative = error - self.last_error   # 简化（省略dt）
        output = self.Kp * error + self.Kd * derivative
        self.last_error = error
        return output
```

输出可以是关节速度指令（对应你控制器配置中的 `velocity` 接口），或者直接作为相机云台的角速度。

---

## 6. 总结

- **PD = 比例 + 微分**，没有积分项，所以**存在稳态误差**，但响应快、无超调、鲁棒性好。
- **核心作用**：用P快速靠近目标，用D“刹车”防止过冲，实现平滑快速跟踪。
- **不适合**要求无静差的静态定位（如数控机床），**适合**高速动态系统或允许微小误差的场景（如视觉抓取、平衡控制）。

在你的抓取系统中，如果直接用PD控制机械臂末端速度去追逐目标像素点，是非常经典的设计。
