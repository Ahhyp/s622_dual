## 问题

双臂 tip 是 `left_grasp_frame` / `right_grasp_frame`，规划组是 `left_arm` / `right_arm`。
原代码只精确匹配 `grasp_frame` / `robot_arm`，双臂下工具模型判定落到 **FLANGE**
→ 工具偏移（flange→TCP 0.1168）丢失 → IK 求解错误。

## 改动

### 1. `src/fairino_planning_ros/src/fairino_ik_plugin.cpp`

**`resolveToolModel()`** — 夹爪名称匹配加后缀识别（C++17，手写 ends_with）：

```cpp
const bool ends_with_grasp_frame =
    tip_frame.size() >= 12 &&
    tip_frame.compare(tip_frame.size() - 12, 12, "_grasp_frame") == 0;
if (tip_frame == "gripper_tool_link" ||
    tip_frame == "grasp_frame" ||
    tip_frame == "tool_link" ||
    tip_frame == "ee_tool_link" ||
    ends_with_grasp_frame) {          // ← 双臂支持
    return ToolModel::GRIPPER;
}
```

**tool/URDF check**（initialize 内诊断）— 原只查 `grasp_frame`，改为遍历候选：
`grasp_frame` / `left_grasp_frame` / `right_grasp_frame`，存在才 check；全部缺失才 skip。
纯诊断，不影响求解。

### 2. `src/fairino_planning_ros/src/fairino_planner_manager.cpp`

**`resolveToolModelFromGroupName()`** — 组名匹配加双臂：

```cpp
if (group_name == "robot_arm" ||
    group_name == "left_arm" ||       // ← 双臂支持
    group_name == "right_arm" ||      // ← 双臂支持
    group_name == "gripper_arm" ||
    group_name.find("gripper") != std::string::npos) {
    return ToolModel::GRIPPER;
}
```
