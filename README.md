# Robot Project

This project is a ROS 2 based robotic arm planning, simulation, perception, and grasping system.
这个项目是 ROS2 为基础的机械臂计划，仿真，感知和抓取系统。

## Main Modules

- 机器人描述 Robot description
- ros2_control 硬件接口 ros2_control hardware interface
- MoveIt2 配置 MoveIt2 configuration
- 客制化planning core Custom planning core
- MoveIt2规划和逆运动学求解插件 MoveIt2 planner and IK plugins
- Gazebo仿真 Gazebo simulation
- yolo视觉感知 YOLO perception
- 手眼协同 Hand-eye calibration
- 视觉 servo 抓取 Visual servo grasping
- web控制和数据监控 Web control and data monitor
