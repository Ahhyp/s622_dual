## 误差模式分析

### Δx（水平方向）

所有测试 |Δx| ≤ 16mm。x 方向映射基本正确。

### Δy（左右方向）

**系统性正向偏移，随 spawn_y 增大而减小：**

| spawn_y              | Δy (mm)  |
| -------------------- | -------- |
| 0.0（测试1）         | **+136** |
| 0.0（测试5，static） | **+160** |
| 0.1（测试2,4）       | **+110** |
| 0.2（测试3）         | **+84**  |
| 0.3（测试0）         | **+58**  |

Δy 随 spawn_y 变化（非恒定 offset），越靠相机光轴中心偏得越大。结合 camera_y 数据——各测试的 camera_y 值差异都很大，但 base_y 偏移模式一致——说明问题是 **camera→base TF 变换中 y 分量的角度依赖性误差**。

### Δz（高度方向）

| 类型                 | 误差          |
| -------------------- | ------------- |
| static:false（落地） | ≤ 1cm（极准） |
| static:true（悬空）  | -4cm          |

对于地面目标 z 检测几乎完美，悬空目标偏高 4cm。相机 79° 倾斜下深度值放大了 z 误差。

## 偏差类型判定

| 分类                      | 特征               | 匹配？             |
| ------------------------- | ------------------ | ------------------ |
| **A**（TF 外参/固定偏移） | 每次固定偏一个方向 | ❌ Δy 随位置变化    |
| **B**（内参/深度对齐）    | 越靠边偏得越大     | ✅ Δy 在 y=0 时最大 |
| **C**（yaw 方向）         | 夹爪方向不对       | ⚠️ yaw 未传入 IK    |
| **D**（下降后偏）         | 上方准下降偏       | 待验证             |

**结论：B 类为主——相机外参或 pixel→3D 在 y 方向有系统误差，随目标位置变化。**

## 关键发现

1. **x 极准**（≤16mm），**z 落地时极准**（≤1cm），**y 偏 6~16cm**
2. Δy 随 spawn_y 增大而减小——越靠近光轴偏得越大 → B 类误差
3. **z 精度取决于目标是否在可观测表面**：地面目标极准，悬空目标偏差 4cm
4. **static 方块悬空时 YOLO 检测质量严重下降**：conf 0.36 vs 0.65，angle 从 1.1 跳到 0.01
5. **IK yaw=0**：OBB 角度未传入规划
6. 相机 79° 倾斜 + 内参 fx≠fy 放大了 y 方向的变换误差

## 投影链路检查

### 思路
先写一个很小的 debug 节点或脚本，目标是验证：

Gazebo 真实物体中心 → TF 到 camera → 投影到像素


然后和 YOLO 检测的 (u, v) 对比。

你要记录这几个值：

ground truth base xyz
ground truth camera xyz
projected uv from camera_info
YOLO uv
depth at YOLO uv
backprojected camera xyz
backprojected base xyz


判断逻辑：

如果 ground truth projected uv 和 YOLO uv 差很多：
    YOLO 检测中心 / 坐标缩放 / letterbox 有问题

如果 projected uv 和 YOLO uv 接近，但 backproject 后 base_y 偏：
    pixel→3D / camera_info / depth对齐 / TF 有问题

如果不用 YOLO，直接用 projected uv 反投影都偏：
    绝对是投影链路问题，不是模型问题

如果用 projected uv 反投影很准，只有 YOLO uv 偏：
    是检测框中心定义或 YOLO 输出坐标问题
